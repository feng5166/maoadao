> A01 #12 #16 #18 + 总表护栏"猫不是资源矿机""无补给责任压力"

> 命题（创始人）：**我们明确要让高价值猫带来更多资源，从而驱动玩家研究
> 它的规律；但怎样做到"这只猫经济价值更高"，又不让用户最后只把所有猫

> 经济最高原则继承（README）：**钱只能扩大可能性，不能购买生命结果**

> 架构守则（全批次适用）：院子循环负责驱动行为，世界模拟负责决定事实，
> AI 负责放大生命差异。

## 零、核心论点：资源是往来，不是产出

矿机化的本质是**猫被功能化**——它存在是为了产出，来访被读成结算事件。
解法不在数值端，在因果端：

> **猫留下东西，是因为它来生活过；不是因为它是产出单位。**

世界观依据（承 v1 正典，玩法化）："全岛的猫都会带回它觉得重要的东西"
（岛的规矩，v1 01）；"互相留东西"本就是岛上关系的形态（v1 02 默契四形态）。
**留下的东西是它和你院子往来的表达，是生活的副产品。**

一句话判据：**用户研究的是"它"，顺便富了；
不是研究"收益率"，顺便有只猫。**

## 一、单币起步：小鱼干

- MVP 一种软资源：**小鱼干**（暂名，词面归 04 终审）；
- 第二货币暂缓（README 拍板）：特殊猫留**特殊纪念物**——纪念物不是货币
  （18 §六 分界：不可花、不入账；仅"特殊交换"一条低频出口，见 §三）；
- 小鱼干可见、可计数——资源不是关系数值，计数不违 05 红线；
- 语言红线：用户侧永不出现**收益率 / 产出 / 效率 / 时薪 / 矿**
  类词（04 补入负面词典）。

## 二、猫的资源差异：怎么"更高价值"而不"矿机化"（本篇核心）

四条设计，合起来回答命题：

1. **留下什么是性格，不是等级。** 每只猫留什么、留多少，挂在它的
   生活方式与行为上（17 概率面 5 Leave Behind）：走南闯北的猫带的东西
   杂而多；讲究的猫留得少而奇；常客留得勤但普通。差异有世界理由，
   可被观察、可被研究（18 渐懂层信息项）——但**岛猫册永不标"高产"**：
   "它总留下好东西"是用户自己总结出的知识（18 认知镜像），
   不是系统颁发的标签；
2. **价值多元，资源只是一轴。** 一只猫的"值得研究" = 资源 + 信息
   （稀有观察）+ 留念可能 + 行为看点 + 社会连接。供给侧不许让资源轴
   独大（配平参数归 22）——否则四类玩家（README）会被压成一类；
3. **无剥削加成，也无衰减惩罚。** 不因你围绕它优化布置而额外增产；
   也不做"来多了就不留了"的递减惩罚（那会被读成惩罚，且教用户
   计算冷却）。它这次留多少，只跟**它这次的生活**有关——
   停留、行为、当日状态（17 面 2/3 的输入）；
4. **结算永不裸数字。** Leave Behind 必须伴随行为叙事——
   "它在纸箱里睡了一下午，走的时候留下了几条小鱼干。"
   **先看见生活，再看见东西**（呈现顺序红线）；
   "+5 小鱼干"式弹出 = P0。

## 三、Sink：花在哪（全部指向实验能力）

| Sink | 是什么 | 节奏 |
| --- | --- | --- |
| 新物件 | 打开新的偏好匹配空间（17） | 主力，归 22 |
| 院子扩槽 | 打开组合空间（16 槽位有限是设计） | 低频里程碑，归 22 |
| 打理 | 可选的状态调整（§四） | 轻量 |
| 特殊交换 | 纪念物/特殊物参与的稀有兑换（铜铃换某个特殊 Goodie） | 低频，归 22 |

Sink 的统一判据：**每一笔支出都应打开新的来访可能**（README 四环之三：
资源 = 扩大实验能力）。

**禁做 Sink**（冻结清单沿 README）：猫升级 / 好感度购买 / 指定猫必来 /
缩短稀有等待 / 体力 / 强制签到。

## 四、磨损与打理：状态，不是义务（A01 #12 + 总表护栏）

- **没有补给系统。** 物件不需要"喂"才有效——摆着就是摆着；
  绝不做"食物没了猫就不来"的责任压力（A01 总表）；
- **旧是受众变化，不是数值下降。** 磨损进入世界事实（抓痕/压痕/旧化，
  A01 #12），但它改变的是物件的**性质面**：旧纸箱软、有味道、有历史——
  可能更受某些猫欢迎；新物件挺括干净——另一些猫喜欢。
  （11"不是衰败，是岁月"的经济侧落法；物件生活史进 18；）
- **打理是实验手段，不是维持收益的义务。** 打理让物件回到"干净"态
  （切换受众），或修一修真坏了的（低频）——不打理**零惩罚**，
  只是受众漂移；
- 永不出现耐久条（"42/100" = P0，A01 #12 禁栏）。

## 五、循环闭合：一圈都绕着实验

```
往来（猫留下）→ 积累 → Sink（新物件/扩槽/打理/特殊交换）
→ 新的来访可能 → 新的往来
```

- **无外溢**：资源永不能变成猫以外的 power（无战力、无加速、无特权）；
- **无囤积意义**：不做余额排行、不做资产炫耀位——攒着不花没有身份价值，
  富的意义只在"能试的更多"；
- **真钱不入小鱼干循环**（本篇立场，12 重写时定稿）：真钱若未来出现，
  只碰表达类（v1 07 §五 左栏遗产），永不直接或间接兑换小鱼干——
  买鱼 = 买实验速度 = 研究环的 P2W，与"时间不出售"同族；
- 节奏全归 22（Retention pacing：首日/D3/D7 的资源与物件获取节奏、
  source/sink 配平）。

## 六、eval

- **矿机化盲读（本篇北极星）**：抽用户 session 叙述（未来加兴趣组发言）——
  谈论猫时说的是"它"，还是"产出/收益"？定性判；
- **结算叙事覆盖率**：Leave Behind 100% 伴随行为叙事，裸数字弹出 = P0；
- **资源轴独大监控**：用户目标分布（资源目标 vs 收集目标 vs 研究目标）——
  长期单极 = 配平回炉（22）；
- **语言扫描**：收益率/效率/产出/时薪/矿/耐久 = P0；
- **无义务审计**：物件长期不打理，来访结构只发生受众漂移、不塌方；
  出现"不打理→惩罚性归零" = 缺陷；
- **通胀报数**：source/sink 比、小鱼干存量分布（报数，配平归 22）。

（磨损随使用，世界事实）；**经济系统只读世界事实，永不反写来访概率**
