## 零、三条硬经济原则（正典，冻结）

> **一、资源是往来，不是产出。**
> **二、钱只能扩大实验空间，不能购买生命结果。**
> **三、时间、概率和猫本身，都不出售。**

矿机化的本质是**猫被功能化**——它存在是为了产出，来访被读成结算事件。
解法在因果端不在数值端：**猫留下东西，是因为它来生活过；
不是因为它是产出单位。**（世界观依据承 v1 正典："全岛的猫都会带回
它觉得重要的东西"；"互相留东西"本就是岛上关系的形态。）

一句话判据（正典）：**用户研究的是"它"，顺便富了；
不是研究"收益率"，顺便有只猫。**

这三条守住后，22 才可以放心做数值。

## 一、资源分类：小鱼干、特殊材料、纪念物（评审修订，P0）

| 类 | 性质 | 能不能花 |
| --- | --- | --- |
| **小鱼干** | 通用软资源（MVP 唯一通货，暂名归 04 终审） | 能——一切常规 Sink |
| **特殊材料** | 稀有资源：特定来访带来的岛材（旧羽毛之外的那把贝壳、一段漂流木） | 能——仅"特殊交换"（§三） |
| **纪念物** | **历史，不是资源**：代表一段经历的物（18 §六） | **绝对不能**——永久留存、不可消费、不入账 |

> **P0 红线：任何不可逆生活记忆，不得进入经济 Sink。**

一只特殊猫可以同一次来访**同时**留下一根旧羽毛（纪念物）和一些岛材
（特殊材料）——但两者**数据层分表**，永不互转。用户拿到代表某段经历的
铜铃，系统绝不会下一秒问"要不要换把雨伞"。

> **落码（2026-08-08，首发四猫判定拍板）**：Home.fish / HomeMaterial /
> Memento 三表分立（Memento 挂 sourceVisitId 溯源，无价格无消耗路径，CI 看守）。
> 土豆→好木料、盐汽水→上了油的小零件（岛材）；斗斗的"叫不上名字的东西"、
> 爆米花的旧日报→**纪念物**——旧日报判**纪念物·信息载体**而非岛材：
> 有故事意义的实体不被 Sink 吞掉（"读报=线索载体"为候补，另案）。
> 买物件（ITEMS.price）为第一个 Sink；岛材的"特殊交换"Sink 后续格接。

小鱼干可见、可计数（资源不是关系数值）；语言红线：用户侧永不出现
**收益率 / 产出 / 效率 / 时薪 / 矿**类词（04 补入负面词典）。

## 二、猫的资源差异：怎么"更高价值"而不"矿机化"（本篇核心）

1. **留下什么是性格，不是等级。** 每只猫留什么、留多少，挂在它的生活方式
   与行为上（17 概率面 5）：走南闯北的猫带的东西杂而多；讲究的猫留得少而奇；
   常客留得勤但普通。差异有世界理由、可被研究（18 渐懂层）——
   但**岛猫册永不标"高产"**："它总留下好东西"是用户自己总结的知识
   （18 认知镜像），不是系统颁发的标签；
2. **Visit Rarity × Economic Value 正交（评审补入，红线）。**
   稀缺档位与资源期望**不得存在映射表**——"COMMON=3 / RARE=10 /
   SPECIAL=30"式落表 = P0（22 落表时的护栏）。合法组合全部存在：
   常见但大方的猫 / 稀有却几乎不留资源的猫 / 特殊猫主要价值在行为、
   信息与记忆 / 不起眼的猫偶尔留下很好的东西。
   **稀有 = 见到它本身难得，不是金色品质、产量 ×5**；
3. **价值多元，资源只是一轴。** 一只猫的"值得研究" = 资源 + 信息 +
   留念可能 + 行为看点 + 社会连接；供给侧不许资源轴独大（配平归 22）；
4. **无剥削加成，也无衰减惩罚。** 优化空间是**提高"遇见它"的机会**，
   不是提高"榨取它"的效率：不因围绕它优化布置而额外增产，也不做
   "来多了就不留了"的递减惩罚。它这次留多少 =
   它是谁 + 做了什么 + 当时状态 + 一定变化（17 面 2/3 输入）；
5. **数字不得成为来访结果的第一表达和唯一表达（评审精确化）。**
   资源既是通货，用户必须清楚拿到了多少——禁的是"数值先于生命"：

   ✓ 合法："它在纸箱里睡了一阵。走的时候，那里留了几条小鱼干。小鱼干 × 5"
   ✗ 非法："+5 小鱼干！"（唯一表达）

   上下文不强制生成叙事句——**视觉本身就是生活事实上下文**
   （压扁的纸箱 + 旁边几条鱼干），防表达机械复读（A01 #11）。

## 三、Sink：花在哪（全部指向实验能力）

| Sink | 花什么 | 是什么 | 节奏 |
| --- | --- | --- | --- |
| 新物件 | 小鱼干 | 打开新的偏好匹配空间（17） | 主力，归 22 |
| 院子扩槽 | 小鱼干 | 打开组合空间（16 槽位有限是设计） | 低频里程碑，归 22 |
| 打理 | 小鱼干（轻量） | 状态切换（§四） | 轻量 |
| 特殊交换 | **特殊材料** | 稀有兑换特殊 Goodie（纪念物**永不**参与） | 低频，归 22 |

Sink 统一判据：**每一笔支出都应打开新的来访可能**。

**禁做 Sink**（冻结）：猫升级 / 好感度购买 / 指定猫必来 / 缩短稀有等待 /
体力 / 强制签到。

## 四、磨损与打理：全是有效状态，没有失效（评审修订）

- **没有补给系统**：物件不需要"喂"才有效，摆着就是摆着——
  绝不做"食物没了猫就不来"的责任压力（A01 总表）；
- **旧是受众变化，不是数值下降**：磨损进入世界事实（抓痕/压痕/旧化），
  改变的是物件的**性质面**——旧纸箱软、有味道、有历史，另一些猫更爱；
  （11"不是衰败，是岁月"的经济侧；物件生活史进 18）；
- **MVP 状态集全部有效，无失效态**：

  ```
  NEW → USED → WORN ⇄ CLEANED / REPAIRED
  （每一个都是合法的生活状态；没有任何状态导致物件失效）
  ```

  "真坏 / broken / 必须修"**不进 MVP**——只要存在"正常→坏→必修"，
  就是没画 HP 条的维护义务。若未来确需破损，另案设计；
- **打理不是修复损失，是主动把物件切换到另一种性质**——
  打理本身是研究行为（新旧受众不同）；不打理**零惩罚**，只是受众漂移；
- 永不出现耐久条（"42/100" = P0）。

## 五、边界：钱与概率、真钱与世界（冻结并加严）

**经济与概率的红线（评审精确化）**：

> **钱不能改概率，钱买到的东西可以改变条件。**

- ✗ 错误：`fishBalance > 1000 → RareCatWeight +20%`；
- ✓ 正确：小鱼干 → 买雨伞 → 用户摆下 → 雨伞作为世界中的**真实物件**
  进入 Preference。

精确表述：**资源余额、消费金额与付费状态本身，不得直接进入
Eligibility / Preference**。经济当然会经由"买到并摆下的物件"影响实验空间——
那正是它存在的意义。

**真钱红线（冻结，加严）**：真钱永不购买**世界响应速度**——
不卖小鱼干，也不卖它的一切变体：双倍小鱼干 / 自动收取增益 /
来访资源加成 / 更多 Visit Window / 缩短机会累积 / 稀有猫概率加成 /
付费专属"高收益猫"。可商业化的落点只在：**表达、视觉、空间个性化、
收藏展示、非竞争性内容扩展**（v1 07 §五 左栏遗产）。
MVP 是否涉及商业化，归 12 定义，本篇只立边界。

**循环闭合**：

```
往来（猫留下）→ 积累 → Sink（物件/扩槽/打理/特殊交换）
→ 新的来访可能 → 新的往来
```

无外溢（资源永不变成猫以外的 power）；无囤积意义（不做余额排行与
资产炫耀位）；pacing 全归 22。

## 六、eval

- **矿机化盲读（北极星）**：抽用户 session 叙述——谈论猫时说的是"它"，
  还是"产出/收益"？定性判；
- **结算上下文覆盖率**：Leave Behind 100% 具有**生活事实上下文**
  （叙事句或视觉现场皆可），数字为第一/唯一表达 = P0；
- **正交审计**：稀缺档 × Leave Behind 期望的相关性监控——
  高相关 = 矿机化前兆，22 落表回炉；
- **资源轴独大监控**：用户目标分布（资源/收集/研究）长期单极 = 配平回炉；
- **语言扫描**：收益率/效率/产出/时薪/矿/耐久 = P0；
- **无义务审计**：物件长期不打理，来访结构只受众漂移、不塌方；
- **概率隔离审计**（CI 级）：Eligibility/Preference 的输入集不含
  余额/消费/付费字段；
- **点击劳动检查**：收取操作数不随资源量线性增长（§合回 UI）；
- **通胀报数**：source/sink 比、存量分布（报数，配平归 22）。

## 合回清单

### 数据模型
资源账户（小鱼干）；**特殊材料表**（与纪念物分表，P0）；Leave Behind 明细
（挂 CatVisit，16）；物件状态面（NEW/USED/WORN/CLEANED，无失效态）；
特殊交换记录。
### Simulation
Leave Behind 由来访行为派生（17 面 5）；物件状态演化（磨损随使用，世界事实）；
**余额/消费/付费不进入 Eligibility/Preference 的输入集**（CI 审计）。
### Director
资源轴配平看守；特殊交换的稀有稀释看守。
### 数值
全归 22：各猫 Leave Behind 分布（**禁稀缺档映射产量表**）/ 物件价格与
获取节奏 / 扩槽里程碑 / 打理成本 / 特殊交换表 / source-sink 配平 /
首日-D7 pacing。
### API / Action
收下（08 既有动作）；获取物件 / 扩槽 / 打理 / 特殊交换；
无任何"加速/必来/增益"类接口。
### Web / UI
资源余额呈现（可计数，无排行/无炫耀位）；结算呈现：生活现场在前、
数字在后（§二·5）；**逐件发现 ≠ 逐单位点击**——一次 CatVisit 的遗留
是一个生活对象，收一次（一小撮鱼干 ≠ 点七下），30 秒循环不被结算操作吃掉。
### 埋点
入账/支出流水；首个自主 Sink 决策时长；资源→物件目标转化
（D4 旗标原料，定义归 20）；收取操作数（点击劳动检查）。
### 文案 / 美术 / 音频
Leave Behind 表达过 04（生活语言；视觉现场可替代叙事句，防机械复读）；
物件旧化视觉归 11（岁月不是衰败）。
### 旧规则迁移
既有鱼币（`lib/sim` 世界经济，守恒已修）KEEP——世界侧事实源，与用户侧
账户的关系实施时定；"叼回小东西 3-5 天一件" MIGRATE→Leave Behind 节奏
（22 重校）；v1 07 §五 钱的边界 KEEP，本篇 §五 为其经济侧加严版。
### 验证指标
H4（经济有效）：资源→下一件物件目标转化率；首个自主 Sink 决策时长；
D4 阶段达成率（旗标归 20）；矿机化盲读通过率（北极星）；
正交审计与资源轴配平健康（22）。
