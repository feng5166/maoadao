# doc2.0/10 猫岛内容生产规则——没有编剧的世界，如何持续产生值得看的内容

> 2026-08-05 立稿（评审指定）。命题（创始人）：这不是"怎么写文案"（那是 04 语言），
> 也不是"什么是故事"（那是 06 哲学）——是**供给问题**：
> **一个没有编剧的生命世界，如何日复一日不枯竭、不重复、不注水。**
>
> 与 06 的分工：06 管质量闸门（三门/五红线），本文管产能与池子。
> 教训基线：30 天干跑 rest 占 23.4% 却产不出一句可看内容（doc/09）——
> 供给问题是这个产品第一次真正撞过的墙。
>
> **2026-08-05 冻结：供给规则 v1。** 评审九项拍板：配不是写、四因子（不互相顶班）、
> 加维度不加集数、池子养护五规则、重复感三分类（行为不设上限）、人机分工、
> 编辑不是编剧、供给红线、仪表盘。两条原则补入（§零）；流水线定稿（§零）。
>
> **2026-08-08 §十二 增量立稿（2.1 批次二收口篇，待评审）**——不设计新系统，
> 把 06 §九 / 05 §十 / A01 已冻结的内容哲学收拢成一套**生产验收标准**。
> 命题句：**重复的生活是习惯，重复的表达才是问题。**

## 零、核心论点：内容不是写出来的，是配出来的

没有编剧的世界，产能来自**组合**，不来自创作：

```
内容 = 事实（组合爆炸）× 素材（手写池）× 表达（LLM 变化）× 选择（导演）
```

四个因子各有各的枯竭方式，也各有各的养护方式（§二-§五）。
任何"内容不够"的问题，先诊断是哪个因子枯了——**四因子不互相顶班**：
素材枯了加事实没用，事实枯了换说法更没用。

与闸门的流水线（评审定稿）：

```
10 生产候选 → 06 审核价值 → 04 审核表达 → 发布
```

两条原则（评审补入，冻结）：

- **内容回写世界**：展示过的事实必须留下持久资产——七仔发现的贝壳
  从此在小屋里，不是渲染完就丢，否则内容只是一次性消费。
  **与 06"故事层只读"的分界**：回到世界的是**事实资产**（物件/记忆，
  走既有链路：拾获 → MemoryEntry → 收藏 → 回响），不是叙事结论——
  箭头依然只朝一个方向。这是 02"沉淀，不是刷新"的供给侧总则。
- **稀有稀释**：稀有之所以珍贵，是因为普通存在。特殊事件的浓度由
  比例配平与巧合限额（06）双重看守；**供给压力永不用稀有内容解**——
  大事件不是产能工具。

## 一、供给的三层结构（doc/00 §十一 的供给视角）

| 层 | 载体 | 服务 | 供给要求 |
| --- | --- | --- | --- |
| 私密层 | 日记/海螺/便条 | 牵挂 | 重**个体差异**（我的猫和别人的不一样） |
| 岛内层 | 岛闻/日报/公告栏 | 世界感 | 重**密度**（岛每天都在发生事） |
| 外部层 | 分享卡/内容号 | 传播 | 重**梗**（三秒可懂，单独成立） |

三层共用事实源，但选材标准不同——同一件事实可以三层各用一次，不算重复。

## 二、事实因子：组合爆炸是主产能

27 组初始 × 七层生命状态（05）× 关系史 × 习俗/天气 × 16 只 NPC——
事实空间天然不重复。**产能瓶颈从不在事实，在"可叙事事实"**：
每个低强度事件必须携带微细节（doc/09 拍板，rest 教训的修法）。

扩产规则：**加维度，不加集数。**
新增内容优先加"状态维度"（新天气、新时段变体、新地点、新物件类）——
一个维度乘进所有组合；一条手写剧情只能用一次。
（例：加"起雾天"一个维度，全岛每只猫自动多出一族新事实；
写"灯塔寻宝第二季"只多一条线。）

扩展判断门（评审拍板）：MVP 后任何内容类新增需求，先问一句——
**是增加世界维度，还是增加剧情数量？** 优先前者；后者需单独立项论证。

## 三、素材因子：池子的养护（人的工作）

手写池现状（主线已有）：Life Moment 微细节池 90+ 条、睡姿/梦境池、
物件池、回执/反应池。养护五规则：

1. **标尺不变**：小得具体、具体得无用（doc/09）——写池子是编辑工作，
   标尺是唯一门槛；
2. **池深按露出频率定**：高频位（rest/日常）池子要深，低频位（大事件）可浅——
   深度错配是重复感的第一来源；
3. **枯竭预警**：单条素材的月露出次数设上限，超限报警 → 补池（§九 仪表盘）；
4. **补池节奏跟着干跑抽读走**：重复感必须先于用户、被 eval 发现；
5. **素材入池过全套门**：三门（06）+ 猫化判据（doc/21）——
   池子是内容的上游，污染都从上游进来。

## 四、表达因子：LLM 的变化域与禁区

LLM 提供表达变化（同一事实、不同说法），但边界既有且不动：
只包装不发明（事实先行）、过 04 五声部与词典、禁总结句、口癖/自称跨天一致。

供给位次律：**表达变化是防重复的最后一层，不是第一层**——
先让事实不同（§二），再让素材不同（§三），最后才轮到说法不同。
用"换个说法"掩盖"事实重复"，三天就会被识破。

## 五、选择因子：导演的供给职责（06 §五 的供给视角）

反重复惩罚、冷却、形态轮换（日记/对话/便条）、比例配平（50/25/15/10）、
习俗节律（01）——全部既有。供给视角的总结：

> **导演不是让内容更多，是让重复更晚被感觉到。**

导演的供给底线即既有红线：每天每猫至少一件值得看的小事。

## 六、重复感的科学（本文核心新增）

**重复感 ≠ 重复。** 用户对重复的耐受分三种，对策各不相同：

| 类型 | 例 | 性质 | 对策 |
| --- | --- | --- | --- |
| **行为重复** | 它每天都睡午觉 | **好**——这是生命感，是习惯（05） | 保留，并入习惯派生让用户"发现规律" |
| **表达重复** | 同一句描述出现两次 | **坏**——穿帮 | 池深 + LLM 变化（§三§四） |
| **结构重复** | 每天都是"捡到东西+一句感想" | **慢性坏**——疲劳 | 形态轮换 + 四形状混合（06 §二） |

最常见的误诊：把行为重复当问题去"修"（让猫每天做新鲜事）——
结果杀死习惯、制造小剧本。**先分类，再动手。**

## 七、人机分工（谁生产什么）

| 谁 | 生产什么 |
| --- | --- |
| 模拟器 | 事实（唯一事实来源） |
| LLM | 表达（包装，不发明） |
| 导演 | 选择（权重，不写台词） |
| **人（编辑）** | 素材池写作、新维度设计（场景/天气/习俗/物件类）、新正典（NPC/地点）、eval 抽读 |

> **人永远不写"今天发生了什么"——人写"什么可能发生"。**
> 编辑不是编剧：编剧决定情节，编辑养护土壤。

## 八、供给红线

- **不为填日历注水**：没内容比假内容好（休刊日精神——"安静"本身是质感）；
- **不为 KPI 加戏**：供给压力永不传导为戏剧密度（06 五红线的上游适用）；
- **池子终审权在人**：LLM 可出素材草稿，入池由人按标尺终审——
  手写池是猫岛味道的最后防线，不外包；
- **外部层永不反哺内核**：传播爆梗不回流改人设、改事实（认知层不动情感层，doc/22）。

## 九、eval（供给仪表盘）

- **素材露出频率表**：单条月露出计数 + 枯竭预警线；
- **重复感三分量**（§六）：行为/表达/结构分开测，干跑 30 天出报表——
  行为重复率**不设上限**（那是习惯），表达重复零容忍，结构重复看轮换分布；
- **30 天耐看性抽读**：既有标准（像生活/像任务日志/像剧本）升为供给验收；
- 池深/露出比健康线：待干跑校准，先报数。

## 十、合回清单

- 素材露出计数与预警（轻量埋点）；
- 重复感三分量 eval 脚本；
- doc/08（内容池扩充方案）与本文合并口径——本文为其 2.0 总纲，实施时加指针；
- 编辑工作手册一页纸：池子写作标尺卡（doc/09 标尺 + 猫化判据 + 三门）。

## 十二、2.1 玩法化接口：内容生产红线的统一（2026-08-08 增量立稿，待评审）

> 命题（创始人点题）：**重复的生活是习惯，重复的表达才是问题。**
> 本章是生产规范，不是玩法设计——不引入任何新系统，只把已冻结的哲学
> 统一成生产侧可执行、可验收的红线。各条出处在括号里，本章不改其语义。

### 12.1 五条生产红线（收拢，冻结候选）

1. **普通一天合法**（06 §九·9.6 / 16 §七 / v1"有些树叶就只是树叶"）——
   安静的窗、无痕的路过、没人看见的来访都是这个世界真实的一部分。
   生产侧禁"找补"：没内容比假内容好（§八 休刊日精神的玩法版）；
   任何"这个窗太空了，补点什么"的机制 = 缺陷。
2. **行为重复合法**（§六 / 05 §十 / 17）——行为重复不是供给问题：
   它是 ContextHabit 的原料（反复发生的世界事实才长得出习惯）、
   是研究环的规律素材（用户靠重复总结规律）。修行为重复 = 杀习惯 +
   拆研究环的台，双重错误。行为重复率**永不设上限**（§九 照旧）。
3. **表达机械复读禁止**（§六 / 06 §九·9.5）——零容忍；对策只有池深与
   表达变化（§三§四 位次律），**永不通过改事实层来解**
   （"最近连续两次是爪印"→强改成一撮毛 = 伪造世界事实，P0）。
4. **反重复只管叙事**（06 §九·9.5 冻结的生产侧执行面）——重复探测器与
   去重惩罚只准挂 Narration / Presentation Selection；来访引擎与事实层
   路径里出现任何叙事去重逻辑 = 缺陷（CI 看守既有）。
5. **Narration 只读**（06 §九·9.1）——叙事管线对链上游一切层零写权；
   内容回写世界的只有**事实资产**（§零 两原则），不是叙事结论。

### 12.2 玩法内容位入池（不新设系统，全部纳入 §三 既有养护）

2.1 新增的内容位全部是**池子**，按池子的规矩管（标尺/池深/枯竭预警/入池过门）：

| 池 | 现状（代码位） | 养护要点 |
| --- | --- | --- |
| 来访行为池 | BehaviorSignature（09 正典）+ IDLE_BEHAVIORS（L3 无用层） | 签名行为随猫终审；无用行为池要深（高频位） |
| 痕迹表达池 | ITEM_TRACES / 毛色痕 / DEFAULT_TRACE | 每物件至少一条专属痕；痕迹一问（11）：谁留下的、为什么留下 |
| 线索文本池 | CanonClue 手写谜面（06 §九·9.9） | 逐条挂 canon 出处；只给假设不给答案；不点名 |
| 留物与纪念物名 | MATERIALS / MEMENTOS（19 落码） | 词面过 04 终审；纪念物名要担得起"永久留存" |

竞品映射照 A01 禁栏执行：可映射机制，**禁照搬表达**——
猫咪后院的"礼物腔/收集进度腔"一句都不许进池（A01 禁栏与正条同效力）。

### 12.3 生产验收（eval 增量——对 12.1 逐条可查）

- **找补审计**：安静窗之后不存在任何补偿性内容生成路径（红线 1）；
- **重复探测器挂点审计**：全库反重复逻辑的挂载点清单 ⊆ {Narration,
  Presentation Selection}（红线 3/4，承 06 §九 CI）；
- **行为重复误诊抽检**：干跑报表中行为重复率高的猫，不得出现"为它加新鲜事"
  的处置记录（红线 2——先分类，再动手）；
- **池子标尺抽读**：12.2 四池纳入 30 天耐看性抽读与露出频率表（§九 既有）；
- **A01 禁栏扫描**：用户侧文案对 A01 禁止照搬总表九条过一遍（lang-scan 扩表）。
