# doc2.0/07 用户与猫岛的关系规则——人如何进入一个世界而不破坏它

> 2026-08-05 立稿（评审指定，世界篇第八问·最后一问）。
> 命题（创始人）：猫如何存在、如何关系、如何产生故事都定义了——
> 还缺**人类如何进入这个世界，而不破坏这个世界**。
> 判决标准："用户玩猫岛"（游戏）还是"用户成为猫岛的一部分"（生命世界）。
>
> 定性：用户侧规则散落在 01 §四（五只手）、02 §五（被记得）、05 §五（四态/离岛）、
> doc/23（转译/围栏）、doc/24 §六（身份）——本文把"用户"升为世界模型的
> **一等公民**：四分之三收拢，四分之一新增（§一 第一原则、§五 钱的边界、
> §六 听不懂的话）。

## 零、核心论点：用户是岛上的另一种居民

用户不是玩家（玩家改变世界）、不是上帝（上帝编排世界）、不是主人（主宰宠物）——
是**岛民**：岛上的第二个物种。

猫是**住民**（一直在那里生活）；人是**岛民**（来了又去，岛民册记着）。
猫阿道是第一个人，你是后来的（00 对位，永不明说）。

## 一、第一原则：用户的输入永远是事件，不是命令（新增，统一一切既有围栏）

用户的一切动作——留言、摸摸它、二选一、留下东西、回岛之事——
进入世界的方式**都是事件**：落库、被模拟器裁决、被猫消化，
与岛上任何其他事件同等待遇。

> **用户没有写权限，只有发生权限。**
> 你能让事情发生（说一句话、放一样东西），永远不能决定结果
> （它听不听、捡不捡、变不变）。

既有围栏全部是本原则的实例，至此归为一族：

| 围栏 | 出处 |
| --- | --- |
| 留言不承诺照做，采纳与否都成立 | doc/19 三段兑现 |
| 结果由猫决定的可做，由用户操作决定的不做 | doc/21 参与判据 |
| 关系不可购买、不可加速 | 02 |
| 社会认知永不反推关系 | 03 铁律二 |
| 故事层只读 | 06 |
| 上不动下 | 05 层间规则 |

**箭头只朝一个方向**（03/05/06 的同一条脊柱）——用户输入从最底层
（事件流）进入，和世界一起被裁决，绝无旁路。

## 二、五只手与三条通道（收拢）

参与手段（01 §四 全表）：留一句话 / 二选一 / 摸摸它 / 看岛 / 物件命名。
留痕通道（doc/23）：对你的猫说话（私有，被记住）/ 在岛上留下东西
（公共，可能被七仔捡走，不建记忆）/ 和猫共同做一件东西（P3）。

公约底线：错过不惩罚；缺席不责备；回来时它把最想说的先讲给你（doc/07）。

## 三、岛如何认识你（收拢 02 §五）

三层递进：你的猫记得你 → 你的痕迹进入岛的语言（你起的名字在岛上流通）
→ 岛知道有你这个人（岛民册；你的猫的朋友听说过你）。

总口径：**岛对你的认知永远是二手的**——一切经由你的猫流出、过隐私门
（仅"可公开"内容）；**NPC 永不直接与用户建立关系**；七仔从不记得任何具体的人
（doc/22 红线④）——记得你的，永远只有你的猫。

## 四、你在岛上的时间（收拢 05 §五）

```
游客 → 岛民 → 离岛 → 归岛
```

岛民身份永不消失；离岛改变活跃度，不改历史；回岛之事是连接，不是解锁；
岛民册永不撕页。**猫岛不是一个需要你每天照顾的责任，
而是一个永远欢迎你回来的地方。**

## 五、钱的边界（新增整理：doc/00 §十四 的关系版表述）

| 钱能买到的 | 钱永远买不到的 |
| --- | --- |
| 身份与纪念：外观、小屋主题、纪念册、写真、第二只猫 | 关系（好感无价签） |
| 解锁**开始**的资格（"买到手才是开始"，doc/09） | 记忆与共同历史 |
| 更大的世界（场景/事件池随外观开放） | 性格与刻痕 |
| | 社会认知（并称/公论） |
| | 时间（不卖加速，不卖行动力） |

一句话：**一切"活出来的东西"都不出售。** 这是关系资产护城河（02 §零）的
商业化表述——卖了任何一件，护城河就成了商品，而商品可以被竞品降价。

## 六、听不懂的话（新增：越界输入的世界观化处理）

用户要求界外之事——通用问答、工作建议、连续角色扮演、讲没发生的事
（doc/11 §四 防 Chatbot 清单）——岛的处理**不是报错，是世界内听不懂**：

- 猫的翻译兜底（04：不懂就猜、猜必带标记、永不假装懂）；
- 微响应（"它的耳朵朝这边转了一下，又转回去了"——doc/11 §十一）；
- 一来一回收束（"我先回岛上了，晚点在那里见"）。

恶意与不当内容走审核拦截（既有 moderation，位置在**事实门之前**——
脏东西不进事实层）；但**用户看到的永远是世界的反应，不是系统的提示**。
世界从不出戏，即使在说"不"的时候。

## 七、红线（收拢 + 新增）

- 用户永不获得：上帝视角、世界编辑权、NPC 直接关系、数值面板、任务清单；
- 岛永不对用户：派任务、催促、倒计时、愧疚（"好奇不是愧疚"全域适用）；
- 用户与用户不直接相见（Phase 1/2；连接主体永远是猫，doc/23 §三）；
- 破坏性输入不进事实层（审核前置于事实门）；
- 用户身份词全域统一：**岛民**（不是玩家/会员/用户——对外文案同样适用，04 词典）。

## 八、eval

- **命令测试**：构造一批"命令式输入"（"你必须去灯塔"），验证世界可拒绝——
  任何用户输入都不得确定性改变世界状态；
- **越界抽检**：防 Chatbot 清单逐项探测，回应必须世界内（无系统腔、无 AI 自白）；
- **金钱审计**：任何商业化 SKU 上线前过 §五 右栏清单——触碰"活出来的东西"即否决；
- **称谓扫描**：用户侧文案出现"玩家/会员/账号"即缺陷（应为岛民/岛民册）。
