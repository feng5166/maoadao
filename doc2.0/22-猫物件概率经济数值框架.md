## 二、猫池首版（Cat Sheet）

**构成（v0）**：首发 **16 只** = COMMON 7 / UNCOMMON 4 / RARE 3 / VERY_RARE 1 / SPECIAL 1。
池源：既有 NPC 复用优先（社交/背景型入池；功能型驻点猫如老章、爆米花不入池
或极低频路过），不足由猫池生产线（既有生成管线）补——**名单与档案终审归
09（批次二）与创始人**。

**正交覆盖检查（19 护栏的落表形式，构成约束·冻结）**——首发池必须同时含：
常见且大方 ≥1 · 稀有且少留 ≥1 · 特殊猫主价值在行为/信息/记忆 ·
不起眼但偶留好东西 ≥1 · 不稀有但难确认（Discovery 难）≥1。

**列结构（冻结）**：

`id / 名字 / 稀缺档 / Core 偏好（tag±强度）/ AVOID / 活跃窗 / 天气倾向 /
Eligibility 硬条件 / 留下风格（频度×量级×品类——独立列，与稀缺档无函数关系）/
Discovery 风格（停留×暴露）/ 行为签名 / 社会种子`

## 六、四线模拟规范（17 干跑 → 本表核心平衡测试，结构冻结）

**Harness**：200 虚拟用户 × 14 日 × 本表全参数；三种玩家模型 + 理论线：

| 线 | 策略 | v0 目标形状 |
| --- | --- | --- |
| Random | 每日随机换 0–1 件 | 基线 |
| Learning | 按观察更新标签信念，每日据信念调整 | RARE 目标达成速度 ≥1.5× Random；D14 确认数 ≥1.3× Random |
| Oracle | 全知本表，每窗最优布置 | RARE 单窗命中 ≤60%；14 日池覆盖 ≤85%——**全知也不能完全控制生命** |
| 100% | 理论上限 | 永不可达 |

判读（冻结）：`Random < Learning < Oracle < 100%`。
Oracle 逼近 100% → 扰动/隐藏维度不足，回炉；
Learning ≈ Random → 线索信息量不足（17 可学习性失败），回炉。

干跑同时产出各冻结篇审计报数：空窗率 / 回访-发现命中率（16）/
岛闻代偿占比（16）/ 稀缺档×留下期望相关系数 ≈ 0（19 正交）/
AVOID 违例 = 0（17）/ TRACE_ONLY 占比（Discovery 曲线）。
