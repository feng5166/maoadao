## 二、猫池首版（Cat Sheet）

**构成（v0）**：首发 **16 只** = COMMON 7 / UNCOMMON 4 / RARE 3 / VERY_RARE 1 / SPECIAL 1。
池源：既有 NPC 复用优先（社交/背景型入池；功能型驻点猫不入池或极低频），
不足由猫池生产线补——**名单与档案终审归 09（批次二）与创始人**。

**正交覆盖检查（硬约束·冻结）**——首发池必须同时含：
常见且大方 ≥1 · 稀有且少留 ≥1 · 特殊猫主价值在行为/信息/记忆 ·
不起眼但偶留好东西 ≥1 · 不稀有但难确认 ≥1 · **稀有但显眼 ≥1**
（traceBias 为负——来了就知道是谁）。

**列结构（冻结）**：

`id / 名字 / 稀缺档 / Core 偏好（tag±强度）/ AVOID / 活跃窗 / 天气倾向 /
Eligibility 硬条件 / 留下风格（独立列，与稀缺档无函数关系）/
Discovery 风格（停留 × DiscoveryModifier/traceBias——与稀缺档正交）/
Composition（独处/成对/无约束）/ 行为签名 / 社会种子`

## 四、Preference 合成初值（17 结构的数）

| 参数 | v0 初值 |
| --- | --- |
| 基础权重 | 1.0 |
| FAVOR 命中 | 每 tag +0.5～1.5（按强度） |
| AVOID | 弱冲突 ×0.1；**强冲突 = 0（硬 0）** |
| 熟悉度加项（Acquired） | 0～+0.5，封顶 |
| 同伴因子 | social：每在场猫 +0.3（封顶 +0.6）；quiet：每在场猫 ×0.5 |
| 同类标签堆叠 | 第 2 件 ×0.5，第 3 件 ×0.25 |
| 随机扰动 | 权重 ±20%；另 5% 域内惊喜采样（仅 NEUTRAL/LOW，永不触 AVOID） |
| Disclosure 判定 | 基础 TRACE_ONLY 20%；night+ +20%；停留<15min +25%；**每猫 traceBias ±30%（Cat Sheet 列）**；封顶 75%；白日久留/social −15%。**稀缺档不得进入本公式**（17 正交） |
| 机会累积（Opportunity Accumulation） | **数据语义 = Cat × Yard 的 eligible miss streak**：`CatOpportunityState{catId, yardId, consecutiveEligibleMisses}`——当【该猫 Eligibility=true ∧ 当前布置达最低有效匹配 ∧ 本窗未出现】时 +1，出现即清零；streak ≥6 起每窗倾向 +8%（隐性），封顶 +50%。**不依赖任何"用户目标"概念**——这是压随机长尾的系统公平机制，不是猜你在追谁（五禁沿 17） |

**Visit Composition Constraint（组合层，评审补入·随本表冻结）**：
决定"本窗最终结果如何组合"，**不参与候选资格判定**（Eligibility 之外的小层）：

- 每窗同现上限 2（§一 既有）；
- `solitary` 猫：入选则独占本窗（或已有他猫入选时权重坍缩 ×0.05）；
- 成对 / 互斥关系：结构预留（社会种子，批次二填）。

Eligibility 由世界侧裁决（活跃窗外=0；天气不符=0；硬条件全查）——
本表只登记硬条件参数，不定义其内部。

## 六、四线模拟规范（结构冻结）

**公式：World × Yard Rules × Player Behavior → Experience。**
Harness = 200 虚拟用户 × 14 日 × 本表全参数 × 以下两个 Profile：

**WorldScenarioProfile（v0）**

| 项 | 初值 |
| --- | --- |
| 天气日分布 | 晴 55% / 阴 25% / 雨 20%（雨→当日可出"雨停傍晚窗"） |
| 世界状态转移 | 猫的活跃窗/行程按 Cat Sheet；社会状态占位（批次二） |
| 特殊事件 | 无（MVP） |

**SessionProfile（v0）**

| 项 | 初值 |
| --- | --- |
| session/日 | 1 次 40% / 2–3 次 45% / ≥4 次 15% |
| 到访时刻分布 | 早 30% / 午后 25% / 晚 45% |
| 观察行为 | 已结算结果查看率 90%（开门即见）；LIVE 撞见由在场窗口派生 |
| 布置变更倾向 | 每 session 0–1 次；获得新信息后概率上调 |
| **知识约束** | **Learning 玩家只依据其 session 内实际观察到的结果更新信念**——不全知结果；三线共用同一 SessionProfile（只有知识不同），差异才可归因于学习 |

**判读（冻结）**：`Random < Learning < Oracle < 100%`。
Learning RARE 达成速度 ≥1.5× Random、Day 14 确认数 ≥1.3× Random；
Oracle RARE 单次合法机会命中 ≤60%、14 日池覆盖 ≤85%。
Oracle 逼近 100% → 扰动/隐藏维度不足，回炉；Learning ≈ Random → 线索信息量不足，回炉。

**Dashboard 输出结构（定稿）**——第一版干跑脚本不吐成功/失败，吐这张表：

| 块 | 指标 |
| --- | --- |
| Discovery | Day 1/3/7/14 确认猫数分布；影子→确认时长；首次 RARE（Eligible Opportunity 数 + Day 映射） |
| Learning | 三线差距；每只猫 eligible opportunity → hit 曲线 |
| Economy | 日收入；首次 Sink；第二/三件 Goodie 到达 Day；扩槽 Day |
| World quality | 空窗率；TRACE_ONLY 占比；AVOID 违例（须=0）；岛闻代偿率 |
| Collection health | 已确认猫后续新信息供给率；**Day 7 后仍有未知目标的用户比例**；**Day 7 后 discovery curve 是否塌陷** |
