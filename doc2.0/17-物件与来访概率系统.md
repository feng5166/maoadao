# doc2.0/17 物件与来访概率系统——可以学会，算不透

> 2026-08-07 立稿（2.1 玩法化·批次一第 4 篇；上游：16 v1 冻结、A01 建档）。
> 命题（创始人）：**在一次合法 Visit Window 内，当前这些布置为什么让 A 猫
> 比 B 猫更可能来；而用户怎样通过反复实验，逐渐学会这种规律。**
> 定性：本篇是数值心脏的**结构**——不写任何具体数字（全归 22）；
> 承接 A01 重点五条：#4 条件权（§一）、#5 物件是行为发生器（§二）、
> #6 稳定偏好（§二/§四）、#7 可研究概率（§四）、#16 稀缺来自条件组合（§三）。
>
> 架构守则（全批次适用）：院子循环负责驱动行为，世界模拟负责决定事实，
> AI 负责放大生命差异——永不为玩法概率跳过世界事实。

## 零、核心论点：设计目标是"可学习的不确定性"

> **玩家可以通过观察逐渐学会，但永远无法完全算透。**

两个失败态，各废掉一环：

- **纯 RNG**：怎么试都学不到东西 → 研究环死（A01 #7 禁栏）；
- **可算透**：攻略收敛成公式 → 全岛同款院子，Build 死（README 反最优解）。

概率哲学（方向性原则，不写死比例）：**规律是主体，随机负责惊喜。**
比例的校准归 22。

## 一、两级判定：Eligibility → Preference（冻结区分）

```
World legality（世界合法性）
   ↓
Eligible Cat Pool（合法候选池）
   ↓
Preference Weight（偏好倾向）
   ↓
Visit Result（进入 16 结算）
```

**第一级 Eligibility——它今天有没有理由来（世界的事）**：
时间是否匹配 / 天气是否匹配 / 猫当前 world state 是否允许（它在岛的哪里、
在忙什么）/ 社会状态是否允许 / 有无硬条件（SPECIAL 档）/ 地点是否合理。
产出 = **合法候选池**。

**裁决权归属**：Eligibility 的裁决者是**世界模拟**——输入全部是世界事实，
本篇只定义它的接口与红线，不定义它的内部。这正是 16"禁止独立院子抽卡器"
的概率侧落法：抽卡器 = 跳过 Eligibility、直接从全猫池按权重抽。

**第二级 Preference——合法候选里谁更可能来（本篇的全部）**：
Goodie 标签 × Slot 标签 × 猫偏好 × 熟悉度 × 当前其他猫 × 随机扰动 → 倾向。

两条边界红线：

- **0 就是 0**：Preference 权重再高，也永不能把 Eligibility 为否的猫拉进结果；
- **低不是无**：Eligibility 通过但倾向很低的猫，仍可能来（随机扰动）——
  这是惊喜的合法来源之一（#7"随机负责惊喜"的落点）。

## 二、偏好模型：三张标签表（#5 #6）

| 表 | 是什么 | 示例 |
| --- | --- | --- |
| CatPreference | 猫的**稳定长期偏好** | enclosed / warm / water / height / quiet / social / night / rain / playful …（词表归 22 维护） |
| ItemTag | 物件的性质标签 | 纸箱：enclosed+++ · quiet++ · soft+ · shelter++ |
| SlotTag | 位置的性质标签 | 遮蔽 / 日照 / 高低 / 离门远近 / 毗邻物 |

- **物件是行为发生器，不是加成道具**（#5 硬线）：标签同时决定三件事——
  (a) 谁更可能来（倾向面）(b) 来了做什么（行为池入口）(c) 留下什么痕迹。
  一个 Goodie 三重输出；把它简化成"猫 A +20%"即违反本篇；
- **偏好是性格的玩法投影**：与 05 七层对齐——偏好挂在性格/习惯层，
  **终生稳定、只允许刻痕级微变**（05 A 案约束沿用）。稳定是可学习的前提（#6）；
- **匹配是多维吻合，不是查表**：猫偏好 × 物件标签 × 位置标签三方合成
  （合成函数与权重域归 22）；同一物件放不同位置 = 不同实验（16 §二）；
- **熟悉度是独立加项**：猫对这个院子的历史关系（CatHomeAffinity，05 批次二定义）
  影响倾向——回头客机制，也是"了解一只猫"（18）与关系层（02）的概率侧接口；
- **同伴因子**：当前/近期在场的其他猫参与计算——social 猫倾向聚集、
  quiet 猫倾向避让。这是反最优解的核心冲突源（§五）。

## 三、稀缺性：苛刻的组合，不是低的概率（#16）

内部五档 COMMON / UNCOMMON / RARE / VERY_RARE / SPECIAL（README；
用户侧永远世界语言，04）。

**稀缺的三个合法来源**（可叠加）：

1. **Eligibility 窄**：只在特定时间/天气/世界状态下成为合法候选
   （"雨停后的傍晚"）；
2. **Preference 要求高**：需要多维匹配才有像样的倾向
   （特定物件 × 特定位置 × 院子安静）；
3. **暴露少**：Disclosure 更偏 TRACE_ONLY——它来过，但你难以确认（§六）。

**禁**：任何档位的稀缺仅由基础概率低实现——纯 RNG 稀有让玩家无事可做，
只能刷（A01 #7/#16 禁栏、README 总表）。

**苛刻必须可推理（公平红线）**：每个 RARE 及以上的条件组合，必须存在
**世界内线索路径**（岛闻的说法 / 别的猫的行为暗示 / 痕迹特征 / 未来兴趣组）——
**谜面必须发得出去**；不存在任何线索的隐藏条件 = 缺陷（玩家会把"苛刻"
体验成"任意"）。

软保底（长期满足条件而未出现的倾斜）**待议归 22** 校准——它是设计公平问题，
与 19"不卖缩短稀有等待"不冲突：保底永不成为商品。

## 四、可学习性设计（#7，本篇的产品灵魂）

学习的素材只有观察：行为即线索（16 §七）/ 痕迹 / 时间与天气的规律 /
岛猫册信息渐明（18）。

**学习曲线三原则**：

1. **能学**：每个偏好至少存在一条可观察的学习路径；
2. **一次学不完**：线索是碎片——单次行为可多解，必须重复验证。
   重复观察本身成为玩法（A01 #9/#10 的概率侧）；
3. **学了长期算数**：学会的规律必须长期成立——规律翻新 = 背叛玩家；
   偏好漂移只走 05 刻痕级尺度（跨月可感知，单次不可感知）。

**"算不透"的合法来源（白名单）**：随机扰动（惊喜项）/ 猫的当日状态
（世界事实：心情、在忙什么）/ 同伴动态 / 隐藏维度的存在
（玩家不知道标签全集）。

**"算不透"的非法来源（黑名单）**：规律本身抖动 / 为难玩家的伪随机 /
同条件下结果无规律翻转。

**玩家知识的形态**：攻略知识应长成**经验句**（"雨停后的傍晚它常来"），
永不长成**公式句**（"雨天 +45%"）——**系统永不吐出数字**，
用户侧无任何概率/权重/百分比展示（04/05 红线沿用）。

## 五、反最优解（README 承接）

**禁全局毕业阵容**：不允许存在一套长期支配所有其他配置的布置。

实现机制（定性清单，参数归 22）：

- **偏好冲突（主力）**：偏好空间必须存在结构性对立——quiet vs social、
  高台 vs 地面、空旷 vs 遮蔽；允许极端型（"只有纸箱不存在才来"的猫）；
- **同类标签堆叠不线性叠加**：三个水盆不等于三倍 water；
- **条件依赖世界**：时间/天气/季节让"当前最优"随世界漂移；
- **槽位有限**（16）：放了这个就放不下那个。

验收：任一固定配置的长期期望覆盖猫池，必须显著小于全池——
**"我现在想钓哪类猫"永远是活问题**（README 四类玩家的 Build 分化由此而来）。

## 六、Disclosure 判定（16 §五 的规则侧）

- visibility 判定同走标签逻辑（定性）：夜行 / 短停 / 胆小 / SPECIAL 档
  更偏 TRACE_ONLY；白日久留 / social 更偏 FULL_RECORD；
  LIVE 取决于用户在场（Observation 层，16）；
- **TRACE_ONLY 是研究素材，不是惩罚**：痕迹必须携带可推理信息
  （毛的颜色 / 爪印大小 / 吃剩的东西）——"它来过但你没见过"
  正是收集张力（A01 #14）；
- 比例与判定参数归 22；红线沿 16：不许用 TRACE_ONLY 掩盖没内容。

## 七、eval

- **可学习性干跑（本篇核心验收）**：模拟两种玩家各跑 N 窗口——
  "观察-调整"型策略玩家的目标命中率必须**显著高于**随机布置玩家（能学）；
  同时全知最优玩家的命中率必须**显著低于 100%**（算不透）。
  两条线的数值归 22，先报数；
- **稳定性抽检**：同猫同条件的长期倾向漂移超阈（22）= 缺陷（背叛已学规律）；
- **毕业阵容审计**：采样常见配置组合，存在覆盖度异常高的单一配置 → 报警回炉；
- **线索存在性审计**：每个 RARE+ 条件组合能指认至少一条世界内线索路径，
  指不出 = 缺陷；
- **纯 RNG 审计**：任一稀缺档的实现若仅是基础概率低 = 缺陷；
- **语言扫描**：用户侧出现概率数字/百分比/权重/掉率 = P0（04/05 沿用）。

## 合回清单

### 数据模型
CatPreference（猫侧稳定偏好，随猫档案）/ ItemTag / SlotTag 词表；
熟悉度接口预留（CatHomeAffinity，05 批次二定义）；
Eligibility 输入 = 世界事实（只读，不新建表）。
### Simulation
Eligibility 裁决在世界模拟侧（本篇定接口：时间/天气/world state/社会状态/
硬条件/地点合理性）；合法候选池产出接入 16 结算管线（快照口径沿 16）。
### Director
惊喜项（低倾向候选的偶发放行）属"导演调权重"合法域；
软保底待议（22 校准，永不商品化）。
### 数值
全部归 22：标签词表 / 权重域与合成函数 / 扰动幅度 / 堆叠衰减 /
各稀缺档苛刻度 / TRACE_ONLY 判定参数 / 干跑双线阈值。
### API / Action
无新动作；任何查询接口**禁止暴露倾向值**。
### Web / UI
无概率数字、无进度条；观察信息的呈现归 18（岛猫册）。
### 埋点
配置变更→结果 配对记录（学习曲线分析的原料）；稀有目标达成时长分布（报数）。
### 文案 / 美术 / 音频
行为线索的表达过 04——**经验句，永不公式句**；痕迹表达走 04 环境语言。
### 旧规则迁移
既有三轴（boldness/sociability/diligence）KEEP，MIGRATE→偏好标签的推导底座
（偏好 = 三轴 + 个体档案派生，规则归 09 批次二）；既有 `goal`
（earn/friends/explore/chill）KEEP，作 Eligibility 的世界侧输入之一。
### 验证指标
可学习性干跑双线（高于随机 / 低于全知）；D5 阶段达成率
（"规律研究"心流成立的证据，旗标归 20）；稀有目标平均实验窗口数（报数，目标归 22）。
