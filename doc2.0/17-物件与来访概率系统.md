## 零、核心论点：设计目标是"可学习的不确定性"

> **玩家可以通过观察逐渐学会，但永远无法完全算透。**

两个失败态，各废掉一环：**纯 RNG**（怎么试都学不到 → 研究环死）；
**可算透**（攻略收敛成公式 → 全岛同款院子，Build 死）。

概率哲学（方向性原则，不写死比例，校准归 22）：**规律是主体，随机负责惊喜。**

全系统七层结构（评审定稿）：

```
世界层   Eligibility      "它今天能不能来"
   ↓
玩法层   Preference       "它为什么更愿意来这里"
   ↓
随机层   Variation        "同样条件为什么不是每次一样"
   ↓
结果层   Visit            "这次到底来了谁"
   ↓
深度层   Stay / Behavior / Social / Leave Behind / Disclosure
                          "来了以后发生什么"
   ↓
认知层   玩家观察
   ↓
再次实验
```

用户长期学习的不是一张 Cat × Item 概率表，而是在建立一个心智模型：
**"我越来越懂这只猫，也越来越懂这个岛。"**——这是与纯《猫咪后院》的分界。

## 一、两级判定：Eligibility → Preference（冻结区分）

**第一级 Eligibility——它今天有没有理由来（世界的事）**：
时间 / 天气 / 猫当前 world state（在岛的哪里、在忙什么）/ 社会状态 /
硬条件（SPECIAL 档）/ 地点合理性。产出 = **合法候选池**。
裁决者是**世界模拟**——本篇只定接口与红线，不定内部。
这正是 16"禁止独立院子抽卡器"的概率侧落法。

**第二级 Preference——合法候选里谁更愿意来（本篇的全部）**：
Goodie 标签 × Slot 标签 × 猫偏好 × 熟悉度 × 当前其他猫 × 随机扰动 → 倾向。

Preference 内部三个语义区（评审修订，冻结）：

| 区 | 语义 | 结果 |
| --- | --- | --- |
| FAVOR | 它喜欢这样 | 权重高 |
| NEUTRAL / LOW | 无所谓 / 不太感兴趣 | 低但可能——惊喜的合法来源 |
| AVOID | **它自己不会选择这样做** | 某些组合下降到**事实上的 0** |

三条边界红线：

- **0 就是 0**：Preference 权重再高，也永不能把 Eligibility 为否的猫拉进结果；
- **低不是无**：NEUTRAL/LOW 的猫仍可能来（随机扰动）；
- **讨厌不是低**：AVOID 不是世界非法（它理论上能来），是它的选择。
  **随机扰动只能在猫愿意接受的行为域内制造惊喜，不能越过稳定厌恶
  制造反人格结果**——用户研究出"它极其怕水"，满院水系它却"惊喜"出现，
  玩家不会觉得惊喜，只会觉得规则是假的。

## 二、偏好模型：三张标签表 × 两层偏好（#5 #6）

| 表 | 是什么 | 示例 |
| --- | --- | --- |
| CatPreference | 猫的偏好（分两层，见下） | enclosed / warm / water / height / quiet / social / night / rain / playful …（词表归 22） |
| ItemTag | 物件的性质标签 | 纸箱：enclosed+++ · quiet++ · soft+ · shelter++ |
| SlotTag | 位置的性质标签 | 遮蔽 / 日照 / 高低 / 离门远近 / 毗邻物 |

**偏好分两层（评审修订，冻结）**：

- **Core Preference（核心偏好）**——稳定、可学习，本篇的主体：
  喜欢高处、怕水、偏安静、喜欢遮蔽、夜间活跃。
  终生稳定，只允许 05 刻痕级微变。**稳定是可学习的前提**（#6）；
- **Acquired Preference / Habit（习得偏好）**——因生活而改变，
  由 05/06 的生命经历产生：最近开始喜欢那个旧纸箱、被另一只猫带着
  开始去水盆、连续雨天后习惯待屋檐、对你院子的某个位置形成偏爱。
  **熟悉度（CatHomeAffinity，05 批次二定义）是习得层的院子维度。**

```
Visit Preference = 稳定核心偏好 + 长期形成的习惯 + 当下世界状态
```

用户学到"它喜欢高处"——长期可靠；后来发现"最近它好像特别喜欢
我院子这张旧垫子"——**习得层的变化是新发现，不是规则背叛**。
两层同时成立，才保得住"规则可学习"与"AI 负责让它活起来"互不压死。

其余原则：**物件是行为发生器，不是加成道具**（#5 硬线）——标签同时决定
(a) 谁更可能来 (b) 来了做什么（行为池入口）(c) 留下什么痕迹，
一个 Goodie 三重输出，简化成"猫 A +20%"即违反本篇；
匹配是多维吻合不是查表（合成函数归 22）；同物件不同位置 = 不同实验（16 §二）；
**同伴因子**：social 猫倾向聚集、quiet 猫倾向避让——反最优解的核心冲突源。

## 三、稀缺性：Visit Rarity——苛刻的组合，不是低的概率（#16）

**Visit Rarity 只回答一件事：这只猫多难来到你的院子。** 由两项决定：

1. **Eligibility 宽窄**：只在特定时间/天气/世界状态下成为合法候选；
2. **Preference 苛刻度**：需要多维匹配才有像样的倾向。

（"它来了以后多难被你确认"是另一个概念——**Discovery Difficulty**，§六。
两者独立组合出完全不同的猫：**猫 A 很稀有但一来就显眼**——很难碰见，
碰见一定知道是谁；**猫 B 不算稀有但很难确认**——常常只留下痕迹。
这是两种不同的收集体验，18 靠这个区分接住"来过 ≠ 已发现 ≠ 已解锁"。）

内部五档 COMMON~SPECIAL（README）；用户侧永远世界语言（04）。

**禁**：任何档位的稀缺仅由基础概率低实现——纯 RNG 稀有让玩家无事可做（A01 #7/#16）。

**苛刻必须可推理（公平红线，冻结）**：每个 RARE 及以上的条件组合，必须存在
**世界内线索路径**（岛闻的说法 / 别的猫的行为暗示 / 痕迹特征 / 未来兴趣组）——
**谜面必须发得出去**。不存在线索的隐藏条件 = 缺陷：那不是探索，是猜密码。
（未来 21 的兴趣组天然是谜面传播系统：一个人得到碎片，很多人共同总结。）

## 四、可学习性设计（#7，本篇的产品灵魂）

学习的素材只有观察：行为即线索（16 §七）/ 痕迹 / 时间与天气规律 /
岛猫册信息渐明（18）。

**学习曲线三原则**：

1. **能学**：每个核心偏好至少存在一条可观察的学习路径；
2. **一次学不完**：线索是碎片——单次行为可多解，必须重复验证；
   重复观察本身成为玩法（A01 #9/#10）；
3. **学了长期算数**：**核心偏好**学会后必须长期成立——规律翻新 = 背叛玩家；
   **习得偏好**的缓慢变化不算翻新——它是可观察的生活变化，
   读起来是"它变了"，不是"规则变了"。

**"算不透"的合法来源（白名单）**：行为域内的随机扰动（§一 红线约束）/
猫的当日状态（世界事实）/ 同伴动态 / 习得偏好的缓慢演化 /
隐藏维度的存在（玩家不知道标签全集）。

**非法来源（黑名单）**：核心规律抖动 / 为难玩家的伪随机 /
同条件下结果无规律翻转 / 越过 AVOID 的反人格结果。

**玩家知识的形态**：攻略知识长成**经验句**（"雨停后的傍晚它常来"），
永不长成**公式句**（"雨天 +45%"）——**系统永不吐出数字**，
用户侧无任何概率/权重/百分比展示（04/05 红线沿用）。

## 五、反最优解（冻结）

**禁全局毕业阵容**：不允许存在一套长期支配所有其他配置的布置。

机制（定性清单，参数归 22）：**偏好冲突（主力）**——quiet vs social、
高台 vs 地面、空旷 vs 遮蔽，允许极端型（"只有纸箱不存在才来"）；
**同类标签堆叠不线性叠加**（三个水盆 ≠ 三倍 water）；
**条件依赖世界**（最优解随时间/天气/季节漂移）；**槽位有限**（16）。

验收：任一固定配置的长期期望覆盖猫池必须显著小于全池——
**"我现在到底想要什么"永远是活问题**（Build 分化的来源）。

## 六、深度层：来了以后发生什么（五个概率面 + Discovery Difficulty）

**来访概率不是唯一概率（评审补入，18 的关键接口）：
同一只猫的概率条件不是一次性谜题。** 本篇定义五个概率面：

| 面 | 回答 | MVP |
| --- | --- | --- |
| 1 Visit | 来不来 | **完整实现** |
| 2 Stay | 待多久 | 部分实现 |
| 3 Behavior | 做什么 | 部分实现 |
| 4 Social | 和谁发生互动 | 概念预留 |
| 5 Leave Behind / Disclosure | 留什么、用户知道多少 | 概念预留 |

用户破解"它喜欢雨天+屋檐"只是第一层；此后还能研究：什么条件让它停得更久、
什么物件让它出现特殊行为、什么猫在场时它会一起出现、什么条件影响它留下什么、
哪些长期习惯逐渐形成。**已解锁的猫永不毕业**（A01 #9）——18 的可持续收集靠此成立。

**Discovery Difficulty（自 §三 移入，评审定稿）**：
"它来了以后多难被你确认/解锁"，由**停留时间 / Disclosure 倾向 /
痕迹可辨识度 / 出现时段**决定——与 Visit Rarity 独立正交。

- visibility 判定走标签逻辑（定性）：夜行/短停/胆小/SPECIAL 更偏 TRACE_ONLY；
  白日久留/social 更偏 FULL_RECORD；LIVE 取决于用户在场（Observation 层，16）；
- **TRACE_ONLY 是研究素材，不是惩罚**：痕迹必须携带可推理信息
  （毛色/爪印大小/吃剩的东西）——"它来过但你没见过"正是收集张力（A01 #14）；
- 比例与判定参数归 22；红线沿 16：不许用 TRACE_ONLY 掩盖没内容。

## 七、Director 边界：普通来访没有第二只手（评审修订，冻结）

**普通 Visit 全部由 Eligibility + Preference + 确定性随机产生。**
"低倾向的惊喜"天然来自 weighted sampling，**不需要也不允许** Director
额外"放行"——用户研究的是一套概率，后台不能还有一只手在修改答案，
否则"可以学会"即死。

Director 只允许介入三处，且**全部只在合法候选与合法偏好域内调整，
永不创造反规律结果**：

1. D1 欢迎结算（16，一次性）；
2. 机会累积（§八）；
3. 极少数明确立项的体验保护（逐项过评审，不开常例）。

## 八、机会累积（Opportunity Accumulation——不叫保底）

用户已经找对物件、位置、天气，连续很多合法窗口目标猫仍未出现——
纯随机的长尾会把"苛刻"变成"倒霉"。系统允许一个隐藏的**机会累积**：
连续满足条件而未命中时，倾向获得缓慢的隐性上浮，只为**压掉概率长尾**。

五禁（冻结）：**不可见**（用户侧零表述，世界语言里什么都不说）·
**不商品化**（与 19"不卖缩短等待"同盟）· **不承诺**（永不"再试两次必出"）·
**不越过 Eligibility** · **不破坏偏好**（AVOID 仍是 AVOID）。
参数与触发口径归 22。

## 九、eval

- **可学习性干跑（升为 22 核心平衡测试，冻结）**——四线形：
  **Random Player < Learning Player < Oracle Player < 100%**。
  学习必须有明显收益（Learning 显著高于 Random），但全知也不能完全控制生命
  （Oracle 显著低于 100%）。阈值归 22，先报数；
- **反人格抽检**：AVOID 猫在高冲突布置下的出现率应为事实上的 0——出现即缺陷；
- **Director 越权审计**（CI 级）：普通来访生成路径无 Director 写入；
- **稳定性抽检**：核心偏好长期漂移超阈（22）= 缺陷；
  习得偏好变化速率超出"生活尺度"（22）同样报警；
- **毕业阵容审计**：采样常见配置，存在覆盖度异常高的单一配置 → 报警回炉；
- **线索存在性审计**：每个 RARE+ 条件组合能指认至少一条世界内线索路径；
- **纯 RNG 审计**：任一稀缺档仅由基础概率低实现 = 缺陷；
- **语言扫描**：用户侧出现概率数字/百分比/权重/掉率 = P0。

## 合回清单

### 数据模型
CatPreference 两层存储（Core 随猫档案 / Acquired 由经历派生）；
ItemTag / SlotTag 词表；五个概率面的接口预留（Visit 完整，Stay/Behavior 部分，
Social/LeaveBehind 预留）；机会累积计数（隐藏态）。
### Simulation
Eligibility 裁决在世界模拟侧（接口：时间/天气/world state/社会状态/硬条件/地点）；
合法候选池接入 16 结算管线（快照口径沿 16）；习得偏好的写入路径走 05/06
生命经历（概率系统只读偏好，永不反写——箭头只朝一个方向）。
### Director
仅三处白名单（§七）：D1 欢迎结算 / 机会累积 / 立项级体验保护；
普通来访路径零介入（CI 审计）。
### 数值
全部归 22：标签词表 / 权重域与合成函数 / 三语义区阈值（含 AVOID 判定）/
扰动幅度 / 堆叠衰减 / 各档苛刻度 / Discovery Difficulty 参数 /
机会累积参数 / 习得偏好演化速率 / 干跑四线阈值。
### API / Action
无新动作；任何查询接口**禁止暴露倾向值与语义区**。
### Web / UI
无概率数字、无进度条；观察信息的呈现归 18（岛猫册）。
### 埋点
配置变更→结果 配对记录（学习曲线原料）；稀有目标达成时长分布；
机会累积触发频次（内部报表，验证长尾压制）。
### 文案 / 美术 / 音频
行为线索的表达过 04——**经验句，永不公式句**；痕迹表达走 04 环境语言。
### 旧规则迁移
既有三轴（boldness/sociability/diligence）KEEP，作 **Core Preference 推导底座**
（派生规则归 09 批次二）；既有 `goal` KEEP，作 Eligibility 世界侧输入；
既有习惯派生统计（doc/09 §六）KEEP，升级为 **Acquired Preference 的数据源**。
### 验证指标
干跑四线（§九，22 核心平衡测试）；D5 阶段达成率（旗标归 20）；
稀有目标平均实验窗口数（报数，目标归 22）；
反人格抽检零违例；解锁后深度面研究行为发生率（观察项，接 18）。
