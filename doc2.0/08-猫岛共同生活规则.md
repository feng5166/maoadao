# doc2.0/08 猫岛共同生活规则——两个岛民如何共享一个世界

> 2026-08-05 立稿。定性：**未来篇的宪法预写（P2 围栏），不是 MVP 文档，
> 也不是世界篇第九问**——先立原则，防止未来任何多人功能把猫岛变成双人游戏；
> 一切功能设计留待 P2。情侣只是第一个多人场景，本文回答的是一般问题：
>
> **两个岛民如何共享一个世界，而不把这个世界变成双人游戏。**
>
> 本篇刻意写短：只有宪法，没有方案。写完本篇，回执行篇（09/10）。

## 零、核心论点：共同生活是"一起看"，不是"一起玩"

- 双人游戏：共享控制、协作任务、共同进度；
- 猫岛共同生活：**两个人见证同一个生命，各自被它记得。**

前提（评审确认）：共同生活依赖**单人关系先成立**——两个和岛没有关系的人
一起进来，只是共享账号，不是共同生活。

## 一、五条宪法

1. **共享的是世界，不是控制台。** 07 第一原则按人独立生效：每个人的输入
   都只是一个事件；两个人的留言是两件事，**可能互相矛盾——由猫决定**
   （它可能谁都不听）。矛盾不是冲突，是生活：
   "你们俩说的不一样，它自己拿了主意。"——这是共同生活独有的内容金矿。
2. **它分得清你们。** 猫对每个人分别建立关系：各自的称呼、各自的记忆、
   各自的关系阶段（02/07 全套按人独立）。它知道你们是一起的（世界层事实），
   但**它不把你们当一个人**——共享账号不是共同生活。
3. **猫不做传声筒。** "告诉他我生气了"不可用——猫不是两个人的即时通讯工具
   （防 Chatbot 的双人版）。它可以在自己的生活里自然提到另一个人
   （"你们那位今天没来"），但**永不代传、永不站队**。
4. **隐私门按人生效。** 你对它说的话，默认另一个人看不见；共同可见的
   只有公共层（岛闻、日报、它的公开行为）。一个人的秘密不因共享而泄露——
   **这条在情侣场景是信任的生死线。**
5. **分开也温柔。** 一人离岛，另一人的岛不变；若共同生活解除，
   关系资产按人归属、共同记忆两份各存、岛民册照旧不撕页——
   "被爱过，而且自在"对人同样适用。

## 二、不做清单

双人任务 / 协作玩法 / 共同进度条 / 情侣排行 / 礼物互赠数值化 /
共享控制权 / 合并记忆 / 代传消息。

## 三、可以长出来的东西（仅记名，P2 再设计）

- **它对"你们"的观察**："你们说的不一样""你们那位"——三角关系的叙事红利；
- **岛民的话延伸到人对**："那两个总一起来的岛民"——03 社会化管线对人复用（待议）；
- **共同的第一次**：你们一起经历的岛上时刻，两份记忆各自保存。
