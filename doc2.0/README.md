## 目录

- **00-猫岛起源.md** —— 猫阿道与七仔：世界观起源正典、口径六红线、
  圣经 2.0 增补、用户身份、合回清单。**已冻结：世界观正典 v1**
  （含升格批注：「被爱过，而且自在」= 全体角色设计最高原则）
- **01-猫岛生活规则.md** —— 这个世界为什么每天值得看：一天的形状、
  关系如何长出来、岛的习俗（三提案全过）、居民公约、回访公式
  （已升格为内容验收标准）、§六「无用即有用」设计原则。
  **已冻结：生活规则 v1（v1.1 增补无用即有用）**
- **02-猫岛居民关系规则.md** —— 为什么舍不得走：关系三货币（升为底层数据模型，
  不做亲密度）、四段阶梯（状态非等级）、速度红线（加严：老朋友以数月计）、
  默契只演不解释、记忆物证化、用户"被记得"三层+二手认知总口径。
  **已冻结：关系规则 v1**（唯一未冻结项并称规则 → 03）
- **03-关系的社会化.md** —— 从"它们俩知道"到"岛上都知道"：社会化四段
  （目击→转述→公论，恒慢半拍 + 永不反推）、五层架构（事件流→个体记忆→关系→
  社会认知→岛屿文化，单向派生）、并称六条定稿（含单猫叫法）、传闻允许失真。
  **已冻结：社会化机制 v1**
- **04-猫岛语言系统.md** —— 岛上的话是怎么说的：生活语言第一原则
  （"能出现在任何 App 里的话不属于猫岛"）、五个声部（自述/旁白/岛民/日报体/
  **沉默**）、关系的叫法、猫的翻译（永不假装懂）、正负词典、
  猫岛语言图灵测试。**已冻结：语言系统 v1（文化防火墙）**——
  一切 Prompt/审核/文案的唯一语言依据

- **05-猫岛居民生命模型.md** —— 一只猫到底如何活着：活着=分层的变化
  （七层解剖 + 下解释上/上不动下）、两条总则（时间痕迹不是系统痕迹/
  只模拟经历不模拟应该成为谁）、性格 A 案（四约束，终生 ±10）、
  大情绪白名单三类、**"生命不会结束，关系只是暂时离开"**（六条规则 +
  用户四态 游客→岛民→离岛→归岛 + 回岛之事三形态 + 猫阿道镜像）、
  双胞胎测试。**已冻结：生命模型 v1**
- **06-猫岛事件与故事生成规则.md** —— 故事不是生成的，是被看见的：
  没有编剧只有目击者、事件三来源、故事四形状（替代起承转合）、
  反小剧本五红线（禁日更三幕/巧合限额/允许无下文/收束用生活/
  目击者不是作者）、三道门（事实/价值/语言）。讨论中
