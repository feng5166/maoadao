## 一、产品总模型（2.1 总架构）

```
Layer 1  院子游戏      放置 → 等待 → 来访 → 解锁 → 资源 → 新物件 → 新组合
                       （游戏性底盘：AI 全部关掉也成立）
Layer 2  猫岛社会      猫不是院子里的刷新物，而是岛上的居民——
                       猫与猫有关系、活动、兴趣、群体与社会事件
Layer 3  AI 生命世界   记忆、习惯、关系、事件、痕迹和长期变化——
                       让同样的收集玩法逐渐产生生命感
```

> **规则系统负责好玩，猫岛社会负责丰富，AI 负责让它们活起来。**
> （没有 L1 → 无聊；没有 L2 → 猫咪后院换皮；没有 L3 → 普通收集游戏。）

产品心智句：短循环 **「摆个东西，等等看谁会来。」**（D1 的灵魂）
长循环 **「见得越多，你越懂这个岛。」**

四环驱动：**探索**（还有什么猫会来）→ **研究**（怎样让它常来）→
**经济**（我要更好的条件）→ **收集**（我想把岛上的猫都遇见）。
用户成长 = **知识成长**（Mastery），永不做玩家等级。

## 二、MVP 总假设（12 重构时展开）

> **「摆下一样东西，等着看看会来谁」本身足够产生持续回访；
> 而猫的稀缺性、资源价值和可研究规律，能够进一步形成七日目标链。**

| 假设 | 内容 |
| --- | --- |
| H1 放置有效 | 用户理解放置会影响结果 |
| H2 未知有效 | 用户期待发现新猫 |
| H3 规律有效 | 用户愿意为某只目标猫调整配置 |
| H4 经济有效 | 资源能驱动下一件物件目标 |
| H5 收集有效 | 用户开始产生主动图鉴目标 |

## 三、术语裁定：Day 与 D0–D7（全卷统一，永不再混）

- **Day = 世界/现实时间**（worldDay、七日留存的"七日"都是它）；
- **D0–D7 = 体验心流阶段编号**（编号即编号，不是任何单词的缩写），与自然日**无对应关系**——
  有人 30 分钟走完 D0→D2，有人一周还停在 D5；
- **推进条件 = 事件完成 + 认知成立**，永不用 `worldDay == N` 触发。Director 侧用完成旗标：

```
first_item_placed + first_wait_completed + first_cat_visit_observed → D1_COMPLETE
observed_multiple_outcomes 或 changed_item_and_received_different_result → D2_COMPLETE
遇见未知猫 + collection_surface_seen + unresolved_cat_target_exists → D3_COMPLETE
```

旗标是"认知成立"的**代理条件**，本表只定结构；一切阈值与判定参数归 22——
**README 永不做数值规范**。完整旗标定义在 20。

- **七日留存仍然测**，但它属于 Analytics 时间窗口，不是 D7；
  Dx 反而成为漏斗分层——例如"达到 D5 的用户，Day7 留存是否显著高于只达到 D2 的"。

| 阶段 | 用户在回答 | 完成的认知（Aha） |
| --- | --- | --- |
| D0 进入世界 | 这里是什么？为什么值得留下？ | "原来这是一个会自己生活的猫岛，而我在这里有一个地方。" |
| D1 操作认知 | 我在这里能做什么？ | "我放的东西真的会影响谁来。" |
| D2 概率认知 | 是不是每次都一样？ | "我可以影响概率，但不能控制结果。" |
| D3 收集目标 | 猫与猫一样吗？ | "还有很多猫我没见过。" |
| D4 经济循环 | 来访还给我什么？ | "遇到猫，让我获得更多尝试的条件。" |
| D5 规律研究 | 怎样让它再来？ | "我好像摸到它的规律了。" |
| D6 社会认知 | 猫只存在于我的院子吗？ | "这些猫真的生活在同一个岛上。" |
| D7 自主目标 | 下一步做什么？ | "我自己知道下一步想干什么了。" |

D7 终态定义：**用户已经从"我该做什么"进入"我有很多自己想做的事"**——
产品不再需要继续教用户怎么玩，这才是新手阶段真正完成的标志。

D0/D1 边界拍板：**D0 = 认识猫岛（现结构不动，零玩法教学——不塞物件概率/稀缺性/资源循环）；
D1 = 第一次真正开始玩猫岛**（完整经历 放置→等待→猫来访→回来发现）。
D1 出口心智：**「我换个东西，下一次会来谁？」**

| **21 猫岛社会与兴趣组设计** | 第二阶段，但现在写框架防走样：猫社会（朋友/同行/避让/群体事件）→ 玩家研究社会（共享目击/配置/天气/规律猜测）→ 兴趣组=**共同观察板**（雨天猫研究会/纸箱协会），不是聊天群、不是好友系统；系统可总结趋势，**不公布底层概率公式**；（提案待议）世界猫单实例为事实层方向，但个人图鉴进度不被全局争抢决定 |
