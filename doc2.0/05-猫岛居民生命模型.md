## 零、核心论点：活着 = 分层的变化

生命感的来源不是"有很多状态"，是**不同的层以不同的速度变化**：

- 全部同速变 = 木偶（每天都像新角色）；
- 全部不变 = 雕像（三十天后一眼望穿）；
- **分层变化 = 生命**。

这也是既有速度规则的统一解释：02 的速度红线、03 的恒慢半拍、
doc/09 的声线一致性，都是同一件事——**每层只能被它自己尺度的事撼动**。

评审补入两条总则（与七层模型同级冻结）：

- **生命原则：猫的变化必须留下时间痕迹，而不是系统痕迹。**
  时间痕迹 = 习惯、旧物、岛民的说法；系统痕迹 = 数值、日志、面板。
- **模拟器原则：不模拟"猫应该成为谁"，只模拟"这只猫经历了什么"。**
  成为谁是经历的副产品——与 §六"个体是活出来的"同构。

## 一、生命的七层解剖（由快到慢）

| 层 | 变化尺度 | 是什么 | 机制现状 |
| --- | --- | --- | --- |
| 动作 | 分钟 | 此刻在做什么 | 三时段事件 + 此刻状态行〔已运转〕 |
| 情绪 | 天 | 心情的天气 | 摸摸它心情池、D5 情绪事件〔半已运转〕 |
| 欲望 | 天 | 今天想做的事 | Agent 意图（性格×状态×关系×记忆×留言）〔已运转〕 |
| 习惯 | 周 | 活出来的规律 | 地点/时段派生统计〔已运转，doc/09 §六〕 |
| 关系 | 月 | 02 的四段阶梯 | 〔已冻结〕 |
| 性格 | 季/年 | 三轴 + 口癖，地质层 | 恒定〔已运转〕；微刻痕〔§四 待拍板〕 |
| 身份 | 永不变 | 名字的来历、相遇的那天、"被爱过，而且自在" | D1 四资产〔已运转〕 |

两条层间规则：

1. **下解释上**：快层的变化由慢层解释——"它今天躲着人"（情绪）之所以可读，
   是因为"它一向不躲人"（性格）。没有慢层做底，快层只是噪声。
2. **上不动下**：一件小事改不了性格，一次留言改不了关系阶梯——
   越慢的层，撼动它需要的事件越重。

## 二、欲望：猫没有人生目标，只有今天想做的事

- `goal`（earn/friends/explore/chill，doc/21 由三轴推导）是**倾向，不是任务**；
- 意图永远小而具体：想要**那片羽毛**，不是想要"幸福"；想去**码头东头**，
  不是想"探索世界"；
- 禁：任何人生叙事——"它的梦想是开一家店"违反拟人化红线（doc/21）。
  猫可以连续三十天想着同一件小事（对小东西的执念是猫化判据），
  但它没有五年规划。

## 三、情绪：天气，不是仪表盘

1. **由事实引起**（事实先行）：情绪必须能指认出处事件；
2. **通过行为与语言被看见**：影响行为权重、日记语气、摸摸它的反应——
   **永不数值、永不图标、永不弹窗**；
3. **大情绪可过夜，小情绪日清**：日常小情绪不隔夜——猫记仇不过三天，
   记好可以记很久。**"大情绪"白名单（评审定义，防滥用）仅三类**：
   重要关系变化（02 阶梯变动/闹别扭）、重大失去（记忆物丢失/朋友离开）、
   长期事件收束（事件线落幕级）。白名单外一律日清（D5 式冲突属第一类，
   挽回空间照 doc/07）；
4. 旁白不解释情绪（04 沉默声部）；归因是岛民声部的特权；
5. **性格过滤环境**（评审补）：同一场雨，有的猫烦躁、有的猫爱听雨——
   环境不直接写情绪，**环境 × 性格才是情绪**（天气是输入，不是指令）。

## 四、性格：地质层（待拍板 ①）

三轴 + 口癖恒定是 IP 一致性的底座（doc/09 声线一致性，eval 已有跨天抽检）。
问题：性格要不要**完全**恒定？两案：

- **A 案（提案）：极慢的事件刻痕。** 只有稀有级大事件（10% 档）可在三轴上留下
  微小偏移；累计有上限（终生 ±10 以内）；**变化永不被宣布**，
  只能被岛民注意到（"它最近胆子大了点"——岛民声部特权，与 03 同构）。
  理由：一年后的老用户应该能说"它跟刚来的时候不一样了"，这是岁月的证据。
- **B 案：性格完全恒定。** 一切变化发生在习惯/关系层。
  理由：绝对防 OOC，IP 更稳（秃秃路线）。

**拍板（2026-08-05）：A 案通过。** 四条约束同时冻结：

1. **不宣布**——"勇敢度提升"类句式即 P0；
2. **不逆转**——胆小猫永不变社牛；刻痕只能让它"没那么怕"，不能让它换人格；
3. **不由单事件决定**——单次只留刻痕，性格变化是多次刻痕的累积；
4. **必须被观察到**——唯一出口是岛民声部："它最近好像没以前怕那个地方了。"

幅度红线照案：终生累计 ±10 以内，单次不可感知，跨月对比才可感知。

## 五、生命不会结束，关系只是暂时离开（岁月与离岛）

**拍板（2026-08-05）：猫不老，不死。** 写入"岛上永远不会发生的事"清单
（doc/24 §四，合回项）。引入死亡会让用户害怕投入、害怕回来、害怕失去——
与"慢生活观察"的产品核心冲突。

- 世界观依据（00）：现实世界太忙，猫阿道建了一座岛——
  **岛的时间对生命是温柔的**。不老不死不是回避，是这座岛存在的理由本身；
- **"不死"不代表"不变化"**：生命的厚度代替长度——岁月 = 第一次系列 +
  记忆物 + 关系史 + 收藏。"它来岛上多久了"的答案不是数字，是
  "它已经有一柜子东西、三个老朋友、和一整本生活册了"；
- 七仔永远在码头（doc/22 §十"它是这座岛的常量"）是这条规则的活证明。

### 离岛：离开的是人，不是猫（2026-08-05 评审两轮定稿）

旧口径作废：~~"你的猫可能被你送走（离岛流程）"~~（doc/22 §十·3，合回时修订）。
**离岛不是死亡机制，是用户与猫岛的关系机制**——现实里人会忙、会暂时离开，
猫岛不把这当失败，也不当惩罚。强行要求每天回来，反而违背猫岛理念：
**猫岛接受有些朋友会离开一段时间，但他们留下过的痕迹不会消失。**

六条规则（冻结核心）：

1. 猫不会死亡；
2. 猫不会因时间流逝消失；
3. 用户可以离开猫岛——**不是删除，不是暂停，是"暂时离开猫岛生活"**；
4. 离开不会删除关系和记忆：你的猫记得你、小屋保留、收藏保留、关系保留——
   但**世界继续**（它照常生活，低频背景态，海螺停发）；
5. 回岛需要重新建立一次连接（回岛之事，见下）；
6. 岛民册永远保留来过的痕迹——**存在过就是存在过**。

用户的身份层（七层模型的镜像——用户也有"永不变"的一层）：

```
游客 → 岛民 → 离岛 → 归岛
```

**岛民身份永不消失**：离岛改变的是当前关系的**活跃度**，不是**历史关系**。
"被记得"就是用户的身份层（02 §五）。

镜像结构（起源的完成时）：

```
猫阿道 离开猫岛 → 七仔守护记忆
用户   离开猫岛 → 猫岛保存记忆
```

**你走的是猫阿道走过的路；而岛对你做的，正是七仔对他做的。**

### 回岛之事：重新连接，不是解锁

归岛者不走新客序章（doc/21 §九·② 老用户不重放；岛还是那座岛，你不是新客）——
入口是**被认出**，不是被介绍：岛民册那一行还在，老章记得你哪天登的岛。
但生活不是按钮——**关系不能通过登录恢复，要通过一次连接恢复**。

回岛之事由归来者**主动求之**，岛从不派发（守"永不收到任务"红线）。
方向三种（详设待排期）：

1. **带回一个现实世界的故事**：告诉它你这段时间去了哪里（留言/海螺即载体）；
2. **帮猫岛做一件小事**：修一修旧公告栏、在某个地方留下一件新东西；
3. **回应过去留下的牵挂**：离开前它在找的那样东西——回来发现，它还在找。

完成后，一切都在：它的小屋、你的生活册、它对你的记忆，一页没少。

语言口径（已登记进 04 负面词典）：**永不说"存档/读档/恢复进度"**——那是游戏语言。
岛上的说法：**"岛上的生活仍在那里。""你的房间还在等你。"**

边缘情形：弃旧猫换新猫**不设计为正常路径**；若未来确有需求另议，
任何形态必须过"被爱过，而且自在"校验（落点参照第七行笔法，永不写成被抛弃）。

一句话（入定位语料池）：**猫岛不是一个需要你每天照顾的责任，
而是一个永远欢迎你回来的地方。** 现实里，人会离开。但总有一个地方——
你的猫还在那里，你留下的东西还在那里，你回来时，故事还能继续。

## 六、个体性：出厂差异小，活出来的差异大

创建时只有 27 组参数（doc/21），但个体性 =
三轴 × 出身（三条相遇路线）× 习惯史 × 关系史 × 收藏史 × 主人史——
**两只出厂相同的猫，三十天后不再是同一只猫。**

这与 02 的关系哲学同构：性格是设定的，**个体是活出来的**。
maoadao 的"千猫千面"不靠生成参数堆量，靠生活史分化。

eval 新增（本文最重要的验收）：**双胞胎测试**——干跑两只同参数的猫 30 天，
盲读双方日记与生活册，测试者能否稳定区分"这是两只不同的猫"。
区分不出 = 生活史分化失败 = 本文不成立。

## 十、2.1 玩法化接口：经历如何留在一只猫身上（2026-08-08 增量立稿）

> 命题（批次二拍板）：09 拆出 Immutable Birth Canon 之后，本章接手另一半——
> **哪些经历可以在猫身上留下长期变化，而且怎么变化仍然不像升级系统。**
> 本章只补 2.1 需要的接口，不重写生命哲学；一切承 §零 两总则
> （时间痕迹不是系统痕迹 / 只模拟经历不模拟应该成为谁）。

### 10.1 总结构（与 09 §一 对接，冻结）

```
Immutable Baseline                  → 09（永不 UPDATE）
        +
Life History（经历的事实层）
├─ Context Habit                    → 05/06
├─ Home History                     → 05
├─ Personality Imprint              → 05/06
└─ Relationship History             → 02/06
        +
Current World State                 → 01
        ↓
Derived Runtime State（运行时派生，永不写回）
├─ EffectivePreference
├─ EffectiveDisposition
└─ CatHomeAffinity
```

**刻痕是叠加，不是修改**——v1 §四 A 案四约束全部沿用，实现形态为
Baseline 之上的 overlay。收束句（冻结）：
**经历可以改变猫后来怎么生活，但不能修改它曾经是谁。**

### 10.2 LifeImprint 白名单（评审扩充：接住 17 习得层全量）

| 类 | 亚类 / 例 | 来源（事实先行） | 尺度 |
| --- | --- | --- | --- |
| **ContextHabit（情境习惯）** | item-specific（对那只旧水盆的例外：water −0.8 ⊕ old_basin +0.2）· slot/place-specific（对某个位置形成偏爱）· weather/time-specific（雨天躲某个屋檐的习惯）· companion/social-specific（跟另一只猫学会去水盆） | **反复发生的世界事实**——不能因为策划觉得"这样更有趣"就写进去 | 周–月 |
| **HomeHistory（院子历史）** | 它在这个院子真实生活过的一切：来过多少、待过多久、做过什么 | 来访事实史（永久，不衰减，见 10.3） | 累积 |
| **PersonalityImprint（性格刻痕）** | v1 §四 A 案：稀有大事件在三轴留微小偏移（终生 ±10） | 稀有级事件 | 季–年 |

这一版才真正接住 17 的公式：
`Visit Preference = Core Preference + Acquired Preference/Habit + Current World State`
——习得层的全部形态都有了归属，工程不必另找系统装习惯。

白名单外不刻。**每条 Imprint 挂 sourceEventIds**——指不出出处 = 数据造假。
刻痕是稀有的，数量与幅度上限归 22。

### 10.3 HomeHistory 与 FamiliarityActivation（评审拆分，冻结）

一个数值装不下两个概念（两年前常来、最近一年没来，affinity 算高算低？）——拆：

```
HomeHistory                永久事实：来过多少 / 待过 / 做过什么——不衰减
FamiliarityActivation      当前"这里还熟不熟"：从历史 + 近期经历派生——慢淡
CatHomeAffinity            = derived(HomeHistory, recency)
                           —— 派生缓存，不是正典事实源
```

规则句（冻结）：**记忆不消失，活跃熟悉感会变淡。**
"回来还认得"（历史在）与"很久不来就没那么自然"（激活淡）同时成立
——v1 §五 离岛哲学的院子版。

**防好感度化（冻结）**：affinity 只从"它来过并生活过"派生，
**永不由用户动作直接加分**——留言 +1 / 摸猫 +2 / 连续登录 +3 / 付费 +10
这类路径永远不存在。合法路径只有一条：
用户摆了东西 → 猫因此**合法地**来了 → 它**真的**在这里睡了一下午 →
这段生活事实进入 HomeHistory——**中间必须经过猫真实发生的生活**。

**防常客锁死三红线（评审补入，冻结）**——affinity 只能表达熟悉，
不能形成占坑优势，否则院子会从"下一只会是谁"退化成"又是棉花"：

1. **永不越过 Eligibility**（合法性与熟悉度分离）；
2. **永不抵消 AVOID**（熟悉不能治怕）；
3. **不得成为 Visit Preference 的主导项**——只在原本合理的候选之间轻微修饰
   （有界加项 0～+0.5 的语义就是"修饰"，22 落数守此界）。

配套审计（归 22，与"Day 7 后 discovery curve 塌陷"哨兵接轨）：
**随 Day 推进，常客 affinity 增长不得导致新猫 discovery rate 单调塌陷。**

### 10.4 append-only 与修正语义（评审明确，冻结）

> **生命经历只能继续发生，不能改写已经发生过的经历。**

- **禁止 UPDATE 老 Imprint**。修正 = 新事件产生新 Imprint：
  supersede（`Imprint B supersedes A, created by Event 305`）
  或反向 delta（`+0.2 old_basin` 之后 `−0.1 old_basin`）——
  Effective 聚合整条事件链；
- 规则 bug 也不许偷改过去的猫——发现错误走 supersede，历史照旧可重放；
- **调参改的是解释层，不是生命（冻结）**：RULES_VERSION 升级 =
  同一份历史事实 + 新解释规则 → 新 Effective，**永不批量 UPDATE LifeImprint**
  （漂移审计：调参提交前后 Imprint 表 diff = 0）；
- 与升级系统的分界：Imprint 无等级、无进度、无可见数值，
  唯一出口是**行为被观察到**——"最近它敢走近水盆了"。

### 10.5 eval（增量）

- **溯源审计**：任一 Imprint 指认出处事件，指不出 = 缺陷；
- **好感度化审计**：出现"用户动作 → affinity 直接映射"的代码路径 = 缺陷；
- **常客锁死审计**（22 哨兵接轨）：新猫 discovery rate 不因常客 affinity
  增长而单调塌陷；
- **不可变审计**（CI 级）：LifeImprint 无 UPDATE 路径（append-only）；
  调参提交前后 Imprint 表零变化；
- **双测并立**：09 北极星测"生而不同"，v1 双胞胎测试测"活出分化"——
  两个都过，生命才同时"独特"且"活着"。

### 10.6 合回清单（增量）

数据模型：`LifeImprint`（id / catId / kind / feature / delta / sourceEventIds /
createdAt / **supersedesImprintId?**，append-only，库层无 UPDATE 权限）；
