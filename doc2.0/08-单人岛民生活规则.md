## 零、核心论点：经营一个会被生活经过的院子

v1 第一句继承：岛民的生活没有"应该"。2.1 补上后半句：**没有"应该"，但有"想"。**

用户回来不是完成日课，是两件事的叠加：
**看我不在的时候发生了什么**（结果是世界给的）+ **决定下一次试什么**（下注是自己下的）。

一次有效使用 = 一个完整的小循环。30 秒是它的最小完整形态，
3 分钟是它的自然放大——**放大的是"看多深"，不是"义务多少"**。

## 一、日常主循环（七拍）

```
打开院子 → 发现结果 → 理解发生了什么 → 收下留下的东西
→ 判断自己的目标 → 调整布置 → 离开等待
```

| 拍 | 用户在做什么 | 世界提供什么 | 样例（过 04 词典） |
| --- | --- | --- | --- |
| 1 打开院子 | 第一眼回答三问：现在有谁？我不在时谁来过？下一步能做什么？ | 首页即院子画面；日记等长文字撤出首屏 | 一只猫正在纸箱边；垫子上有压痕 |
| 2 发现结果 | 扫一眼变化 | 此刻在场的猫 / 来过的痕迹 / 岛猫册新条目 / 留下的东西 | "水少了一点。地上多了颗小石子。" |
| 3 理解发生了什么 | 读来访记录（可跳过） | 世界语言的来访叙述；允许"只有痕迹、没有记录" | "下午来过一只没见过的，待了一会儿就走了。" |
| 4 收下留下的东西 | 发现并收下它留下的东西（小鱼干、纪念物）；观察信息入册 | 收下无时限、不腐烂、不催收 | "它留下了几条小鱼干。" |
| 5 判断自己的目标 | 想清楚现在想要什么（"不动"也是决定） | 只提供材料、不派目标：岛猫册的未知槽 / 可获得的新物件（获取方式归 19）/ 岛闻 | "那只灰的，还差雨天没试过。" |
| 6 调整布置 | 换物件、挪位置——为下一次实验下注 | 更换轻量；这是发生权的全部 | 把纸箱挪到屋檐下 |
| 7 离开等待 | 走人 | 世界继续（tick 不停）；离开时的钩子只有一个 | **"我换个东西，下一次会来谁？"** |

3/5/6 三拍可跳；1→2→4→7 构成最短路径。**任何一拍都不是义务**——没有红点逼你走完。

## 二、为什么 30 秒成立，3 分钟也成立

**30 秒版**（最短完整路径 1→2→4→7）：开门、看见结果、收下、带着一个悬念离开。
成立条件只有一条：**每次回访至少有一件可发现的事**——来了谁、剩了什么痕迹；
"今天没猫来"也合法，但必须可感知（看得出"没来"），不是空白。

**可发现 ≠ 必有来访**：发现物包括环境变化、旧痕迹的变化、物件状态、岛闻、猫来过——
结果节奏保障是内容供给约束，**永不许 Director 为凑节奏硬造来访**（约束在 16 展开）。

**3 分钟版**：在此之上读来访细节、翻岛猫册补观察、盘算资源与下一件物件、
调整布置、看看岛上。

**超过 5 分钟不是目标。** v1 时长健康继承：超长可能是负担或迷路。
多待是欢迎，不是设计追求——**长 Session 永不成为 KPI**。

两版之间没有身份差别：30 秒的用户不是"轻度用户"，这个循环本来就允许这么短。

## 三、等待的形状（一天与一段日子）

- 不规定每天几次、几点来。等待节奏（短/中/长三档，16 定义）让用户自然长出
  自己的查看习惯；
- **不在线，世界照跑**（三最高原则之"活着"）：回来看到的是累积的结果，
  不是补播的动画；
- **错过合法**：来访结束就只剩痕迹。错过不补发、不追偿、更不惋惜
  （"可惜你错过了"句式禁用）——**痕迹本身就是给你的那一份**；
- 海螺按你当前的目标捎信（绑 Home，README §八）：可以不点名
  （"刚才来了个没见过的家伙"），悬念即召回；永不催促。

## 四、岛民在忙什么：四种自然长出的"忙"

同一个循环，长出四种日常（README 四类玩家的生活形态；系统不认证类型，可自由混合）：

| 忙法 | 日常样子 | 主要动线 |
| --- | --- | --- |
| 收藏的忙 | 翻岛猫册数未知槽，为没见过的猫调布置 | 5→6（对未知下注） |
| 研究的忙 | 为某只猫总结规律：换时间看、换天气试、换物件比 | 3→5→6（做实验） |
| 经营的忙 | 攒小鱼干，盘算下一件物件、下一个槽位 | 4→5（攒与换） |
| 看日子的忙 | 就看猫。看它们做无用的事 | 1→2（观察本身即回报） |

第四种忙是 L3 的日常出口（README §九 待议提案"保留无用层"）：
猫来了除了结算，还会打哈欠、把你的东西挪歪、对着墙角发呆——
**院子不能每样东西都有数值目的，否则最终变成纯效率盘。**

## 五、节奏权利（v1 全文继承 + 2.1 增补）

- 缺席不责备；没有愧疚（"你 N 天没来了"永不出现）；来去自由；
  **你唯一"欠"岛的：什么都不欠**；
- 2.1 增补：**没有体力、没有签到、没有每日任务、没有过期**——
  等待不是对玩家的惩罚，**等待就是玩法本身**（"摆个东西，等等看谁会来"）；
- 好奇是唯一的召回力。任何一条变成推力（催促/倒计时/损失厌恶），
  按 P0 缺陷处理（继承 v1）。

## 七、eval（体验抽检）

- **义务扫描**（继承 v1 词表：必须/记得来/别忘了/每日）+ 2.1 增补：
  体力/签到/过期/补偿/惋惜句式，出现即缺陷（词表补入 04，批次三）；
- **30 秒完整性实测**：最短路径（1→2→4→7）实际可在 30 秒内走完，且"完整"——
  至少一件发现 + 离开时有下一次悬念；
- **循环盲读**：抽一次回访的埋点串起来读——像"一次经营决策"，
  还是像"清了一遍红点"？前者过，后者缺陷；
- 数值健康线（日均来访/资源节奏/回访分布）全部归 22，**本篇零数值**。

## 合回清单

### 数据模型
Yard / YardSlot / Placement（结构归 16 定义，本篇消费）；资源账户（19）；
观察记录（18）；CatVisit（16）——本篇只读它的结果面。
### Simulation
**来访必须是世界模拟中的合法事实，不能由独立"院子抽卡器"生成**（架构守则落点）。
实现形态不预设——location state / schedule / transition 皆可，守住事实一致性即可；
离线期间照常 tick。
### Director
D1 阶段首访保底（欢迎权重，"导演调权重"的合法用法，不碰稀缺层）；结果节奏保障：
每次回访至少一件可发现的事（"每天每猫至少一件值得看的小事"的玩法版）——
**可发现 ≠ 来访，不许硬造 CatVisit**（供给面与顺序在 16）。
### 数值
零。全部归 22。
### API / Action
三个动作：摆放 / 更换 / 收下；更换成本参数归 22；**冷却降为待议**——按钮 CD 会挡住
实验心流、伤发生权，限制实验频率优先由世界时间与来访结算窗口承担
（22 研究是否需要，本篇不默认存在）；刷新不重 roll（16 红线）。
### Web / UI
首页改为院子画面，第一眼三问；日记等长文字撤出首屏；岛猫册/物件/岛上降为次级入口；
30 秒路径的交互预算（点击数上限，实测校准）；「收下」按逐件发现呈现，
**不做一键收菜式批量结算**。
### 埋点
七拍各拍事件；session 时长分布（30 秒/3 分钟双峰观察）；
Dx 完成旗标的事件落点（旗标定义归 20）。
### 文案 / 美术 / 音频
痕迹的视觉表达（11 Home Yard 母场景分层）；来访叙述过 04 词典与声部；
环境语言（04 批次三增补）承担"只有痕迹、没有记录"的表达。
### 旧规则迁移
"我和我的猫的一天"主轴 DELETE；"一天三个时刻"（早/午后/晚）MIGRATE→等待节奏（16）；
"1-5 分钟注意力预算" MIGRATE→30 秒-3 分钟；五动作：物件命名 KEEP（归 18），
留一句话/二选一/摸摸它/看岛 待议（16/18/02）；节奏权利全文 KEEP；
eval 三项（义务扫描/时长健康/盲读）KEEP 并入 §七。
