## 零、核心论点：岛民的生活没有"应该"

岛民生活的第一特征：**没有必须做的事。** 没有日课、没有签到、没有进度。
你来，是因为想看看它；你不来，岛照常运转；回来，不被责备。

一天 1-5 分钟（doc/00 注意力预算）——多待是欢迎，不待是自由。
（"猫岛不是一个需要你每天照顾的责任，而是一个永远欢迎你回来的地方"——05。）

## 一、岛民的一天（三个可能的时刻，全部可跳过）

| 时刻 | 可能发生什么 | 出处 |
| --- | --- | --- |
| 早 | 海螺也许有一封信：它昨晚答应的事、你昨晚说的话有了回音；打开能看到它此刻在哪、在做什么 | doc/19 早晨档；此刻状态行 |
| 午后 | 下午的事浮现了——上午你看过的那一天，又长出了一段 | doc/14 时段解锁 |
| 晚 | 日记把一天收起来；海螺也许问你一个小问题；你可以留一句话——**明早它带着自己的决定回你** | doc/19 晚间档；三段兑现 |

随时可做：摸摸它、看岛。

一天的形状（回访公式的用户视角，01 §五）：
**确定的小满足**（它现在怎么样）+ **不确定的小惊喜**（今天它捡了什么）+
**未完成的小牵挂**（昨晚那句话，它今天怎么答）。

## 二、岛民的一周

- 岛有自己的周律：大退潮日全岛往海边去、某天日报休刊
  （"今天没有新闻。天气很好。"）、雨天全岛慢半拍——
  你只是**遇见**，不是参加（01 §三 习俗判据）；
- 它约每 3-5 天叼回一件东西；你可以给它起名字——名字从此在岛上流通（04 §五）；
- 第一周有自己的曲线（doc/07）：相遇 → 记住 → 意外 → 关系 → 冲突 → 兑现 → 纪念册。

## 三、岛民的一月与更久

- 你开始能说出它的习惯（"它最近总在下午去码头"）——习惯是活出来的，
  不是设定的（05）；
- 它和某只猫熟了；再过些日子，岛上开始有它们的叫法（"码头那两只"，03）；
- 你的猫第一次被岛上用一句话描述——**它有了自己的位置，
  而这个位置不是你给它的，是它自己活出来的**；
- 你的生活册越来越厚：第一次系列、记忆物、它记得的话。

**岛民的岁月和猫一样：不数天数，数第一次**（05）。

## 四、岛民的五种动作与三条留痕（07 §二 的生活视角）

五种动作：留一句话（今晚说，明早有回音）/ 二选一 / 摸摸它 / 看岛 / 给东西起名字。

三条留痕：对它说（私有，被记住）/ 留在岛上（公共，可能被七仔捡走）/
和它一起做一件东西（P3，还没开）。

全部遵守 07 第一原则：**你拥有发生权，没有结果权**——你能让事情发生，
结果永远属于生命。

## 五、岛民的位置（你在岛上有什么）

- 岛民册上你那一行（老章记得你哪天登的岛）；
- 你的猫的小屋——你在岛上的"家"，是它的门口；
- 你的生活册（共同记忆）、你留下的东西、你起的名字。

**这些都带不走，也不会丢**——离岛不删除，归来一页没少（05 六条规则）。

## 六、岛民的节奏权利（收拢，生活视角重述）

- **缺席不责备**：缺一天——"昨天你没来，它还是给你留了句话"；
  缺几天——回来它把最想说的一件先讲给你（doc/07）；
- **没有愧疚**：岛永不说"你 N 天没来了"（好奇不是愧疚，全域）；
- **来去自由**：游客 → 岛民 → 离岛 → 归岛，岛民身份永不消失（05）；
- **你唯一"欠"岛的：什么都不欠。**

## 七、eval（岛民生活抽检，本文新增）

- **义务扫描**：任何用户触点出现"必须 / 记得来 / 别忘了 / 每日"即缺陷
  （词表并入 04 负面词典的情感绑架系）；
- **时长健康**：日常回访时长中位数应落在 1-5 分钟——**超长不等于好**，
  可能是负担或迷路（与"无目的打开次数"埋点并读，doc/09 §九）；
- **30 天岛民日志盲读**：把一个岛民一个月的全部触点串起来读——
  像"一段生活"，还是像"一串功能使用记录"？这是本文的北极星。
