## 零、核心论点：生成的产出是"居民"，不是"掉落物"

同三轴的两只猫**不能是同一只猫**。个体差异必须在生成时就存在，
而不是靠 LLM 运行时表演出来——反面就是那条死路：

```
三轴 → 固定查表 → 所有内向猫都喜欢 quiet
```

查表制的世界还没开始就同质化了。本篇的全部机制都在回答一句话：
**分布给方向，采样给个体，身份给灵魂。**

## 一、最小正式档案（问题 ①：数据边界，冻结）

```
CatIdentity        id / name / appearance / origin / role
                   —— 世界正典，永不变
CatDisposition     boldness / sociability / diligence
                   —— 世界正典；仅 05 刻痕级微变（终生 ±10）
CorePreference     稳定标签倾向（favor±强度）/ AVOID / 活跃倾向（activity）
                   / Discovery 倾向（traceBias）
                   —— 生成时定，稳定可学习（17 的前提）
BehaviorSignature  签名行为（"总把东西摆整齐""先拍两下再叼"）
                   —— 生成时定，表达素材（入池过 10 池标尺）
SocialSeed         初始关系 / 兴趣 / 常走的路线
                   —— 生成时定，是 03/06 让社会"长出来"的种子
─────────────────────────────────────────────
Runtime state      情绪 / 习得偏好（Acquired）/ 熟悉度（CatHomeAffinity）
                   / 习惯 / 关系史 / 机会累积 …
                   —— 不属于 09 正典，由 01 / 05 / 06 持有
```

**可进入玩法池 = 前五块齐 + 通过 §四 检查。**
既有 NPC 已有 Identity / Disposition / bio——入池只需补
CorePreference / BehaviorSignature / SocialSeed 三块（按 §二 派生 + 人终审）。

## 二、派生链（问题 ②③：三轴 → 偏好，但不查表）

```
三轴 + 个体种子 + 世界身份/生活背景
        ↓
CorePreference + BehaviorSignature + SocialSeed
```

三步，顺序固定：

1. **三轴给分布，不给答案。** 三轴决定各偏好维度的**倾向分布**——
   低 sociability 让 quiet 的倾向概率升高、social 概率降低，
   但那是概率，不是判决；
2. **个体种子采样。** 每猫用确定性种子（catId 派生，与 16 同族：可复现）
   从分布中采样出**这只猫**的具体偏好组合、强度与 AVOID——
   同三轴的两只猫，采样结果就是不同；
3. **世界身份覆写（最强派生源）。** 档案里的既有事实一票覆写采样：
   盐汽水是灯塔管理员 → night/height 上调；斗斗"怕水却爱出海" →
   water 进 AVOID 而 origin 里有海——**矛盾即性格，正典优先于统计**。
   一句 bio 的信息量大于三个数值轴。

个体差异的四个来源（问题 ③ 的正面答案）：
采样种子（同轴不同猫）· 世界身份覆写（bio/role/怪癖）·
**AVOID 的个性化**（怕什么比爱什么更定义一只猫）·
Discovery 风格独立采样（traceBias 与稀缺档正交，17/22）。

两条反红线：

- **禁固定查表**：派生实现里出现"三轴区间 → 固定 tag 集合"的确定映射 = 缺陷；
- **禁运行时编造**：偏好是生成期正典，LLM 永不在叙事时临时发明
  "它其实喜欢水"（§四）。

## 三、首发 16 只怎么选（问题 ④）

**池源规则**（既有居民优先——这些猫已经在岛上活了很久，玩法池应该是
他们生活的延伸，不是一批新角色空投）：

- **社交型 / 背景型 NPC 优先入池**（棉花/汤圆/糯米/铃铛/橘子/冰粉/黑豆…）；
- **功能型驻点猫不入池或极低频路过**（老章在登记处、爆米花在报社、
  球球在杂货铺、馒头在早点摊——他们有职务，生活重心不在你院子；
  偶尔"路过"是彩蛋不是常客）；
- **剧情型看档案**（斗斗/盐汽水/老怪的生活方式适合做少见档）；
- **七仔不入池**（13 锁死：码头常量；玩法调用七仔的条件由玩法文档另门定义）；
- 不足者由猫池生产线补新猫（生成管线既有）。

**构成约束**（与 22 §二 正交覆盖检查同体，此处从生成侧冻结）：
稀缺档配比 7/4/3/1/1；六项正交组合各 ≥1（常见大方 / 稀有少留 /
特殊主价值在行为 / 不起眼偶好 / 难确认 / 稀有但显眼）。

**群像感检查（本篇新增，防"合格但不像一座岛"）**：16 只放在一起要像
**同一座岛的居民**——

- 偏好空间覆盖对立轴两侧（social 群与 quiet 群并存、白天猫与夜猫并存——
  17 反最优解的猫侧供给）；
- 活跃窗覆盖全天（深夜窗有主场猫）；
- SocialSeed 互相咬合（有朋友对、有互相避让的、有谁都不理的）——
  D6"这些猫生活在同一个岛上"的证据从这里来；
- **稀缺档看生活方式，不看戏份**：爆米花很重要但不入池；
  一只没名气的背景猫完全可以是 RARE——"来你院子的难度"
  与"角色重要度"是两回事。

**名单终审**：本篇冻结后，按上述规则产 16 只候选档案
（工程脚本派生 + 人逐只终审，10 红线"池子终审权在人"沿用），
填入 22 Cat Sheet 并替换 `POOL_V0`。

## 四、字段纪律（问题 ⑤：正典 / 演化 / 禁编，冻结）

| 类 | 内容 | 规则 |
| --- | --- | --- |
| **世界正典** | Identity 全部；Disposition（刻痕外）；CorePreference；BehaviorSignature；SocialSeed；**谜** | 永不变；**谜在档案里也是谜**（承 13 档案纪律）——origin 写"没人知道"就是没人知道，内部不写答案，写了总有一天从 LLM 嘴里漏出去 |
| **允许演化** | 习得偏好 / 习惯 / 熟悉度 / 关系史 / 刻痕 | 由 01/05/06 按各自尺度持有与改写；Core 偏好只接受 05 刻痕级微变 |
| **绝不许 LLM 编造** | 偏好、AVOID、签名行为、社会关系、任何档案字段 | 叙事层只能**引用**档案与事实（06 目击者原则的生成侧）；LLM 可生成的只有**表达** |

## 五、eval

- **同质化抽检（本篇北极星）**：干跑生成若干同三轴的猫，偏好向量两两距离
  必须显著大于零——距离 ≈ 0 = 查表制复活（报数与阈值归 22 干跑）；
- **查表审计**（实现级）：派生器代码里出现三轴→tag 的确定映射 = 缺陷；
- **正典泄漏抽检**：谜被任何产出（档案/叙事/册子）写出答案 = P0；
- **群像终审**：16 只并排盲读——"像同一座岛的居民"，
  还是"一批填表角色"（定性，人判）；
- **正交构成检查**：沿 22 §九 自查清单。
