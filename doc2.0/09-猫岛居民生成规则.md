## 零、核心论点：生成的产出是"居民"，不是"掉落物"

同三轴的两只猫**不能是同一只猫**。个体差异必须在生成时就存在，
而不是靠 LLM 运行时表演——反面就是那条死路：

```
三轴 → 固定查表 → 所有内向猫都喜欢 quiet
```

总纲句（冻结）：**分布给方向，采样给个体，身份给灵魂。**

## 一、数据边界：Birth Canon 与 Life State（问题 ①，冻结）

```
Immutable Birth Canon —— 09 的唯一产出，落库后永不 UPDATE
├─ CatIdentity             id / name / appearance / origin / role
├─ DispositionBaseline     boldness / sociability / diligence
├─ CorePreferenceBaseline  favor（tag±强度）/ AVOID
├─ LifePatternSeed         活动倾向 / 路线倾向 / 天气倾向
│                          （01 结合当前世界状态生成真实行程——
│                           09 定"它通常是什么样"，01 定"它今天实际在干什么"）
├─ DiscoveryTrait          停留倾向 / traceBias
│                          （17 Disclosure 专用；与稀缺档正交，永不混回"猫属性权重"）
├─ BehaviorSignature       签名行为（表达素材，入池过 10 池标尺）
└─ SocialSeed              初始关系 / 兴趣 / 常走路线
                           （Seed 二字是边界：冻结的是**初始社会条件**，
                            当前关系图归 05/06 演化）
        ↓ 世界运行
Mutable Life State —— 09 无权持有
├─ CurrentState                    → 01
├─ AcquiredPreference / Habit      → 05（LifeImprint）
├─ CatHomeAffinity                 → 05
├─ RelationshipHistory             → 05 / 06
└─ Trace / Event history           → 06
```

**Effective = Baseline ⊕ LifeImprint（运行时派生，永不写回）。**
生命经历不是修改出生档案，而是在它上面留下刻痕：

```
CorePreferenceBaseline:  water = -0.8        （出生：怕水）
LifeImprint:             old_water_basin_affinity = +0.2
Effective:               总体仍怕水，但对你院里那只旧水盆形成了例外习惯
```

这正是"Core 可学习、Acquired 的变化是新发现而不是规则背叛"（17）的数据形态，
也让历史重放天然成立。铁律（冻结）：

> **09 只拥有 Baseline；05/06 永远不得直接 UPDATE Baseline。**

一句话分工（冻结）：**09 决定"它出生时是谁"；01/05/06 决定"它后来活成了什么样"。**

## 二、派生链（问题 ②③：三轴 → 档案，但不查表）

```
三轴 + 个体种子 + 世界身份/生活背景
        ↓
CorePreferenceBaseline + LifePatternSeed + DiscoveryTrait
+ BehaviorSignature + SocialSeed
```

三步，顺序固定：

1. **三轴给分布，不给答案（冻结）。** 三轴决定各维度的**倾向分布**——
   低 sociability 让 quiet 概率升高，但那是概率，不是判决；
2. **个体种子采样。** 每猫确定性种子（catId 派生，可复现）从分布中采样出
   这只猫的具体组合与强度——同三轴的两只猫，采样结果就是不同；
3. **世界身份覆写（最强派生源）——但必须是有正典依据的 constraint/exception，
   不是策划随手改。** 每条 override 落审计记录：

   ```
   override:
     feature: water
     value: AVOID
     source: canon.bio
     reason: "怕水却每天跟船出海"
   ```

   source 只认正典（canon.bio / canon.role / canon.quirk）；
   **无 source 的 override 不合法**（审计面）。矛盾即性格——
   "怕水却爱出海"比完美一致的人设更像生命，但矛盾要有出处。

个体差异的四个来源（问题 ③）：采样种子 · 有据覆写 ·
**AVOID 的个性化**（怕什么比爱什么更定义一只猫）·
DiscoveryTrait 独立采样（与稀缺正交）。

反红线两条：**禁固定查表**（实现里出现三轴区间→固定 tag 集合的确定映射=缺陷）；
**禁运行时编造**（档案是生成期正典，LLM 叙事时永不发明"它其实喜欢水"）。

## 三、首发 16 只怎么选（问题 ④）

**池源规则**（既有居民优先——玩法池是他们生活的延伸，不是新角色空投）：

- 社交型 / 背景型 NPC 优先入池（棉花/汤圆/糯米/铃铛/橘子/冰粉/黑豆…）；
- 功能型驻点猫不入池或极低频路过（老章/爆米花/球球/馒头——有职务，
  生活重心不在你院子；偶尔路过是彩蛋不是常客）；
- 剧情型看档案（斗斗/盐汽水/老怪适合少见档）；
- **七仔不入池**（13 锁死；玩法调用七仔另门定义）；
- 不足者由猫池生产线补新猫。

**构成约束**：稀缺档配比 7/4/3/1/1；22 §二 六项正交组合各 ≥1。

**群像感检查**：16 只放在一起要像**同一座岛的居民**——偏好空间覆盖对立轴两侧；
活跃窗覆盖全天（深夜有主场猫）；SocialSeed 互相咬合（有朋友对、有互相避让、
有谁都不理的）——D6"它们生活在同一个岛上"的证据从生成期埋好。

**稀缺档看生活方式，不看戏份（冻结）**：爆米花很重要但不入池；
一只没名气的背景猫完全可以是 RARE——"来你院子的难度"与"角色重要度"是两回事。
这条防的是内容团队日后自然把重要 NPC 全塞进高稀缺档。

**名单终审**：本篇冻结后，工程脚本按 §二 派生 16 只候选档案，
人逐只终审（10 红线"池子终审权在人"），填入 22 Cat Sheet 并替换 `POOL_V0`。

## 四、字段纪律（问题 ⑤：正典 / 演化 / 禁编 + 谜的两类，冻结）

**谜分两类（评审修订——防泄漏靠信息权限，不靠删除正典）：**

| 类 | 定义 | 处置 |
| --- | --- | --- |
| **OpenMystery** | 世界中本来就没有确定答案 | 永不强行解释；档案就写"没人知道" |
| **SealedCanon** | 世界有确定真相，用户未知 | 真相存在但**物理隔离**：普通 LLM / Director 的任何 narration context 默认不可读取；只有满足明确世界事件才解封 |

> **不知道，不等于不存在真相。** 用删除世界事实解决权限问题，
> 未来揭晓时只能靠 LLM 临时编答案——那才真正违反唯一事实源。

实现（先物理拆表，权限系统后置）：`CatProfile`（narration 可读）/
`SealedCatCanon`（默认任何叙事上下文不读取）。
既有正典谜的归类：13/00 的谜（短尾、猫阿道去向、第七行）全部属于
**OpenMystery**（正典红线"永不解答"），不迁入 SealedCanon——13 锁死不动。

三级纪律：

| 类 | 内容 | 规则 |
| --- | --- | --- |
| 世界正典 | Birth Canon 全部 + 两类谜 | 永不 UPDATE；SealedCanon 靠隔离防漏 |
| 允许演化 | LifeImprint / 习惯 / 熟悉度 / 关系史 / 刻痕 | 01/05/06 持有，叠加不覆写（§一 铁律） |
| 绝不许 LLM 编造 | 任何档案字段与 SealedCanon 内容 | 叙事只**引用**档案与事实；LLM 可生成的只有表达 |

## 五、eval（评审升级：两层验收）

- **数值层**：同三轴猫在 Preference / AVOID / LifePattern / Discovery
  四块的组合达到**最小有效距离**（阈值归 22）——quiet 0.61 vs 0.63
  这种"统计不同、体验同质"不算过；
- **行为层（北极星，冻结）**：同一套标准院子条件干跑 14 日——
  **遮住名字和立绘，只看来访/行为记录，能否判断这是两只不同的猫。**
  判据是玩家能形成两句不同的经验：
  "它喜欢夜里钻箱子" vs "它雨后总去高处"。
  （这是 05 v1"双胞胎测试"的生成侧对偶：那边测"活出分化"，
  这边测"生而不同"——两测并立，缺一不可；）
- **查表审计**（实现级）：三轴→tag 确定映射 = 缺陷；
- **覆写审计**：无 source 的 override = 缺陷；
- **SealedCanon 隔离审计**：任何 narration context 的输入集出现
  SealedCanon 字段 = P0；
- **群像终审**：16 只并排盲读（定性，人判）。
