## 零、核心论点：可信不靠精致，靠痕迹

AI 内容的破绽从来不是画得不好，是**太干净**——没有磨损、没有累积、没有时间。

生活痕迹 = 时间在物上留下的证据。这是 05 生命原则的视觉版：
**变化必须留下时间痕迹，而不是系统痕迹**——美术同理，
世界要有**被生活过的样子**。猫阿道的岛是一座旧岛（00），新的反而假。

## 二、生活痕迹层（本文核心新增）

痕迹三类：

1. **累积**——小屋的东西慢慢变多、收藏排成一排、门口的物件：
   "内容回写世界"（10 原则）的视觉出口。三个月后贝壳还在，旁边多了颗松果；
2. **磨损**——旧牌子褪色、木箱磨圆的边角、被踩熟的小路：
   世界有年龄。岛民册第七行的划痕、猫阿道小屋的锁——旧物是起源的沉默证词；
3. **摆放**——东西有"被用过"的位置：贝壳不在正中间，歪一点；
   它总把东西放在同一个角落（10 §六"行为重复是生命感"的视觉版——**习惯可见**）。

判据（"无用即有用"删除判据的视觉版）：
**删掉这个痕迹，画面是否变得更"干净"了？是——痕迹就是对的。**

红线：痕迹必须可溯源（角色/世界/关系，01 §六）——
贝壳在那里是因为它捡过；**不做贴图式做旧**（无来历的脏=装饰，删）。

**边界（评审补入）：痕迹 ≠ 脏。** 猫岛不是破旧、不是废墟、不是垃圾堆——
是**被爱惜使用过**：旧木桌、磨亮的扶手、被整理过的收藏。
关键词：**不是衰败，是岁月。**

**痕迹一问（评审补入，冻结）：所有痕迹必须回答——谁留下的，为什么留下。**
答不出的痕迹，删。

## 三、外貌：一眼认出的差异

- 立绘一次定稿 + 差分复用（doc/00 §十三）；七仔锁母版派生（doc/22）；
- **剪影识别**是角色外形的第一判据（七仔=短尾+半张黑脸+嘴里叼着东西）；
- 你的猫：firstSight → 外观 → 姿势集（管线已自动化）；
- 个体差异靠**轮廓与花色**，不靠配饰堆砌——商业化外观（07 §五 左栏）同守此线：
  买的是表达，不是识别度的通胀。

## 四、声音：岛上只有猫和风

- 无人声铁律不重复（doc/17）；人走了，岛上只剩猫的声音（00 §四·2 的互证）；
- 每只猫的第一声必须可辨识（doc/21 拍 4 声音身份）；
- **环境永远大于表达**（评审冻结）：大部分时间是海浪、风、树叶、脚步；
  偶尔才是猫叫——**猫一直叫，它就不是生命，是提示音**；
- **声音的沉默**：大部分时刻没有声音——声音稀有才被听见
  （休刊日/稀有稀释原则的听觉版）。环境声是底，猫叫是事件，不是背景音乐；
- **系统声音清零**（评审冻结）：叮、任务完成音、奖励音、成就音、红点提示音、
  BGM 循环——那些是 App 的声音，不是猫岛的。

## 五、触感：交互的手感

- 摸摸它：反应有延迟、有性格、会腻（不是按钮响应——结果属于生命，07）；
- 微动：呼吸、耳朵、尾巴尖——存在感，不是表演（doc/16）；
- 纸张物理隐喻：翻页、票根、印章、手写体——岛民册落笔（09）必须是**手写体**；
- 禁：弹窗动效、庆祝粒子、进度动画、骨架屏闪烁——**系统痕迹**。

判据：**反馈来自世界（它动了），不来自界面（UI 闪了）。**

## 六、镜头规则（评审补入——观看方式也是感知层）

**镜头不是寻找玩家，而是观察生命。**

- ❌ 猫望向屏幕打招呼、镜头转向强调"看这里"——那是演员看镜头；
- ✓ 镜头停在那里，猫刚好经过——**世界不知道有观众**
  （doc/25"镜头跟着它，不是它带着你"的全域化）；
- 精细化：猫可以发现**你**（你是岛民，存在于世界内——doc/21 拍 3 的遭遇
  是相遇，不是表演），但永不表演给**屏幕**看；
- 镜头永不催促：不自动聚焦"重点"、不缩放强调、不加引导箭头——
  什么值得被看见由导演选材（06），**怎么看由用户自己的眼睛决定**。

## 十二、2.1 玩法化接口：Home Yard 母场景七层（2026-08-08 增量立稿，待评审）

> 命题（创始人点题）：已经跑起来的 Yard 世界，如何在一个**固定母场景**里
> 让用户一眼看见"现在、发生过什么、我能做什么"——同时仍然像生活，
> 不像 UI 面板。只回答五个问题，范围压死在七层。

### 12.1 七层解剖：Static Canon / Dynamic World Facts / Presentation（问题 ①，评审修订①②，冻结）

```
Static Canon（静态世界正典——不随 Window 变化）
└─ Base          房屋 / 树 / 门口 / 三槽位的空间关系：世界的"这里"本身也是正典，
                 构图与视角永不换

Dynamic World Facts（动态世界事实——画面与世界 1:1）
├─ Weather       世界天气史：同一院子的光与湿度，不是换背景图
├─ Time          窗口时段：光线方向 / 影长 / 色温：同一院子的一天
├─ Object        Placement 快照：摆着什么、在哪个位置
├─ Trace         ActiveTrace：此刻还看得到的痕迹（消退归 06 生命周期管）
└─ Cat           CatVisit 浮现纪律：此刻在场才画；世界说不在，就不许画

Presentation Derivatives（表现派生）
└─ MicroMotion   可以由事实驱动，但绝不新增事实
```

> **表现层可以读取事实来表现它，但不能凭表现新增事实。**

- Cat 在场 → 可以呼吸、甩尾巴（事实驱动的表现，✓）；
- 下雨 → 草叶可以有风雨反馈（✓）；
- Cat 不在 → **绝不能凭 MicroMotion 造一道猫影**（✗ 伪造事实，P0）。

**同状态同语义画面（评审修订②，冻结）：**

> **同一 YardView 必须得到相同的事实语义与视觉层级；
> 无事实意义的动画相位允许变化。**

同样的猫、同样的物件、同样的痕迹、同样的注意力中心、同样的天气/时段语义
——这些必须确定；光斑挪几像素、树叶摇摆相位、呼吸动画在第几帧、水面波纹
——这些不要求逐像素一致。**工程 CI 测 semantic render tree，不测截图像素。**

覆盖红线照旧：表现不得遮蔽事实（微动不遮痕迹，装饰不压猫）；
事实层之间按 12.2 注意力秩序让位，不互相覆盖信息。

### 12.2 注意力秩序：一屏一个注意力中心（问题 ②，评审修订③，冻结）

> **一屏只有一个注意力中心，不要求只有一个主体。
> 事实决定注意力中心；表现负责让这个中心被看见。**

```
单猫强事实        → 这只猫
双猫发生互动      → 这组互动本身（挤一个垫子 / 互相闻 / 一个躲另一个——
                    最有生命感的画面恰恰是"它们之间正在发生的关系"，
                    强挑一只主角 = 把 Social Fact 降格成背景）
无互动的两只猫    → 强行为猫为中心（正在用物件的 > 路过的），其余退底
无猫有痕          → 痕迹与留物（"有谁来过"是院子最重的悬念）
无猫无痕          → 院子本身（布置 × 天气 × 时间）——安静合法，不找补
```

- 注意力中心由事实决定，不由运营决定；
- "刚摆下"（placedThisWindow）属于 Object 层的轻微强调（环境语言），
  永不盖过猫与痕迹；
- 禁一切"所有信息一起抢注意力"的排版——这是 12.5 面板化的前兆。

### 12.3 时间与天气：改变同一院子，不是换一张图（问题 ③，冻结候选）

- **Base 永不换**，变的是：光（色温/影子的方向与长度）、湿度（雨的水洼 /
  湿了的石板 / 雨后反光）、以及**事实层自己的变化**（雨天猫躲屋檐下——
  那是行程与偏好在变，不是美术在演）；
- 禁"四时段四张背景轮播"感——验收标准：
  **用户能认出"还是我的院子，只是天暗了 / 下雨了"**；
- 水洼、被雨打湿的垫子属于**环境类 Trace**（06 §九 白名单：天气作用于物件）
  ——走事实层，不走贴图装饰；
- 实现形态自由（整图时段变体 / 分层滤镜 / 混合，归实施与 doc/15 管线），
  语义唯一：**时间天气改变的是同一个地方**。

### 12.4 MicroMotion：世界没停，但不撒谎（问题 ④，冻结候选）

- 职责：提供"世界没停"的存在感——猫的呼吸/耳朵/尾巴尖（在场时）、
  风吹草叶、光斑缓移、檐下影子随时间挪动；
- **红线：微动永不成为假事件**——不暗示"有事发生"、不指向可点击、
  不新增视觉钩子；猫不在场时，微动不得伪装猫的存在
  （草丛里晃过一道影子 = 伪造世界事实，P0）；
- 幅度守 doc/16：**呼吸可见但不表演**；微动是底噪，不是内容。

### 12.5 首屏信息密度红线：Yard 不是手游大厅（问题 ⑤，冻结候选）

> **Yard 是院子，不是仪表盘。一切 UI 都是"你在院子里做事的手"，
> 不是"系统发给你的面板"。**

- **禁**：卡片墙、任务面板、红点、常驻资源 HUD 角标、进度条、倒计时、
  签到入口、轮播 banner——出现任何一个，Yard 就退化成手游大厅（A01 禁栏）；
- **空院子必须真的允许空（评审补入，冻结）**：无猫无痕时，不得用 CTA、
  推荐位、每日提示去填视觉真空——**安静本身就是第三种有效首屏状态**
  （12.2 注意力秩序的末位不是缺省，是设计）；
- 信息进画面的方式：**状态即画面**（摆着什么，画里就摆着什么；
  痕迹就画在它发生的地方）；记录与翻旧账走**纸张动作**（翻册/翻记录，
  既有纸张隐喻）；数字只在动作现场以世界语言出现
  （收下时知道收了几条；小鱼干在"手边"，不在屏幕角落常驻）；
- 动作入口贴着对象走：摆放贴着槽位、收下贴着留物、翻册贴着门口——
  **能做什么由画面里的东西告诉你，不由按钮清单告诉你**；
- 现有临时页（文本列表）定性为**功能脚手架**：翻转时被母场景整体替换，
  动作语义（摆放/收下/翻册/换货）原样保留。

### 12.6 渲染管线与 CI 口径（评审修订④，冻结）

"渲染输入 ⊆ YardView"不严格成立——Renderer 还要读 Base 资产、
sprite 映射、动画配置、排版与 presentation tokens。真正要限制的是
**动态世界语义的唯一来源**。工程形态冻结为：

```
YardView              // 唯一动态事实输入
        +
YardVisualConfig      // 纯表现配置（资产映射/动画/排版）——无世界写权
        ↓
YardPresentationModel // 语义合成（注意力中心 + 分层语义节点）
        ↓
Renderer
```

> **CI 红线：PresentationModel 中任何 Cat / Object / Trace / Weather / Time
> 语义节点，都必须能回溯至 YardView；
> VisualConfig 只能改变怎么画，不能决定画什么事实。**

### 12.7 eval（增量）

- **注意力中心抽检**：任意时刻截屏，能指出唯一注意力中心（可以是一组互动），
  且中心由事实层决定；
- **回溯审计**（CI 级，12.6 口径）：PresentationModel 语义节点逐一回溯
  YardView；换 VisualConfig 不得改变语义节点与注意力中心；
- **语义确定性**（CI 级）：同一 YardView → 相同 semantic render tree
  （动画相位除外，不测像素）；
- **假事件抽检**：微动逐条过"它是否暗示了未发生的事"；猫不在场时
  不存在任何猫形态微动节点（CI 可测）；
- **面板化扫描**：红点/角标/进度条/倒计时出现 = P0（与"无露出扫描"20 同族）；

### 12.9 母场景 Base 定稿口径（2026-08-08 创始人拍板，冻结）

**美术命题**：**一座有人住过、但正在等你慢慢留下痕迹的小院子。**
不是"空白装修房"，也不是"精致萌宠乐园"。第一版先定构图口味，不追求画面精致。

**构图：轻俯视的固定 3/4 绘本视角**（非纯俯视、非平视）——三个好处：
三槽位天然可读；猫在场时看得见身体动作与表情；Trace 真正落在地面/物件/台阶上，
而不是变成 UI 图标。

```
       后景 / 海风方向
  ┌────屋檐 / 小屋────┐
  │   檐下槽位          │
  │              老树   │
  │              槽位   │
  │                    │
  │       中央空地槽位   │
  │                    │
  └──门口/台阶─────────┘
       用户视线 / 前景
```

- **三个自然可以摆东西的位置**，不是规则九宫格、更不是三个发光 Slot：
  檐下（遮雨/安静/封闭感）· 老树边（高度/树荫/自然痕迹）·
  中央空地（开放/日晒/社交可见）——**22 的玩法轴直接长在环境里**；
- **小屋放左后方，老树放右后方，中间必须留出大片"没东西"**：
  房子居中 = 房屋经营，大树居中 = 景观图；真正的主角永远是
  **"院子里今天发生了什么"**。中央空地未来可以有猫、有两猫互动、有水盆、
  有一撮毛、什么都没有——**什么都没有时，也必须成立**。

**Base 生活痕迹 vs 事件痕迹（Static Canon 与 Trace 的分界，冻结）**：

> **Base 要证明这里有年月，Trace 才证明这里刚发生过生活。**

- Base 可以永久存在：石板颜色不均、木门边缘磨白、台阶旧划痕、墙角一小簇草、
  老树根把地面顶起一点、屋檐木头风吹雨打的色差；
- Base 不许画：新鲜脚印、一撮毛、打翻的东西、猫影、刚被喝过的水位——
  那些全部归 Trace/Cat 层；七仔那枚瓶盖若成为世界事实，走 Trace/纪念物层，
  不烙死在 Base 里。

**风格**：手绘水彩 + 纸张颗粒 + 克制线稿 + 偏灰自然色——
关键不是可爱度，是**有空气、有时间、有一点旧**。避三个方向：
手游 Home Scene（高饱和/发光槽位/商城精修）· 等距 3D 玩具屋（猫会变成棋子）·
梦幻 AI 插画（花/光粒子/藤蔓/魔法高光堆满）。
第一版**故意留一点"不漂亮"**：墙没有完全正、草不均匀、石头大小不一、
木头有旧色——要的是**被住过的感觉**。

**首图范围**：只做 **Base + 白天普通天气**，零动态事实；
Weather / Time 套件后做——都是在这张"同一个地方"上生长。

**三个极端测试（构图过关判据）**：
A. **空院子**——只看 Base，能不能待 10 秒而不觉得"页面没加载完"
（**最重要**：空院子若一看就"缺东西"，美术后面必然往 Base 加装饰，
最终杀死"安静合法"）；
B. **一只猫**——放一只普通猫进去，它是否自然成为注意力中心；
C. **一撮痕迹**——猫拿掉只留一个很小的 Trace，用户是否仍能找到它。

**最终验收三句（不是"好看"）**：

> 我一眼知道这是我的院子。
> 这里今天没有发生什么，也没关系。
> 只要一只猫走进来，整个画面的意义就变了。

**验收第四句（v1 三测后创始人补入，冻结）**：

> **院子不能为了显得有生活而画得太满，
> 因为真正的生活还要后来发生在上面。**

**首版三测记录（2026-08-08，v1 = 首张生成稿）**：
A 空院子 **PASS**（不像没加载完；中央留白是自然空间不是待填 Slot；
没画任何"刚发生的事件"）· B 单猫 **PASS WITH RISK**（中央槽 PASS；
树下槽深色猫有被树根阴影吃掉的风险；檐下槽偏弱）· C 小痕迹 **HOLD**
（中央泥地的水彩颗粒/斑驳/树根阴影会与低强度 Trace 竞争——用户不是
自然发现而是根本看不到，随后 UI 团队就会想描边/闪烁/小标签，
反向破坏本章刚冻结的规则。**Base 必须替 Trace 预留低噪声表面**）。

**v2 构图修正（只改四处，不换画风不换题材；解决即锁，不做第三轮）**：

1. 前景门压低 15–25% 或镜头往院内推进半步——**门槛感保留**
   （用户视角像站在自己家门口往院子里看，这是这张图的意外优点：
   门应该说"这是你回来的地方"，不能天天说"看，这是一扇门"）；
2. 檐下空间打开，别被前景白墙吃掉——至少完整容纳
   "一只猫 + 一个中型物件 + 一条小 Trace"；
3. 中央泥地保留旧感，减约 20% 斑驳噪声——不是变干净，
   是给爪印、毛、挪动物件后的痕迹留视觉余量；
4. 树根周围保留生活感，树下前方留一块稍平静的可用区域——
   否则它是"景观树"，不是"猫能生活的地方"。

其余（海平线/小屋位/老树位/3/4 俯视/水彩/旧门/白墙/中央留白）全部不动。
v2 通过三测即锁母场景；锁前 Renderer 不绑定 Base 资产。
