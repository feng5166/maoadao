## 零、核心论点：可信不靠精致，靠痕迹

AI 内容的破绽从来不是画得不好，是**太干净**——没有磨损、没有累积、没有时间。

生活痕迹 = 时间在物上留下的证据。这是 05 生命原则的视觉版：
**变化必须留下时间痕迹，而不是系统痕迹**——美术同理，
世界要有**被生活过的样子**。猫阿道的岛是一座旧岛（00），新的反而假。

## 二、生活痕迹层（本文核心新增）

痕迹三类：

1. **累积**——小屋的东西慢慢变多、收藏排成一排、门口的物件：
   "内容回写世界"（10 原则）的视觉出口。三个月后贝壳还在，旁边多了颗松果；
2. **磨损**——旧牌子褪色、木箱磨圆的边角、被踩熟的小路：
   世界有年龄。岛民册第七行的划痕、猫阿道小屋的锁——旧物是起源的沉默证词；
3. **摆放**——东西有"被用过"的位置：贝壳不在正中间，歪一点；
   它总把东西放在同一个角落（10 §六"行为重复是生命感"的视觉版——**习惯可见**）。

判据（"无用即有用"删除判据的视觉版）：
**删掉这个痕迹，画面是否变得更"干净"了？是——痕迹就是对的。**

红线：痕迹必须可溯源（角色/世界/关系，01 §六）——
贝壳在那里是因为它捡过；**不做贴图式做旧**（无来历的脏=装饰，删）。

**边界（评审补入）：痕迹 ≠ 脏。** 猫岛不是破旧、不是废墟、不是垃圾堆——
是**被爱惜使用过**：旧木桌、磨亮的扶手、被整理过的收藏。
关键词：**不是衰败，是岁月。**

**痕迹一问（评审补入，冻结）：所有痕迹必须回答——谁留下的，为什么留下。**
答不出的痕迹，删。

## 三、外貌：一眼认出的差异

- 立绘一次定稿 + 差分复用（doc/00 §十三）；七仔锁母版派生（doc/22）；
- **剪影识别**是角色外形的第一判据（七仔=短尾+半张黑脸+嘴里叼着东西）；
- 你的猫：firstSight → 外观 → 姿势集（管线已自动化）；
- 个体差异靠**轮廓与花色**，不靠配饰堆砌——商业化外观（07 §五 左栏）同守此线：
  买的是表达，不是识别度的通胀。

## 四、声音：岛上只有猫和风

- 无人声铁律不重复（doc/17）；人走了，岛上只剩猫的声音（00 §四·2 的互证）；
- 每只猫的第一声必须可辨识（doc/21 拍 4 声音身份）；
- **环境永远大于表达**（评审冻结）：大部分时间是海浪、风、树叶、脚步；
  偶尔才是猫叫——**猫一直叫，它就不是生命，是提示音**；
- **声音的沉默**：大部分时刻没有声音——声音稀有才被听见
  （休刊日/稀有稀释原则的听觉版）。环境声是底，猫叫是事件，不是背景音乐；
- **系统声音清零**（评审冻结）：叮、任务完成音、奖励音、成就音、红点提示音、
  BGM 循环——那些是 App 的声音，不是猫岛的。

## 五、触感：交互的手感

- 摸摸它：反应有延迟、有性格、会腻（不是按钮响应——结果属于生命，07）；
- 微动：呼吸、耳朵、尾巴尖——存在感，不是表演（doc/16）；
- 纸张物理隐喻：翻页、票根、印章、手写体——岛民册落笔（09）必须是**手写体**；
- 禁：弹窗动效、庆祝粒子、进度动画、骨架屏闪烁——**系统痕迹**。

判据：**反馈来自世界（它动了），不来自界面（UI 闪了）。**

## 六、镜头规则（评审补入——观看方式也是感知层）

**镜头不是寻找玩家，而是观察生命。**

- ❌ 猫望向屏幕打招呼、镜头转向强调"看这里"——那是演员看镜头；
- ✓ 镜头停在那里，猫刚好经过——**世界不知道有观众**
  （doc/25"镜头跟着它，不是它带着你"的全域化）；
- 精细化：猫可以发现**你**（你是岛民，存在于世界内——doc/21 拍 3 的遭遇
  是相遇，不是表演），但永不表演给**屏幕**看；
- 镜头永不催促：不自动聚焦"重点"、不缩放强调、不加引导箭头——
  什么值得被看见由导演选材（06），**怎么看由用户自己的眼睛决定**。

## 十二、2.1 玩法化接口：Home Yard 母场景七层（2026-08-08 增量立稿，待评审）

> 命题（创始人点题）：已经跑起来的 Yard 世界，如何在一个**固定母场景**里
> 让用户一眼看见"现在、发生过什么、我能做什么"——同时仍然像生活，
> 不像 UI 面板。只回答五个问题，范围压死在七层。

### 12.1 七层解剖：谁是事实层，谁是表现层（问题 ①，冻结候选）

```
Base         表现层基底 —— 院子固定母场景（构图/视角永不换）：世界的"这里"
Weather      事实驱动 —— 世界天气史：同一院子的光与湿度，不是换背景图
Time         事实驱动 —— 窗口时段：光线方向 / 影长 / 色温：同一院子的一天
Object       事实层 —— Placement 快照：摆着什么、在哪个位置，与世界 1:1
Trace        事实层 —— ActiveTrace：此刻还看得到的痕迹（消退归 06 生命周期管）
Cat          事实层 —— CatVisit 浮现纪律：此刻在场才画；世界说不在，就不许画
MicroMotion  表现层 —— 呼吸 / 风 / 光斑：唯一允许"无事实对应"的层
```

组合与覆盖规则（冻结候选）：

- **事实五层只能如实合成**——画面是世界状态的忠实视图
  （渲染 = Disclosure 视图的确定性函数：同状态同画面），
  任何层不得画出事实层没有的东西；
- **表现两层永不携带事实语义**——Base 不暗示事件，MicroMotion 不制造事件；
- **覆盖红线**：表现层不得遮蔽事实层信息（微动不遮痕迹，装饰不压猫）；
  事实层之间按 12.2 注意力秩序让位，**不互相覆盖信息**。

### 12.2 注意力秩序：一屏一主角（问题 ②，冻结候选）

> **画面永远只有一个"现在最值得看的东西"，由事实决定，不由运营决定。**

```
猫在场          → 猫是唯一主角，其余全部退底（环境大于表达，但生命大于环境）
猫不在场有痕迹  → 痕迹与留物成为主角（"有谁来过"是院子最重的悬念）
无猫无痕        → 院子本身（布置 × 天气 × 时间）——安静合法，不找补
```

- 主角只有一个：两只猫同窗在场时（Composition 层允许），主次由行为强度定
  （正在用物件的 > 路过的），绝不并排展签；
- "刚摆下"（placedThisWindow）属于 Object 层的轻微强调（环境语言），
  永不盖过猫与痕迹；
- 禁一切"所有信息一起抢注意力"的排版——这是 12.5 面板化的前兆。

### 12.3 时间与天气：改变同一院子，不是换一张图（问题 ③，冻结候选）

- **Base 永不换**，变的是：光（色温/影子的方向与长度）、湿度（雨的水洼 /
  湿了的石板 / 雨后反光）、以及**事实层自己的变化**（雨天猫躲屋檐下——
  那是行程与偏好在变，不是美术在演）；
- 禁"四时段四张背景轮播"感——验收标准：
  **用户能认出"还是我的院子，只是天暗了 / 下雨了"**；
- 水洼、被雨打湿的垫子属于**环境类 Trace**（06 §九 白名单：天气作用于物件）
  ——走事实层，不走贴图装饰；
- 实现形态自由（整图时段变体 / 分层滤镜 / 混合，归实施与 doc/15 管线），
  语义唯一：**时间天气改变的是同一个地方**。

### 12.4 MicroMotion：世界没停，但不撒谎（问题 ④，冻结候选）

- 职责：提供"世界没停"的存在感——猫的呼吸/耳朵/尾巴尖（在场时）、
  风吹草叶、光斑缓移、檐下影子随时间挪动；
- **红线：微动永不成为假事件**——不暗示"有事发生"、不指向可点击、
  不新增视觉钩子；猫不在场时，微动不得伪装猫的存在
  （草丛里晃过一道影子 = 伪造世界事实，P0）；
- 幅度守 doc/16：**呼吸可见但不表演**；微动是底噪，不是内容。

### 12.5 首屏信息密度红线：Yard 不是手游大厅（问题 ⑤，冻结候选）

> **Yard 是院子，不是仪表盘。一切 UI 都是"你在院子里做事的手"，
> 不是"系统发给你的面板"。**

- **禁**：卡片墙、任务面板、红点、常驻资源 HUD 角标、进度条、倒计时、
  签到入口、轮播 banner——出现任何一个，Yard 就退化成手游大厅（A01 禁栏）；
- 信息进画面的方式：**状态即画面**（摆着什么，画里就摆着什么；
  痕迹就画在它发生的地方）；记录与翻旧账走**纸张动作**（翻册/翻记录，
  既有纸张隐喻）；数字只在动作现场以世界语言出现
  （收下时知道收了几条；小鱼干在"手边"，不在屏幕角落常驻）；
- 动作入口贴着对象走：摆放贴着槽位、收下贴着留物、翻册贴着门口——
  **能做什么由画面里的东西告诉你，不由按钮清单告诉你**；
- 现有临时页（文本列表）定性为**功能脚手架**：翻转时被母场景整体替换，
  动作语义（摆放/收下/翻册/换货）原样保留。

### 12.6 eval（增量）

- **一屏一主角抽检**：任意时刻截屏，能指出唯一主角，且主角由事实层决定；
- **事实一致性审计**（CI 可做）：渲染输入 ⊆ YardView（画面上每只猫/每件物/
  每条痕迹都能指认对应事实；画面出现事实不存在的元素 = P0）；
- **假事件抽检**：微动逐条过"它是否暗示了未发生的事"；
- **面板化扫描**：红点/角标/进度条/倒计时出现 = P0（与"无露出扫描"20 同族）；
- **第一眼测试照旧总闸**（§七）：遮 logo，Yard 首屏不像任何一个手游大厅。
