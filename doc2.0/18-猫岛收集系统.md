# doc2.0/18 猫岛收集系统——从未知，到懂得

> 2026-08-07 立稿（2.1 玩法化·批次一第 5 篇；上游：16/17 冻结、A01 #8 #9 #14 #15）。
> 命题（创始人）：**既然猫的发现和收集是最主要的长期目标，那么"一只猫从完全未知，
> 到我认为自己已经很了解它"，中间到底有哪些可持续收集层级？**
> 18 做好了，maoadao 的"收集"才不会退化成一个普通图鉴。
> 定性：不管概率（17）、不管资源数值（19/22）——管**用户知道什么、怎么知道、
> 知道的东西住在哪**。
>
> 架构守则（全批次适用）：院子循环负责驱动行为，世界模拟负责决定事实，
> AI 负责放大生命差异。

## 零、核心论点：收集的对象不是猫，是"对猫的认识"

图鉴收集**拥有**（"17/50"），猫岛收集**经历过 + 懂得**（A01 #15）。

由此推出本篇最重要的一条设计：

> **岛猫册记录的是你的认知，不是世界的百科。**

册子的内容全部来自你的 Observation（16 三层分离的收集侧落地）——
世界知道的（CatVisit 事实）永不直接灌进册子。因此：

- 同一只猫，在不同岛民的册子里**长得不一样**（你知道它爱雨天，
  他只见过它一次背影）；
- 你的册子厚，是因为你观察得多，不是因为你登录得久；
- 这为 21 的兴趣组留好了地基：**每个人手里都是碎片，拼图才有意义**。

第二条推论（A01 #9，17 §六 五面接口）：**已解锁的猫永不毕业**——
"了解"没有终点，只有下一层。

## 一、认识的阶梯：来过 ≠ 有迹象 ≠ 已确认 ≠ 渐懂 ≠ 代表记忆

一只猫在你这里的收集状态（17 的 Visit Rarity × Discovery Difficulty
在体验侧的落点）：

| 态 | 定义 | 载体 |
| --- | --- | --- |
| 来过 | CatVisit 事实存在——**世界知道，你不知道** | 无（事实层） |
| 有迹象 | 只有痕迹（TRACE_ONLY）：压痕、毛、吃剩的东西 | 册子的**影子条目**："最近有谁常来？" |
| 已确认 | 第一次 FULL_RECORD 或 LIVE 观察——**岛猫册正式条目诞生** | 岛猫册（A01 #8：新猫本身就是强奖励） |
| 渐懂 | 重复观察逐项解开：时间/喜好/位置/天气/社交/习惯 | 条目逐渐变厚（§三） |
| 代表记忆 | 特殊行为/特殊经历留下的纪念 | 纪念物与抓拍（§五） |

- **影子条目是 Discovery Difficulty 的体验面**：猫 B 型（不稀有但难确认）
  的玩法就在这——痕迹可积累、可比对（"这撮毛和上次的颜色一样"），
  确认那天有"原来是你"的爽感；
- 错过合法（A01 #14）：来过而你永远没确认，也是这个世界的真实——
  影子条目允许长期存在，永不倒计时、永不催。

## 二、岛猫册（核心载体）

**正式条目**（已确认后诞生）可以逐步长出：

- 样子（立绘/抓拍）与**名字**；第一次见面（何时何地、当时你摆着什么）；
- 最近一次来访；来的频率（**世界语言呈现**："常客""偶尔路过"——
  精确计数是否露出，评审时定，倾向不露）；
- 你观察到的喜好、常待的位置、出现的天气；
- 它用过你的哪些东西、留下过什么；
- 你目击过的行为；它和哪些猫一起出现过。

**名字是被知道的，不是被输入的**：世界猫自有其名。首次确认时你可能只有
一个"叫法"（03 单猫叫法语法："总在下午来的灰猫"）；正式名字经由
岛闻/日报/观察自然揭示——**知道它叫什么，本身是一次收集**。

**未知槽**：没见过的猫留轮廓 + 线索（"有岛民说，下雨天在旧雨伞附近见过它"）
——未知槽是 17"谜面必须发得出去"的正式载体，也是 D3 阶段
（"还有很多猫我没见过"）的供给源。

**禁**（A01 #15 禁栏 + 04）：完成率百分比 / "17/50"计数导向 / 进度条 /
"收集完成"类宣布 / SSR·稀有度标签外显——稀缺只用世界语言
（"有些岛民住很久也只见过几次"）。

## 三、渐懂层（可持续收集的主体）

"了解一只猫"= 一组**渐明信息**，每项靠重复观察解开（不是一次全给）：

活跃时间 · 喜欢的物件 · 常待的位置 · 天气规律 · 和谁要好 · 特殊习惯 ·
（长期）它最近的变化——**习得偏好的演化（17 §二）本身是新的收集内容**：
"它以前不碰水盆，最近好像变了。"

三条规则：

1. **信息可溯源**：条目里每一条都能指认来源观察（你亲眼/痕迹推理/
   岛闻听说）——**听说的要标记为听说**（"日报上说它常去灯塔"），
   听说可能不准（03 传闻允许失真），亲证后修正——修正本身是玩法；
2. **渐明不设进度**：永不显示"了解度 60%"；条目变厚的感觉靠内容累积；
3. **永不完卷**：信息清单没有"最后一项"——17 五个概率面持续供给新的可研究维度。

## 四、特殊行为与行为册

- **特殊行为** = 有条件的行为（挂 17 Behavior 概率面）：第一次钻纸箱、
  第一次和某只猫挤在一起睡、雨天躲屋檐、对着月亮叫；
- 目击特殊行为可获**抓拍**（Observation type: PHOTO，16）——
  抓拍进条目，也是分享素材；
- **行为册**（四本之二）：跨猫的行为收集——"见过哪些行为"独立成册，
  同一行为不同猫做出来不一样（10 表达变化）；
- 红线：特殊行为是**发现**不是任务——永不出现"待观察行为清单"式引导。

## 五、纪念物（代表记忆）

- 特殊猫或特殊经历留下的**物**：老板留下的铜铃、雨伞猫留下的旧布条；
- 纪念物 ≠ 资源（19 分界）：不可花、不入账，进小屋/生活册既有链路
  （02 v1"记忆物证化"的玩法侧继承——沉淀，不是刷新）；
- 它是一只猫在你这里的"收集完成感"，但**不宣布毕业**——
  纪念物之后，生活还在继续（A01 #9）。

## 六、四本收集总表

| 册 | 收集什么 | 供给来源 |
| --- | --- | --- |
| 岛猫册 | 猫：确认、渐懂、影子条目、未知槽 | CatVisit + Observation（§一–§三） |
| 行为册 | 见过的行为（跨猫） | Behavior 概率面 + 抓拍（§四） |
| 物件册 | 物件的生活史——"这个旧纸箱已经被九只不同的猫用过" | 物件状态 + Wear/Trace（A01 #12） |
| 岛屿见闻 | 在整个猫岛经历过的特殊事——习俗日、岛闻大事、世界变化 | 原 maoadao 世界层（01/06 管线） |

四本的共同性质：**记录"我经历过什么"**；全部可溯源到 Observation 或
亲历事件；全部无完成率。

## 七、eval

- **图鉴退化审计**：任何完成率/百分比/SSR 词/进度条出现 = P0；
  稀缺表述全部世界语言（04 扫描）；
- **认知镜像审计**：抽任一册子条目，逐条可溯源到该用户的 Observation
  或标记为"听说"——出现"用户从未观察过却已在册"的信息 = **P0**
  （册子在抄数据库的证据）；
- **毕业审计**：已确认猫的后续供给率——确认后 N 窗口内仍产生
  新信息/新行为的比例（报数，健康线归 22）；
- **影子条目转化**：有迹象→已确认的转化时长分布（观察项，
  验证 Discovery Difficulty 曲线是否过挫）；
- **盲读（本篇北极星）**：随机读一个用户的岛猫册——读起来像
  **"一个人的观察笔记"**，还是像"一套数据卡片"？前者过，后者缺陷。

## 合回清单

### 数据模型
岛猫册条目（认知镜像：全部字段挂 Observation 溯源）；影子条目（痕迹聚合）；
未知槽与线索投放记录；行为册 / 物件册 / 岛屿见闻三册；抓拍资产；
纪念物（与 19 资源分表）。
### Simulation
无新模拟机制——册子只读 Observation 与亲历事件，**永不反写世界**
（箭头只朝一个方向）。
### Director
线索投放节奏（未知槽的谜面供给，接 17 线索存在性审计）；
特殊行为的稀释看守（稀有稀释原则沿用）。
### 数值
归 22：渐明信息的解锁观察次数 / 影子条目聚合阈值 / 抓拍频率 /
纪念物触发条件 / 毕业审计健康线。
### API / Action
查册 / 翻条目（纯读）；无"标记收藏""追踪目标"类任务化动作。
### Web / UI
岛猫册入口（08 次级入口）；条目"变厚"的排版（渐明信息逐条浮现，
非百分比）；影子条目与未知槽的呈现；抓拍展示。
### 埋点
册子打开率 / 条目停留 / 未知槽查看→布置变更转化（D3 旗标原料，定义归 20）。
### 文案 / 美术 / 音频
条目文案全部过 04（观察笔记腔，禁数据卡腔）；"听说"标记的表达；
抓拍的视觉规格归 11。
### 旧规则迁移
既有"相遇档案 / 生活册"概念 MIGRATE→四本收集体系（映射细节实施时定）；
v1 09"相认四方式" 的观察素材 MIGRATE→渐懂层信息项；
**物件命名 KEEP 落位本篇**（08 冻结遗留）：给它用过的物件、捡来的东西起名字，
名字进物件册与世界语言流通（v1 02 §五"你的词汇进入岛的词典"继承）。
### 验证指标
D3 阶段达成率（旗标归 20）；已确认猫数分布（报数）；
确认后持续供给率（§七 毕业审计）；盲读通过率（§七 北极星）。
