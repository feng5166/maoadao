# doc2.0/18 猫岛收集系统——从未知，到懂得

> 2026-08-07 立稿（2.1 玩法化·批次一第 5 篇；上游：16/17 冻结、A01 #8 #9 #14 #15）。
> 命题（创始人）：**一只猫从完全未知，到"我认为自己已经很了解它"，
> 中间到底有哪些可持续收集层级？** 18 做好了，收集才不会退化成普通图鉴。
> 定性：不管概率（17）、不管资源数值（19/22）——管**用户知道什么、
> 怎么知道、知道的东西住在哪**。
>
> **2026-08-07 冻结：收集系统 v1**（同日评审修订五处 + 一条 UI 边界后冻结：
> ① 收集事实与完成度压力分离——可示"已认识多少"，禁示"还差多少"
> ② 未知条目必须有认知来源，不预加载全猫池 ③ 代表记忆拆为旁轴里程碑
> ④ 影子证据禁用隐藏 catId 归因，认知层允许误判与修正
> ⑤ 物件命名默认私人 Alias。UI 边界：四类 Collection 是逻辑结构，
> MVP 不等于四个独立入口。**第一原则升格冻结**（见 §零）。）
>
> 架构守则（全批次适用）：院子循环负责驱动行为，世界模拟负责决定事实，
> AI 负责放大生命差异。

## 零、第一原则与三个词

图鉴收集**拥有**（"17/50"），猫岛收集**经历过 + 懂得**（A01 #15）。

> **岛猫册记录的是你的认知，不是世界的百科。**（第一原则，冻结）

册子的内容全部来自你的 Observation（16 三层分离的收集侧落地）——
世界知道的（CatVisit 事实）永不直接灌进册子。因此：同一只猫在不同岛民的
册子里**长得不一样**；你的册子厚是因为你观察得多，不是登录得久；
21 兴趣组的地基在此——**每个人手里都是碎片，拼图才有意义**。

整套收集体系压成三个词（评审定稿）：

| 词 | 回答 | 内容 | 核心驱动力 |
| --- | --- | --- | --- |
| **发现** | 它是谁？ | 新猫、影子、第一次确认 | 好奇 |
| **研究** | 它是什么样的猫？ | 偏好、时间、天气、行为、社会关系 | 掌握规律 |
| **留念** | 我们经历过什么？ | 抓拍、纪念物、物件痕迹、特殊事件 | 时间价值 |

```
发现 → 研究 → 不断产生新的发现 → 偶尔留下代表记忆
```

**不是一个填满进度条的线性流程。** 已确认的猫永不毕业（A01 #9；
17 五个概率面持续供给"研究"的新维度）——"解锁"只是开始认识，不是收集完成。

## 一、认识的主轴与旁轴（评审修订：非线性）

**主轴**（认知递进，有顺序）：

```
UNKNOWN → EVIDENCE → CONFIRMED → KNOWLEDGE ACCUMULATION
 未知       有迹象      已确认         渐懂（无终点）
```

| 态 | 定义 | 载体 |
| --- | --- | --- |
| 未知 | 你不知道它存在（世界可能知道它来过） | 无 |
| 有迹象 | 只有痕迹：压痕、毛、吃剩的东西 | 影子证据（§三） |
| 已确认 | 第一次 FULL_RECORD 或 LIVE 观察——**正式条目诞生** | 岛猫册（A01 #8：新猫本身就是强奖励） |
| 渐懂 | 重复观察逐项解开，无终点 | 条目逐渐变厚（§四） |

**旁轴：MEMORABLE MOMENT（代表记忆）——里程碑，不是 Lv.5。**
它不挂在主轴上：一只猫可能第一次来就发生极特殊的事、留下纪念物，
而你根本不了解它；也可能认识很久，从未产生留念。两种都对（§六）。

错过合法（A01 #14）：来过而你永远没确认，也是这个世界的真实——
影子证据允许长期存在，永不倒计时、永不催。

## 二、岛猫册（核心载体）

### 收集事实可以有，完成度压力不能有（评审修订，冻结）

- **可以**：呈现你真实经历的总结——"你在岛上已经认识了 12 只猫"、
  条目自然陈列。收集成长感是合法驱动力；
- **禁止**：任何"距离全收集还差多少"——12/50、百分比、还差 N 只、
  全收集奖励、进度条；
- 世界口径配套：**永远不知道岛上一共有多少猫**——猫池规模不是公开事实，
  内容更新也不发"新增 N 只"公告。收集成长感与世界未知感由此并存。

### 未知条目：必须有认知来源（评审修订，冻结）

> **岛猫册不预加载全猫池。未知条目必须有认知来源后才出现。**

- **已知未知**：世界给过线索（"有岛民提过一只雨天才出现的猫"）→
  册子里出现一页**未确认的传闻**——这是合法目标，
  也是 17"谜面必须发得出去"的正式载体、D3 阶段的供给源；
- **未知未知**：你连它存在都不知道——**不显示**。
  "岛上是不是还有我根本没听说过的猫？"这个悬念远强于一排问号。

### 正式条目（已确认后诞生，逐步长出）

样子（立绘/抓拍）与**名字**；第一次见面（何时何地、当时你摆着什么）；
最近一次来访；来的频率（**世界语言**："常客""偶尔路过"，精确计数不露）；
你观察到的喜好、常待位置、出现天气；它用过你的什么、留下过什么；
你目击过的行为；它和哪些猫一起出现过。

**名字是被知道的，不是被输入的（冻结）**：世界猫自有其名。首次确认时
你可能只有一个"叫法"（03 单猫叫法："总在下午来的灰猫"）；
正式名字经岛闻/日报/观察自然揭示——**知道它叫棉花，本身是一次收集**。

## 三、影子证据：允许误判，禁止代答（评审修订，冻结）

有迹象态的载体是 **UnknownEvidenceCluster（证据簇）**：

```
证据簇 · 未确认
- 灰色短毛
- 小爪印
- 都在夜间
- 两次纸箱痕迹
```

用户可以自己猜："好像是同一个家伙。"但——

> **红线：认知层不得用隐藏 catId 替用户完成归因。**

世界当然知道每条痕迹是谁留的；岛猫册**不知道**，直到用户有足够证据。
系统不得因为两撮灰毛就后台合并成"某只未知灰猫的影子条目"——
那是世界数据库偷偷投影给用户。认知层必须允许三种结局：

- 后来证明是同一只（"原来是你"）；
- 后来发现其实是两只猫（"原来是你们俩"——同样是好时刻）；
- 部分证据重新归类。

**误判与修正是研究感的来源**，不是数据缺陷。

## 四、渐懂层（"研究"的主体）

"了解一只猫" = 一组渐明信息，每项靠重复观察解开（不是一次全给）：
活跃时间 · 喜欢的物件 · 常待位置 · 天气规律 · 和谁要好 · 特殊习惯 ·
（长期）**它最近的变化**——习得偏好的演化（17 §二）本身是新的收集内容。

三条规则（冻结）：

1. **信息可溯源，且分认知等级**：每条能指认来源——亲眼（LIVE/RECORD）/
   痕迹推理（TRACE）/ 听说（岛闻/日报/别的猫）。**听说要标记为听说**
   （"日报上说它常去灯塔"），听说可能不准（03 传闻允许失真）：

   ```
   RUMOR → PERSONAL EVIDENCE → CONFIRMED / REVISED
   ```

   亲证后修正——**修正本身是玩法**（"大家都这么说，但我怎么从来没碰到？"
   ——21 兴趣组的天然话题）；
2. **渐明不设进度**：永不显示"了解度 60%"；变厚的感觉靠内容累积；
3. **永不完卷**：信息清单没有最后一项——17 五个概率面持续供给新维度。

## 五、特殊行为与抓拍

- **特殊行为** = 有条件的行为（挂 17 Behavior 概率面）：第一次钻纸箱、
  第一次和某只猫挤在一起睡、雨天躲屋檐；
- 目击可获**抓拍**（Observation type: PHOTO，16）——进条目，也是分享素材；
- 行为收集跨猫成册（逻辑上的"行为册"，UI 边界见 §八）；
  同一行为不同猫做出来不一样（10 表达变化）；
- 红线：特殊行为是**发现**不是任务——永不出现"待观察行为清单"式引导。

## 六、留念（旁轴里程碑）

- 特殊猫或特殊经历留下的**物**：老板留下的铜铃、雨伞猫留下的旧布条；
- 纪念物 ≠ 资源（19 分界）：不可花、不入账，进小屋/生活册既有链路
  （02 v1"记忆物证化"继承——沉淀，不是刷新）；
- 它是里程碑不是等级（§一 旁轴）：可能来得很早（还不了解它就发生了），
  可能一直不来（认识很久也没有）——**留念之后，生活还在继续**（A01 #9）。

## 七、物件命名：私人 Alias（评审修订，冻结）

用户给物件起的名字（"灰灰床"）**默认只属于自己的认知与院子语言**
（User-local Alias）——不自动成为公共世界事实：岛上的居民不会
因此都管它叫"灰灰床"。

> **私人认知 ≠ 世界事实**——只有经过明确的世界事件传播，
> 私人称呼才可能成为公共称呼（传播机制 MVP 不做，仅立边界）。

（v1 02 §五"你起的名字在岛上流通"相应收紧：流通必须经世界事件门，
合回时按此修订。）

## 八、UI 边界：逻辑四类，不是四个入口（评审补入，冻结）

四类 Collection 是**信息架构**：猫（岛猫册）/ 行为 / 物件生活史
（"这个旧纸箱已经被九只不同的猫用过"，A01 #12）/ 岛屿见闻。

**MVP 用户认知里只有一本：岛猫册。** 进去以后自然看到猫、行为、
物件留下的生活史；"岛屿见闻"继续属于岛世界（岛闻/日报既有面）。
**禁止实现成首页四个 Tab / 四个按钮。**

## 九、eval

- **图鉴退化审计**：完成率/百分比/还差 N/总量 N/SSR 词/进度条 = P0；
  "已认识 N 只"类**经历总结合法**；稀缺表述全部世界语言（04 扫描）；
- **认知镜像审计**：抽条目逐条溯源到该用户的 Observation 或标记为听说——
  "从未观察过却已在册" = **P0**（册子在抄数据库）；
- **归因审计**（CI 可测）：两个证据簇事实上同猫时，系统不得提前合并；
  认知层视图不携带 catId；
- **毕业审计**：已确认猫的后续供给率——确认后仍持续产生新信息/新行为
  （报数，健康线归 22）；
- **影子转化**：有迹象→已确认的时长分布（观察项，验证 Discovery
  Difficulty 曲线不过挫）；
- **盲读（北极星之一）**：随机读一个用户的岛猫册——像
  **"一个人的观察笔记"**，还是像"一套数据卡片"？后者缺陷；
- **实验回送（北极星之二，评审补入）**：翻完岛猫册后，用户有没有产生
  **"一只我接下来特别想遇见/确认/搞懂的猫"**？
  册子必须把结果送回 08/16 的循环：

  ```
  院子来访 → 岛猫册变厚 → 看见新的未知/未解问题 → 改布置 → 再等
  ```

  册子好看但不驱动下一轮实验 = Collection Loop 断裂 = 缺陷。

## 合回清单

### 数据模型
岛猫册条目（认知镜像：字段全挂 Observation 溯源 + 听说标记）；
UnknownEvidenceCluster（**catId 关联只存世界侧，认知层视图不携带**）；
未知条目的认知来源记录（线索投放→传闻页）；抓拍资产；
纪念物（与 19 资源分表）；物件私人 Alias（user-local）。
### Simulation
无新模拟机制——册子只读 Observation 与亲历事件，永不反写世界。
### Director
线索投放节奏（传闻页的谜面供给，接 17 线索存在性审计）；
特殊行为的稀释看守（稀有稀释原则沿用）。
### 数值
归 22：渐明信息的解锁观察次数 / 证据簇聚合规则参数 / 抓拍频率 /
纪念物触发条件 / 毕业审计健康线。
### API / Action
查册 / 翻条目（纯读）；证据簇的用户侧"我猜是同一只"标记（可选，轻量）；
无"追踪目标"类任务化动作。
### Web / UI
单入口（岛猫册，08 次级入口）；条目"变厚"排版（渐明信息逐条浮现）；
传闻页与证据簇呈现；抓拍展示；**禁四 Tab**。
### 埋点
册子打开率 / 条目停留 / 传闻页与证据簇查看→布置变更转化
（北极星之二的量化；D3 旗标原料，定义归 20）。
### 文案 / 美术 / 音频
条目文案过 04（观察笔记腔，禁数据卡腔）；"听说"标记的表达；
抓拍视觉规格归 11。
### 旧规则迁移
既有"相遇档案/生活册"概念 MIGRATE→本篇收集体系（映射实施时定）；
v1 09"相认四方式"观察素材 MIGRATE→渐懂层信息项；
**物件命名 KEEP 且收紧**（§七：私人 Alias，公共流通须经世界事件门——
v1 02 §五 合回时按此修订）。
### 验证指标
D3 阶段达成率（旗标归 20）；已确认猫数分布（报数）；
确认后持续供给率（§九 毕业审计）；翻册→布置变更转化率（北极星之二）；
盲读通过率（北极星之一）。
