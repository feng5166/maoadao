## 一、世界猫实例规则（创始人拍板，冻结）

> **猫的身份、履历和社会事实全局唯一；用户院子里的 Visit 是该世界猫
> 生活事实的个体观察实例，不要求跨用户物理互斥。**

```
Global Cat（全局唯一）          Per-yard Visit（可以并存）
├─ Identity                     ├─ Observation
├─ Birth Canon                  ├─ Disclosure
├─ Life History                 ├─ Trace
├─ Social History               ├─ User Knowledge
└─ World Role                   └─ HomeAffinity
```

冻结句：

> **世界猫只有一个"它是谁"，但可以有多个"谁看见了它"。**

- **不做 MMORPG 式物理互斥**（"乌鸦 20:00 在 A 家，所以 B 家不能出现"）——
  那会让个人进度被全服在线用户互相抢资源，个人图鉴变成世界锁竞争，
  系统无法控制；
- **真正禁止的是社会事实矛盾，不是渲染实例重复**：
  它的履历、关系、职务、公开行程（itineraryFor 唯一事实源）全岛一份、
  永不自相矛盾；"今天下午它在集市"这类**公共世界事实**对所有用户一致；
  它出现在谁家院子，是各家院子对这份生活的**个体观察**；
- 与既有架构零冲突：Eligibility 读的是全局行程（01 §九），
  结算是 per-yard 确定性种子（16），Observation/岛猫册本就按用户隔离（18）
  ——本条只是把"一直这么实现着的东西"正式定成规则；
- 一致性红线照旧适用于**每一个观察实例**：任一 CatVisit 不得与全局行程
  发生时间重叠/不可达位移（auditVisitAgainstItinerary，01 §九 验收③）。

### 1.1 事实 ontology：CatVisit 是院子局部事实（评审补严，冻结）

"身份唯一，观察多份"只解决认知层——事实层还须把 **CatVisit 是什么层级
的事实**说死，否则"20:30 乌鸦在 A 院树下、同时在 B 院屋檐"会被误读成
全局物理位置矛盾。正式分层：

```
Global World Fact（全局世界事实——全岛一份，永不自相矛盾）
├─ Cat Identity / Canon / Life History / Social History / Role
└─ Itinerary / broad whereabouts state（它今天大体在哪、在做什么）

Yard-local Fact（院子局部事实——每院一份，互不干涉）
├─ CatVisit（它与这个院子发生的交集：stay / behavior in this yard）
├─ Trace / Disclosure / Observation
└─ 由此派生的一切认知与 HomeAffinity
```

> **CatVisit 是院子局部事实，不反写 Global Whereabouts；
> 跨院同时存在的 CatVisit 不构成"猫分身"的社会事实。**

> **全局世界决定它今天过着怎样的一天；
> 个人院子记录的是这一天与你这里发生的交集。**

由此三件事同时成立：itineraryFor 仍是统一世界输入（结算与叙事同读一份）；
每个用户有独立确定性结算；A 用户的一次 Visit 永不把全局猫位置锁死、
从而阻止 B 用户。

**CI/架构红线（冻结）**：

> **任何 per-yard CatVisit 的产生与消费路径，
> 都不得 UPDATE 全局 itinerary / location state。**

（当前实现天然满足：行程是纯函数派生、无全局位置表——本红线的意义是
**永远不许为了"更真实"加一张全局位置表让 Visit 去写**；静态看守入 CI。）

## 二、猫社会（第二阶段的世界侧，框架）

朋友/同行/避让/群体事件——SocialSeed（09）→ 关系演化（02/03/05）→
社会事件（06）。全部走既有事实链，多人到来不新增机制：
**猫的社会生活本来就在发生，多人只是多了几双看见它的眼睛。**

## 三、共同观察板（第二阶段的用户侧，框架立稿）

> **用户共享"观察"，不共享"答案"。**

- 形态 = **共同观察板**（雨天猫研究会/纸箱协会式的兴趣组）——
  不是聊天群、不是好友系统、不是攻略 wiki；
- 合法共享物：**观察**（"有人说旧伞附近见过黑影""三个人都在雨后看到过
  类似爪印"）——即 18 认知镜像里"岛闻公开过/用户目击过"档的二手化，
  经 01 §九 可知性裁决；
- **禁止**：全服图鉴自动解锁（"别人确认了乌鸦 → 你的册子也确认"= 拆掉
  个人认知镜像，18 P0）；系统公布底层概率公式；观察板变成答案板；
- 系统可以总结趋势（"最近很多人雨后见到爪印"），**永不给结论**；
- 个人图鉴进度永不被全局争抢决定（README 待议提案在此转正，与 §一 同族）。

## 四、红线汇总

1. §一 冻结句——身份唯一，观察多份；
2. 社会事实矛盾 = P0；渲染实例重复 = 合法；
3. 共享观察不共享答案；全服解锁永不存在；
4. 多人一切表达过 04（观察板语言 = 岛民的话声部，允许失真带猜测标记）；
5. MVP 期本篇零实施——防走样文档，不是排期文档。

## 五、eval（第二阶段实施时生效）

- **矛盾审计**：任意两个用户可见的同猫事实（公开行程/履历/社会事件）
  不得互相矛盾（个体观察差异合法：A 见过它睡觉、B 只见过毛）；
- **认知隔离审计**：任一用户的 confirmed/rumor/evidence 变化，
  找不到该用户自己的观察或合法二手来源 = P0（18 既有审计的多人版）；
- **观察板语言抽检**：出现概率数字/图鉴进度/解锁词 = P0。
