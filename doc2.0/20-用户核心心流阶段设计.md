# doc2.0/20 用户核心心流阶段设计——D0–D7 旗标正典

> 2026-08-07 立稿（2.1 玩法化·批次一第 8 篇，开工三前置之一；
> 上游：README §三（术语裁定摘要，本篇为正典）、12 v2.1（H 判据挂本篇旗标）、
> 08/16/17/18/19 冻结）。
> 定性（创始人点题）：**克制——本篇不设计任何新玩法**。只做两件事：
> 定义 D0–D7 每个认知阶段"发生了什么才算真的成立"，
> 以及这些旗标怎么被观测。

## 零、三条总则

1. **D0–D7 = 体验心流阶段编号**（编号即编号，不是缩写、不是自然日）。
   Day 管时间，Dx 管认知；推进条件 = 事件完成 + 认知成立，
   永不 `worldDay == N` 触发；
2. **旗标是认知成立的代理条件**：本篇只定事件组合结构，
   一切阈值（次数 N / 时间窗 T）归 22；代理不完美，
   需与定性访谈互相校准（§四）；
3. **阶段是观测工具，不是游戏化等级**：只进不退、达成即记录；
   **无 UI、无奖励、无提示、无仪式**——用户永远不知道自己"在 D 几"。
   任何"阶段/进度"的用户侧露出 = P0。

## 一、八阶段正典

| 阶段 | 用户在回答 | 成立条件（自然语言） | 完成旗标（事件组合） | 对应 |
| --- | --- | --- | --- | --- |
| **D0 进入世界** | 这里是什么？为什么值得留下？ | 走完 D0 心流；拥有自己的院子；理解这不是聊天 AI | `d0_complete + yard_granted`（走跳过口者记 skip，不判 D0 达成，单独观察其后续差异） | 进入（观测项） |
| **D1 操作认知** | 我在这里能做什么？ | 完整经历 放置→等待→猫来访→回来发现 | `first_item_placed + first_wait_completed + first_visit_result_observed`（任意 Disclosure 档的首次结果观察；欢迎结算保障首 session 可达，16） | H1 |
| **D2 概率认知** | 是不是每次都一样？ | 知道条件影响概率、但不决定结果 | `observed_multiple_outcomes`（同布置两次不同结果）或 `changed_item_and_received_different_result` | H1 深化 |
| **D3 收集目标** | 猫与猫一样吗？ | 第一次产生"还有我没见过的猫" | `new_unknown_encountered`（新确认 / 新传闻页 / 新影子簇）`+ collection_surface_seen`（翻过岛猫册）`+ unresolved_cat_target_exists` | H2 |
| **D4 经济循环** | 来访还给我什么？ | 走通 收下→自主花费→新物件摆下 | `resource_collected + first_autonomous_sink + new_item_placed` | H4 |
| **D5 规律研究** | 怎样让它再来？ | 第一次为某个具体目标主动调整配置 | `targeted_adjustment`：查看某猫条目/传闻页后的窗口内发生布置变更，且围绕同一目标重复 ≥N 次（N 归 22） | H3 |
| **D6 社会认知** | 猫只存在于我的院子吗？ | 意识到猫在同一个岛上生活 | `social_evidence_observed`：目击猫猫同现/互动，或岛闻与自家院子的猫产生关联且被查看（MVP 供给薄：**先埋不判**，12） | 观测项 |
| **D7 自主目标网络** | 下一步做什么？ | 不再需要被教——多类目标自己长出来并存续 | `multi_goal_persistence`：未解猫目标 / 物件·资源目标 / 规律验证目标 中 **≥2 类**，且跨 **≥2 个 session** 存续（**先埋不判**，12） | H5 关联 |

阶段间无强制顺序依赖（D4 可能先于 D3 达成——先花了钱才翻册），
漏斗分析按"最高已达成阶段"归组。

## 二、旗标的实现约束（克制条款）

- **不新增行为埋点**：旗标全部由既有埋点组合推导——08（七拍/收下）、
  16（摆放/更换/窗口结算/Observation）、18（翻册/传闻页/证据簇→布置转化）、
  19（入账/Sink）。本篇只定义组合逻辑；
- **离线可重放**：旗标由埋点流推导，不要求实时判定——定义修订后
  可全量回溯重算（判据可迭代而历史可比）；
- **旗标永不反写世界**：Dx 阶段不进入 Eligibility / Preference / Director
  的任何输入——**没有"按学习进度调难度"这种东西**。
  唯一例外：D1 欢迎结算消费"首次摆放"这一个事件事实（16 已冻结），
  它读的是事件，不是阶段；
- 阈值（N/T/存续窗口）全归 22。

## 三、漏斗用法（12 判决结构的操作面）

- **分层留存**：按最高达成阶段分组对比 Day7 留存——
  "达 D5 者 vs 仅 D2 者"的差是玩法成立与否的主证据（12）；
- **达成时长分布**：各阶段从上一阶段到本阶段的间隔——过快（没体验就过）
  与过慢（卡住）都值得看；
- **卡点定位表**（流失最大的阶段 → 该修哪个系统，不改规则）：

| 卡在 | 先查 | 出处 |
| --- | --- | --- |
| D1 | 首闭环体验（欢迎结算/发现呈现） | 16 |
| D2 | 结果差异的可感知度（表达面） | 16/04 |
| D3 | 线索投放与传闻页供给 | 18/17 |
| D4 | 经济节奏（首个可及 Sink 的距离） | 19/22 |
| D5 | 可学习性（线索信息量/规律稳定度） | 17/22 |

这张表是 12 §三"低数据唯一合法路径（四环诊断）"的落地入口。

## 四、eval

- **重放一致性**（CI 级）：同一埋点流两次推导，旗标结果一致；
- **无露出扫描**：用户侧出现"阶段/等级/进度/D 几"= P0；
- **隔离审计**（CI 级）：Eligibility/Preference/Director 输入集不含
  任何 Dx 旗标字段（唯一白名单：16 欢迎结算的首摆事件）；
- **代理校准**：种子期定性访谈（5-10 人，12 定性信号清单）与旗标判定
  对照——访谈说"我一直在试怎么让那只再来"而旗标未判 D5（或反之），
  修旗标定义，不修用户。

## 合回清单

### 数据模型
StageFlag 记录（userId × 阶段 × 达成时刻 × 触发事件引用）；
组合逻辑定义表（可版本化，支持重放）。
### Simulation
无——本篇零新机制。
### Director
无消费（隔离审计看守；欢迎结算走事件白名单，16 既有）。
### 数值
阈值 N / 时间窗 T / 存续窗口 → 22。
### API / Action
无新动作。
### Web / UI
无任何阶段露出（§零 总则 3）。
### 埋点
零新增行为埋点；组合推导逻辑落观测台；D6/D7 先埋不判（12）。
### 文案 / 美术 / 音频
无（本篇无用户侧表达）。
### 旧规则迁移
v1 首周曲线（doc/07，`lib/sim/firstweek.ts` catDay 1-7 主题曲线）语义拆解：
**catDay 是 Day 侧的世界供给节奏，与 Dx 认知阶段是两回事**——
旧曲线挂在"我的猫"模型上，其处置（DELETE/MIGRATE）归批次二与实施；
`d0_*` 埋点 KEEP（D0 阶段沿用）；旧 adopt 漏斗埋点退役（12 已记）。
### 验证指标
本篇即度量地基：各 H 的旗标观测就位率（开工验收项）；
重放一致性通过；代理校准一致率（种子期报数）。
