## 零、三条总则（冻结）

1. **D0–D7 = 体验心流阶段编号**（编号即编号，不是缩写、不是自然日）。
   Day 管时间，Dx 管认知；推进条件 = 事件完成 + 认知成立，
   永不 `worldDay == N` 触发；
2. **旗标是认知成立的代理条件**：本篇只定事件组合结构，一切阈值
   （次数 N / 时间窗 T）归 22；代理不完美，须与定性访谈互相校准——
   **冲突时修旗标定义，不修用户**（§六）；
3. **阶段是观测工具，不是游戏化等级**：只进不退、达成即记录；
   **无 UI、无奖励、无提示、无仪式**——用户永远不知道自己"在 D 几"。
   任何"阶段/进度"的用户侧露出 = P0。

## 一、双层模型：Signal 与 Reached（本篇核心数据模型，冻结）

```
世界时间轴   Day / WorldDay      —— 世界什么时候发生什么
用户证据层   StageSignal         —— 某种认知证据曾发生（可乱序）
用户心流层   StageReached        —— 从 D1 到 Dx 的必要认知链已闭合
```

- **Signal 可以乱序**：用户完全可能先花钱再翻册——`D4_SIGNAL` 先于
  `D3_SIGNAL` 出现，合法；
- **Reached 不能跳级**：`Reached Dx = D1..Dx 的 SIGNAL 全部在场`。
  D4_SIGNAL 先出现的用户，等 D2/D3 的证据补齐后，`D4_REACHED` 才成立；
- **分析主用 Reached**（"达 D5 用户 vs 仅达 D2 用户"由此才可比）；
  **诊断看乱序 Signal**（"D4 先于 D2"的人群分布本身就是信息）；
- **D0 在链外**：单独记 `d0_complete` / `d0_skip`（跳过者不判 D0 达成，
  单独观察其后续差异）；Reached 链从 D1 起算，D0 不阻塞。

## 二、八阶段正典（SIGNAL 定义）

| 阶段 | 用户在回答 | 成立的认知 | SIGNAL（事件组合） | 对应 |
| --- | --- | --- | --- | --- |
| **D0 进入世界**（链外） | 这里是什么？ | 理解世界、拥有院子 | `d0_complete + yard_granted`（skip 单独记） | 进入（观测项） |
| **D1 操作认知** | 我在这里能做什么？ | "我能影响这里" | `first_item_placed + first_wait_completed + first_visit_result_observed`（任意 Disclosure 档首次结果观察；欢迎结算保障首 session 可达，16） | H1 |
| **D2 不确定性认知** | 是不是每次都一样？ | **"同样的院子，不一定每次来同样的猫"**——只证结果不固定，不证可控（"条件影响概率"归 D5） | `observed_multiple_outcomes`（≥2 次可区分的来访结果，同布置或跨布置均可） | H1 深化 |
| **D3 收集目标**（目标诞生，一次成立） | 猫与猫一样吗？ | "我看见了一只还没搞懂的猫，并因此做了下一次实验" | `unknown_or_rumor_seen + collection_surface_seen + subsequent_placement_change`（与 12 H2 同口径） | H2 |
| **D4 经济循环** | 来访还给我什么？ | "来访可以支持下一次实验" | `resource_collected + first_autonomous_sink + new_item_placed` | H4 |
| **D5 规律研究**（研究行为形成，需要重复） | 怎样让它再来？ | "我开始主动研究规律，并调整自己的判断" | `targeted_adjustment × ≥N`：查看某猫条目/传闻页后的时间窗内布置变更，围绕**同一目标**重复（N/T 归 22） | H3 |
| **D6 社会认知** | 猫只存在于我的院子吗？ | "这些猫生活在同一个岛上" | `social_evidence_observed`（同现/互动目击，或岛闻×自家猫关联被查看）——**先埋不判**（12） | 观测项 |
| **D7 自主目标网络** | 下一步做什么？ | "我有很多自己想做的事" | `multi_goal_persistence`（未解猫/物件·资源/规律验证 ≥2 类目标，跨 ≥2 session 存续）——**先埋不判** | **产品成熟度观察项（不挂 H5）** |

D3 与 D5 的分界（评审定稿）：**D3 = 目标诞生，一次成立；
D5 = 研究行为形成，需要重复。**

## 三、H5 的度量（独立于 Dx 链，评审定稿）

H5（收集有效："解锁以后，我还继续回来了解它"）不塞进任何 Dx——
一个用户可能拥有健康的 D7 目标网络（想买物件/想找新猫/想验证天气），
却对已确认的猫毫无后续兴趣，那 H5 仍然失败。独立度量链（由 18 行为派生）：

```
confirmed_cat → later_cat_entry_view
→ 新渐懂信息 / 新行为 / 留念 被观察
→ subsequent_targeted_action 或 repeated_revisit
```

落观测台，与 18 毕业审计共用数据面。

## 四、实现约束（克制条款）

- **不新增行为埋点**：Signal 全部由既有埋点组合推导——08（七拍/收下）、
  16（摆放/更换/窗口结算/Observation）、18（翻册/传闻页/证据簇→布置转化）、
  19（入账/Sink）。本篇只定义组合逻辑；
- **离线可重放**：Signal/Reached 由埋点流推导，不要求实时——
  定义修订后可全量回溯重算（判据可迭代而历史可比）；
- **旗标永不反写世界**：Signal/Reached 不进入 Eligibility / Preference /
  Director 的任何输入——**没有"按学习进度调难度"这种东西**。
  唯一白名单：16 欢迎结算消费"首次摆放"这一个**事件**（不是阶段）；
- 阈值（N / T / 存续窗）全归 22。

## 五、漏斗用法（12 判决结构的操作面）

- **分层留存**：按 `StageReached` 最高值归组对比 Day7 留存——
  "达 D5 者 vs 仅达 D2 者"的差是玩法成立与否的主证据（12）；
- **乱序诊断**：Signal 顺序分布（如"D4_SIGNAL 先于 D2_SIGNAL"人群）
  用于理解真实路径，不入判决；
- **达成时长分布**：各 Reached 的间隔——过快（没体验就过）与过慢（卡住）
  都值得看；
- **卡点定位表**（Reached 链上流失最大的一级 → 先修哪个系统，不改规则）：

| 卡在 | 先查 | 出处 |
| --- | --- | --- |
| D1 | 首闭环体验（欢迎结算/发现呈现） | 16 |
| D2 | 结果差异的可感知度（表达面） | 16/04 |
| D3 | 线索投放与传闻页供给 | 18/17 |
| D4 | 经济节奏（首个可及 Sink 的距离） | 19/22 |
| D5 | 可学习性（线索信息量/规律稳定度） | 17/22 |

这张表是 12 §三"低数据唯一合法路径（四环诊断）"的落地入口。

## 六、eval

- **双层一致性审计**（CI 级）：任一 `Reached Dx` 必然蕴含 D1..Dx 全部
  Signal——否则判定器有 bug；
- **重放一致性**（CI 级）：同一埋点流两次推导，结果一致；
- **造目标审计**：D3 判定必须含 `subsequent_placement_change`——
  仅凭"系统里存在传闻页"不判（系统不替用户造目标）；
- **无露出扫描**：用户侧出现"阶段/等级/进度/D 几"= P0；
- **隔离审计**（CI 级）：Eligibility/Preference/Director 输入集不含
  任何 Signal/Reached 字段（白名单仅欢迎结算的首摆事件）；
- **代理校准**：种子期定性访谈（5-10 人）与旗标判定对照——
  访谈说"我一直在试怎么让那只再来"而未判 D5（或反之），
  **修旗标定义，不修用户**（冻结）。
