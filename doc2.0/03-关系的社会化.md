## 零、核心论点：一段关系要成立两次

第一次成立在它们之间（02 的私人阶梯）；第二次成立在**岛的语言里**。
社会 = 关于关系的公共记忆。doc/00 §六 从 Generative Agents 借来的
"Agent 之间的信息传播"，本文把它落到关系上——这是那条机制第一次有了产品形态。

五层架构（评审入档——猫岛的世界模型，未来跨家庭/社区/文化都从这里接出）：

```
Event Stream        事件流（事实层，唯一事实来源）
      ↓
Individual Memory   个体记忆（可错，不覆盖事实）
      ↓
Relationship State  关系状态（02：由事件史派生）
      ↓
Social Belief       社会认知（本文：由目击/转述派生）
      ↓
Island Culture      岛屿文化（长期沉淀：语言、习俗、公论）
```

**每层只从下层派生，永不反向写入。** 这个单向结构是猫岛区别于社交游戏的架构底座。

## 一、社会化四段（与私人阶梯平行，恒慢半拍）

```
私人阶梯（02）：见过 → 熟了 → 有默契 → 老朋友
社会阶梯（本文）：它们俩知道 → 有猫看见过 → 有猫说起过 → 岛上都这么说
                 （私人事实）    （目击）      （传闻）      （公论）
```

铁律一：**社会阶梯永远慢于私人阶梯**——"岛上都知道"必然晚于"它们自己知道"；
公论不得早于私人阶梯的"有默契"。社会是慢半拍的，这正是它可信的原因。

铁律二（评审补，与铁律一并列）：**社会认知永不反推关系。** 顺序永远是
行为 → 关系 → 社会认知；公论是**只读的派生态，永不作为关系裁决的输入**——
"大家都说它们关系好，所以它们关系好"在机制上不可能发生，否则就是社交游戏。

## 二、链路：目击 → 转述 → 公论

1. **目击**〔增量：事件目击维度〕：共同事件发生时，第三只猫刚好在场
   （同地点即目击），落 `Event.witnesses`。没有目击者的关系推进照常发生——
   只是暂时不为岛所知（**私下的友谊是允许的**，被看见只是概率）。
2. **转述**〔半已有：交叉视角扩展〕：目击者在**自己的生活**里说起这件事——
   转述是一个普通事件，不是系统广播。天选载体：社交型 NPC"爱八卦的三花"
   （doc/00 §八 既有角色）。
   - **传闻允许失真**：三花可以传错（"听说它们吵翻了"——其实没有）。
     主观认知可错、且不覆盖世界事实，是既有正典（doc/00 §七）；
     错误传闻由后续生活自然修正或自然淡出。八卦是轻喜剧，不是狗血（doc/07）。
3. **公论**〔增量：派生统计〕：当**足够多只不同的猫**在**足够长的时间**里
   说起过这对关系（转述次数 × 来源多样性的派生统计，阈值永不暴露），
   岛的语言开始默认它们是一对——**并称在此刻自然出现**。

## 三、并称生成规则（定稿，六条）

1. **永不系统颁发。** 没有弹窗、没有称号、没有成就页。
   "七仔和小橘成为最佳搭档"这类句式即 P0。
2. **从一张嘴开始。** 并称第一次出现，必须在**某一只具体的猫**的话里
   （"码头那两只"最先是三花说的）；别的猫沿用是它们的自由；
   《猫啊岛日报》**最后**才跟着这么写——媒体从不发明称呼，只记录已经流行的。
3. **描述，不是头衔。** 并称只能由**地点/时段/行为**构成：
   "码头那两只""总在退潮时一起出现的那两个"。
   抽象头衔（搭档/组合/CP/最佳/黄金…）入禁词表。
4. **会淡出。** 关系冷了，岛上就慢慢不这么说了——无仪式、无通知，
   最多在日报一角出现"很久没人这么叫过了"。**社会事实会呼吸。**
5. **七仔例外。** 岛的语言从不把七仔和谁绑定——它是所有人的（doc/22 红线④）。
   它可以出现在传闻里（"它把最好的贝壳给了小橘"），但永不进入固定并称。
6. **用户猫的第一次并称是里程碑。** 你的猫第一次被岛上并称
   （岛闻里出现"松林那两只"，其中一只是你的猫）——
   **"它在岛上有了自己的位置，而这个位置不是你给它的，是它自己活出来的。"**
   该时刻进"第一次"系列，值得一封海螺（走既有选稿优先级，不加频）。
   同机制也长出**单猫的岛上叫法**（"那个总在雨天去灯塔的家伙"）——你的猫
   第一次被岛上用一句话描述，同样是社会身份时刻，同样进"第一次"系列。

## 四、用户视角：看得见的社会（全部叙事层，零 UI 化）

社会化的进展从四个地方被看见，**且允许互相不一致**：

| 视角 | 载体 | 看见什么 |
| --- | --- | --- |
| 它自己怎么说 | 你的猫的日记 | "今天又碰到小橘了。" |
| 有猫说起过 | 交叉视角/转述 | 三花："它俩最近总在一块儿。" |
| 传闻 | 岛闻 | "松林那边，有两只猫最近形影不离。" |
| 公论 | 日报 | 开始自然并称："码头那两只昨天……" |

反差即内容：它自己觉得只是熟人，岛上都说它们是朋友——
四个视角的错位是喜剧素材，不是数据 bug。

## 五、验收（eval）

- **时序抽检**：公论不得早于私人"有默契"；社会阶梯任何一段不得先于私人对应段；
- **来源抽检**：任一并称必须能指认"第一张嘴"（哪只猫、哪天、因为哪个目击事件）
  ——指不出 = 系统在发明社会，判缺陷；
- **禁词抽检**：头衔词表（搭档/组合/CP/最佳/黄金…）出现即 P0；
  并称出现在任何 UI 元素（非叙事文本）即 P0；
- **失真抽检**：错误传闻必须有修正或淡出路径，不得永久固化为"事实"。

## 七、冻结要点（2026-08-05 评审定稿）

- **核心定义**：关系必须先存在于生命之间，再存在于世界的语言中。
- **核心链路**：共同事件 → 私人关系 → 目击 → 转述 → 公论。
- **核心禁区**：系统授予关系 / 数值展示关系 / 主动制造称号 / 强制社会化
  （私下的友谊永远被允许，被看见只是概率）。
- **用户价值**：用户最终获得的不是"我的猫等级很高"，而是——
  **"这只猫在这个世界里留下了属于自己的位置。"**

## 八、下一步（2026-08-05 评审插队改序）

- **04《猫岛语言系统》**（新增，先做）：岛已经开始长出自己的语言
  （并称语法、叫法、日报体、猫的翻译）——在跨家庭之前把方言定下来。
  **语言即辨识度**；
- **05《跨家庭》**（P2）：本文机制天然是它的地基——别人的猫进入你的岛闻时，
  目击→转述→公论管线**原样复用**，社会结构先于社交功能存在；
- **06《一双手》**（最后）：用户不是创造世界的人，是被这个世界慢慢接纳的人。

**一句话定性（冻结候选）**：

> **maoadao 的多人不是"加好友看主页"，而是——
> 我们生活在同一个岛上，因此偶尔看到彼此留下的观察。**
> **社会化发生在世界里，不发生在社交功能页里。**

**MVP 只保留未来接口（不实施，防走样）**：

- 共同观察（21 §三 观察板——共享观察，不共享答案）；
- 岛闻中的他人匿名事实（"有岛民说…"——本文 目击→转述→公论 管线原样复用，
  多一种目击者而已）；
- 情侣/熟人共同来岛的可能性（曾有共同生活宪法预写稿，git 历史可找回）；
- 世界事件共同见证（大退潮日式习俗，01 §三——天然的多人时刻）。

**明确不做（冻结候选）**：

Feed · 点赞 · 粉丝 · 私信 · 排行 · 公会 · 用户主页内容流。
——以上任何一个出现，多人就从"同岛生活"退化成"社交产品"，
与 12"绝对不证明社交"同轴。
