## 零、猫岛起源（2026-08-05 拍板）

很久以前，有一个人来到这里。他叫**猫阿道**，他很喜欢猫。

他发现：现实世界太忙，人和猫都没有足够的时间慢慢生活。

于是他建了一座岛。在这里，没有主人和宠物，只有一起生活的居民。

他和他的猫——**七仔**——在岛上生活了很久。

直到某一天，他离开了，再也没有回来。

留下七仔，留下一本写了七行的岛民册，和一座等着新故事发生的岛。

### 世界观四层

```
猫岛     —— 一个可以慢下来生活的地方
猫阿道   —— 创造它的人，留下未完成的故事
七仔     —— 他留下的第一位居民，猫岛记忆的守护者
用户     —— 新登岛的人，在这里遇见属于自己的生命
```

### 这段起源解决了什么

- **定位语有了世界内出处**：「当现实世界太忙，总有一座岛上的猫替你慢慢生活」
  （doc/00 附录）就是猫阿道建岛的理由——定位语从此不是文案，是岛的记忆。
- **品牌名有了故事**：岛叫"猫啊岛"还是"猫阿道的岛"叫顺了嘴——哪个在先，
  岛上说法不一，**永不考证**（此悬念自原岛主猫 bio 原句转移，maoadao.com 从此有出处）。
- **制度有了作者**：岛民册、船票（"上岛要有人带"）、登记处，都是他留下的，
  现在由猫们照旧办着——登记处的老猫（原 NPC 换名接任，建议名"老章"，可改）
  是照着他的样子把册子一笔一笔记下去的那只，也是岛上最记得他的"旁人"。
- **岛不是场景，是有人留下心意的地方**：用户进入的不是一个 App，
  是"一个曾经被人深爱过的地方"。

### 猫阿道线口径红线（六条）

1. **去向永不解答**。我们永远不写他回来；世界内则永远开放——
   岛上有猫觉得他会回来，有猫觉得不会，都不算数。
2. **永不出场**。无正脸（旧照片只有背影、被七仔挡住、或已褪色）、无人声——
   人走了，岛上只剩猫的声音（与 doc/17 人声禁令互为表里）。
3. **既有设定一字不改**。怕汽笛、坐船票、只捡被丢下的东西、第七行——
   新起源只是给它们一个引力中心，**关联永不点破**，留给观众自己拼。
4. **沉重度节流**。猫阿道线是温柔背景（星露谷的爷爷、动森的过去），
   走"小剧情 15%"预算的背景脉络；**D0/D1 零主动触达**（序章仅一处
   不点破的背景剪影，doc/25），首触点最早 D3+ 由岛闻/日报带出，首周至多一次。
5. **落点永远是"被爱过"**。任何猫阿道文案的落点是他有多爱这座岛和这只猫，
   不是他走了多久——**岛本身就是那封告别信**，所以他的离开是谜，不是抛弃。
6. **不做寻宝**。他留下的信、未完成的角落、旧照片，是**被生活撞见的**
   （事件线/岛闻/生活册的自然揭示），不是任务清单，不设收集进度。

## 一、四价值观（岛的生活哲学——猫阿道建岛的理由）

| 价值 | 一句话 | 已落地的机制 |
| --- | --- | --- |
| 自由 | 猫想做什么就做什么，结果由猫决定 | Agent 意图 + 模拟器裁决；留言不承诺照做；第一次拒绝（doc/21） |
| 慢 | 没有 KPI，没有进度条 | 无数值/签到/任务；时段解锁；海螺"适时沉默"（doc/19） |
| 发现 | 每天发现一点小东西 | Life Moment 微细节池（doc/09）；叼回小东西（doc/21 §五）；第一次系列 |
| 连接 | 猫和猫之间自然产生关系 | NPC 关系与交叉视角；事件线；未来猫认识猫（P2） |

七仔不新增设定地**演出**这四条（doc/25）；对外文案从这四个词生长，不从功能列表生长。

## 二、核心循环

```
猫自由生活 → 产生事件 → 用户观察 → 轻参与 → 留下痕迹 → 影响明天
```

反面（永不做）：用户操作 → 获得奖励。

留痕的三条通道，边界写死：

1. **对你的猫说话**（私有，被记住）：留言/海螺回信 → 主人记忆 → 转译进日记（doc/23 §二）。
2. **在岛上留下东西**（公共，不定向）：可能被七仔捡走，进它的收藏与内容号——
   被动、公开、**不建立对具体用户的记忆**（doc/22 §八「被捡走」机制）。
3. **和猫共同做一件东西**（P3）：材料来自它捡的，成品进小屋或公共角落，
   有它的反应，无数值（doc/23 §四）。

## 三、生活法则（判据收拢，出处注明）

1. **事实先行**：Agent 产意图，模拟器产事实，LLM 只表达，导演控节奏（doc/00 §五）。
   大模型永不发明事实。
2. **生活驱动**：小事要小得具体、具体得无用（doc/09）；
   内容比例 50 生活 / 25 关系 / 15 小剧情 / 10 大事件。
3. **时间与人同步**：tick 一次生成整天，展示按现实时段解锁（doc/09 §五、doc/14）。
   世界不为你暂停，也不等你。
4. **猫化判据**：把描写里的猫换成狗/狐狸/机器人仍成立，就不合格（doc/21）。
5. **拟人化红线**：猫不许有心事；心事一律由旁人（岛民/日报/邻居猫）来猜（doc/21）。
   七仔"在等谁"，永远只是岛民的说法。
6. **参与判据**：结果由猫决定的可以做；由用户操作/资源决定的不做（doc/21）。
7. **好奇不是愧疚（2026-08-05 新增红线）**：产品的拉力永远是"它今天过得怎么样"，
   不是"它想你了/你多久没来了"。缺席不责备（doc/07）是它的应用；
   召回消息永远是猫的生活，不是催促（doc/11）。
8. **感官不出戏**：无人声（doc/17）；禁 emoji 与卡片堆栈（doc/05）；
   用户侧禁系统词（doc/05/15）。

## 四、岛上永远不会发生的事

对内是红线清单，对外可直接化为世界观文案：

- 没有等级、排行榜、签到、连击、体力值；
- 用户永远不会收到任务，也不会被要求"完成"什么；错过不惩罚；
- 猫不会用愧疚拉你回来（"你 N 天没来了"永不出现）；
- 猫不说人话；不接续聊天（一来一回收束，doc/11 §十一）；
- 没发生的事不会被讲出来；
- 不卖行动力、加速、数值强化（doc/00 §十四）；
- 世界不会为你暂停：你不在，生活继续（doc/14）。

## 五、七仔（全文见 doc/22 圣经）

三个身份，层层递进：

1. **猫阿道的猫**——最深的情感来源。它不是没有主人，它曾经有一个非常重要的人。
2. **猫岛第一居民**——见证建岛与此后的一切；它收的全是"别人留下的痕迹"，
   所以它也是**猫岛记忆的守护者**。
3. **新岛民总会先遇到它**——不是职务，是习性（它总在码头，还爱坐在新船票上，
   怪癖④）。谁也没派它，它也不知道自己是入口（doc/25 镜头红线）。

## 六、用户身份

- 你是**猫岛的新居民**，不是"七仔的新主人"——没有人接替猫阿道，
  七仔也不需要被接替；它接受新的相遇，不接受新的主人。
- 你的名字写进岛民册（账户页=岛民册，已上线）；你的猫住在岛上的小屋里；
  岛上唯一的人屋是猫阿道那间（落锁，长线锚点）。
- 词汇口径：「没有主人和宠物，只有一起生活的居民」是猫阿道的话，
  是叙事的方向（居民/相遇优先于宠物/拥有），**不是词禁**——
  "它怎么叫你"、日常口语里的"主人"照旧（术语产品化见 doc/05）。
- 你和猫阿道的对位**永不明说**：他是第一个来岛的人类，你是后来的——
  这层留给用户自己发现。
