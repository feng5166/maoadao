# 猫啊岛 Dogfood 内测手册（第一层：团队 5-10 人 × 7 天）

## 一、邀请文案（可直接转发）

> 我在做一个小东西：**猫啊岛** 🏝️
> 你可以领养一只 AI 猫。它有自己的性格，会在你不在的时候继续生活——钓鱼、交朋友、卷进岛上的各种故事。
> 每天花 1 分钟回来看看它干了什么，给它留句话或提个建议。它会记住你说的，第二天告诉你听没听、为什么。
> 👉 https://maoadao.vercel.app
> 你的船票号：**BOAT-XXXX**（登记时要填，一张票可供几位朋友用）
> 领养后记得去「账户」页抄下**找回码**（换设备找猫用）。
> 用 7 天，然后告诉我：你有没有开始惦记它。

## 二、给测试者的三个要求

1. **每天打开一次**（早 8 点后有新故事），连续 7 天
2. 每天做一次干预：留一句话或给个建议
3. 遇到任何「看不懂 / 不对劲 / 卡住了」立刻截图发群里，不要自己猜

## 三、第一层要抓的问题（按 v0.6 定义）

| 类别 | 具体看什么 |
| --- | --- |
| 丢档 | 关闭浏览器再开，猫还在吗；清缓存后用找回码能找回吗 |
| 身份错乱 | 会不会看到别人的猫/别人的留言入口 |
| 推进异常 | 早 8 点后是否有新一天；日期是否连续不跳天 |
| 叙事断裂 | 日记是否承接昨天；回执是否对应自己昨天的建议；有无"兜底"样式的干日记 |
| 看不懂 | 首页 10 秒内能否明白这是什么；领养流程哪一步犹豫了 |
| 建议无反馈 | 提了建议第二天没有回执区块 = P0 bug |
| 移动端 | 手机浏览器排版、分享卡保存 |

## 四、你的每日运营例行（约 10 分钟）

1. **早上 8:10** 开观察后台 `/admin`（首次输入管理密钥，12 小时内免登录）：
   - 世界天数 +1 了吗；「兜底日记累计」有没有涨（涨了 = 昨晚叙事有失败，Cron 会自动补，但要留意连续涨）
   - 建议消费状态：昨天的建议是否都变成「第 N 天已消费」
2. **内容抽检**（后台"每日摘要"区，按 v0.6 抽检表人工标记）：
   - 新用户首日内容 / 连续用户当日内容 / 有回执的内容各看一篇
   - 七问：看得懂吗｜像这只猫吗｜承接昨天吗｜状态真变了吗｜有悬念吗｜像模板吗｜值得分享吗
3. **看审核日志**：有没有误拦（好内容被 block）
4. 收集群里反馈，标 P0（丢档/身份/无回执）/ P1（体验）/ P2（文案）

## 六、7 天后的判定问题（对每个测试者问）

1. 你能说出至少一只 NPC 的名字吗？
2. 有没有哪天是"惦记它才打开"的？
3. 你的建议它听没听，你有感觉吗？
4. 第几天开始觉得重复？
5. 你愿意把它的分享卡发给别人吗？

→ 5 个人里有 3 个能答出 1/2/3，重复感出现在第 5 天以后，就可以进第二层（熟人 20-30 人）。

## 七、已知边界（提前告知测试者，避免误报）

- 邮箱验证码暂未开通（邮件服务待配置），先用找回码
- 每天只推进一次（早 8 点），当天再刷新内容不变——这是设计不是 bug
- 立绘生成要等 10~30 秒，刷新后出现
