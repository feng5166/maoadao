# D1「相遇」重构：从创建角色到遇见生命

> 2026-08-01 拍板。受「小蘑菇秃秃」启发：现在的 D1 技术底子是对的（船票/第二 NPC/首日不空白/留言→D2 兑现/旧钥匙线），
> 但心理曲线还是 RPG onboarding——设置属性→生成角色→接任务→推剧情。
> 要翻转成：遇见它→认领它→留下一句话→看它开始生活→明天回来看看。

## 新目标

用户在离开猫啊岛之前，产生一个心理认知：**「这只猫已经属于我了，它会继续在那里生活。」**
D1 最重要的指标不是领养完成率，而是 **first_words_submit**——领养 ≠ 建立关系，第一句话才是关系开始。

## 新流程

```
船票登岛 → 码头相遇 → 岛民登记册 → 第一次告诉它一句话 → 生成相遇照片
→ 猫来到岛上的第一天（日记）→ 发现旧钥匙（轻伏笔）→ 看它现在怎么样
→ 摸摸它 → 约定明天见 → 夜晚离开仪式 → 猫继续生活
```

## 改造清单

### 1. 码头相遇页（/adopt 变为过渡页）

填表前先"遇见"：码头场景图 + 「猫啊岛每天都会迎来新的居民。今天，有一只猫刚刚来到这里。」
按钮「去看看它」→ /adopt/register。作用：把用户从"产品用户"切换成"主人"。

### 2. 岛民登记册（/adopt/register，替代表单感）

- 册页分页体例（第一页…第四页），不是"创建角色信息"
- **性格滑杆 → 心理选择题**：三道"第一次见到它，你觉得它是什么样"（陌生地方/陌生猫/晴天下午），
  后台映射胆量/社交/勤劳，参数彻底隐身
- 称呼保留并提升（第三页单独一页：如果它以后想找你，它应该怎么叫你）
- **第四页新增「第一次见面，你想对它说什么」**（firstWords）——D1 最重要输入

### 3. 首次生成：生成"相遇"而不是"角色"

- **Asset 1 相遇照片**（新增）：不是头像，是"第一天你和它相遇的照片"——码头+海+棉花+它第一次看向主人，
  同一绘本画风。存 ArrivalPhoto 表，`cats.arrival_photo_url`。未来的分享资产
- **Asset 2 第一句话记忆**：firstWords 进 MemoryEntry（kind=first_meeting，importance=10，永久置顶记忆），
  首日日记必须回应这句话
- **Asset 3 旧钥匙降调**：事件线照旧开（arrival_key 五步不动），但 D1 摘要不再挂「旧钥匙的来历·第 1 步」
  进度——今天它只是"门口的一个小发现"，未来才发现它重要

### 4. 第一篇日记结构

30% 它是谁 / 30% 今天做了什么 / 20% 对你的第一印象（回应第一句话）/ 20% 留一个小秘密。
禁止任务腔（"开启主线"）。

### 5. 我的猫首屏 = 它现在怎么样

场景+猫+此刻状态行+心情提到首屏（doc/09 §5 的时段机制已就位），故事在"今天发生的小事"之下。

### 6. 入岛三件事 → 第一天的小约定

不是任务，是约定：告诉它一句话（firstWords 也算）/ 带它认识岛上的一位朋友（2→1）/ 明天再来看它。
完成态从「都办妥了」改为「今天，它记住了三件事。」

### 7. 首次干预降级

D1 只突出「今晚给它留句话」；建议选项收进二级（「你希望它明天更接近哪种生活？」），不选=它自己决定。
第一次见面不让主人"管理"猫。

### 8. 夜晚离开仪式（新增 /my-cat/goodnight）

D1 留言提交后不直接结束：夜晚页——「你离开后，{name}把那张纸放在了床边。它说明天早上会告诉你今天发生的事。」
按钮「明天来看它」。建立"它会继续生活"。

### 9. 关系阶段语调整

D1「它知道你来了。」 D2-3「它开始期待你的留言。」 D4+「遇到事情的时候，它会先想到你。」
D7「它习惯把发生的事告诉你。」

### 10. 相遇漏斗埋点

arrival_scene_view → adopt_start → adopt_complete → **first_words_submit** → arrival_photo_view
→ first_story_view → pet_cat → leave_for_tomorrow

## 采纳的修订（2026-08-01 二次拍板）

1. **相遇照片走合成路线**：码头场景 + 定稿立绘贴纸合成拍立得（sharp，无新增生成成本，一致性 100%），
   必须在立绘定稿**之后**生成；文字说明放 HTML 不烙进图（serverless 中文字体风险）。生成路线进二期。
2. **第一句话记忆防复读**：不永久置顶。只在这些日子进叙事——首周（catDay≤7）、低谷日（当日 fail≥2）、
   每逢七天。低谷日引用是杀手锏（"今天很难。但我想起你第一天说过，不要害怕"）。importance 10 保证进 D7 纪念册。
3. **立绘首次亮相 = D1 小高潮**：码头相遇页不出脸（悬念），登记完成后相遇照片+立绘一起亮相。
4. **夜晚仪式 v1 只做留言后跳转**（/my-cat/goodnight），不做按时间自动入夜（避免与 doc/09 时段机制打架）。
5. **指标基线**：adopt_complete→first_words_submit ≥80%；终审指标 = leave_for_tomorrow→次日 first_diary_read。

## 取舍

保留：船票、第二 NPC、旧钥匙线、首日事件、留言、D2 兑现、立绘。
改造：滑杆→心理选择；三件事→小约定；四选一→降级；首日剧情→生活片段化；日记→相遇故事。
新增：第一句话永久记忆、相遇照片、夜晚离开仪式、当前状态首屏。
