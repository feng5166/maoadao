# v1.0 方向:产品重心校准——从"AI 模拟器"到"生命 IP"

> **状态:P0 三项已于 2026-08-01 当日实施**(Life Moment 六池 90+ 条 + 口癖接入四处叙事;
> 首页此刻状态行 + 时段解锁,日记改为晚六点收束、早八看"它怎么说";
> 生活册"它记得的第一次" + 主人留言跨周引用)。P1(相册/周报/轻互动)待 P0 数据验证后再做。
>
> 2026-08-01 拍板。输入:小蘑菇秃秃案例(Sowii,前美团高管创办,高瓴红杉投资;
> 实体玩偶不联网不用电,NFC 碰一下"住"进手机,24 小时过自己的小日子)+ 30 天干跑现状。
>
> 核心判断:**技术层面已超过"数字宠物 Demo",但产品表达需要从"AI 生命模拟器"
> 转向"一个值得每天打开看的生命 IP"。**
>
> 定位语修订:~~AI 模拟驱动的猫咪世界~~ →
> **一个每天都会发生一点小事情、用户忍不住想打开看一眼的猫咪生命世界。**
>
> 后续方向不是"让猫更聪明",而是"让猫更像一只真实存在的小生命"。

## 一、为什么校准

秃秃用户的第一感知是"这个小东西好可爱,我想看看它";猫啊岛目前给人的第一感知
容易是"这是一个 AI 模拟世界"。Agent / Simulator / Memory / Director 是护城河,
**不是用户购买理由**——全部藏到幕后。秃秃的产品哲学:不急着展示 AI 能力,
让用户感受到生命存在(冯威赫甚至砍掉聊天、不让 IP 说话,只"嘟嘟"叫,以保形象稳定)。

现有事件谱系(灯塔谜题/借钱/开店/探险/NPC 委托)偏"AI RPG";秃秃的内容全是
"薯片熨烫师/饼干打孔师/给可乐打气"——**无意义但极具体**的生活小事。
猫真正吸引人的不是每天抓老鼠,是"它今天又趴在那里睡觉"。

## 二、核心转向:事件驱动 → 生活驱动(Life Moment 层)

```
World Event → Life Moment → Narrative
```

Life Moment 不是新模拟系统,是**事实的生命化表达层**:模拟器照旧产事实,
但每个低强度事件必须携带一个可叙事的微细节(落 Event.data,LLM 只包装不编造——
事实先行架构不变)。30 天干跑里 rest 占 23.4% 却产不出一句可看内容,
v0.9 已给 rest 加睡姿/梦境池——本方向就是把这个修法升级为一等公民。

反例转正样例:模拟器产出「煤球下午没赚钱、没推进灯塔线、没认识新朋友」,
这不是低价值一天,可生成:
「今天风很大,煤球把晒了一下午的树叶都吹跑了,它追了半个岛,最后只找到三片。」
**这个才像猫。**

素材标尺(写池子文案时执行):不是"捡到一片树叶",而是"给薯片熨大波浪"——
小事要小得具体、具体得无用。

## 三、内容比例修订(替代 doc/00 §9 与 doc/08 远期目标)

| 类型 | 新比例 | 旧目标 |
| --- | ---: | --- |
| 普通生活(Life Moment) | 50% | 单日轻事件 50% |
| 关系互动 | 25% | 15% |
| 小剧情(短线推进) | 15% | 持续事件线 30%(修订:线是背景脉络,不是日更主菜) |
| 大剧情(稀有事件) | 10% | 5% |

eval 红线同步修订:事件线事件占比目标从"远期 30%"改为 **15% 上下**;
新增红线:**每天每猫至少一件"值得看的小事"**(有微细节的事件 ≥1)。

## 四、v0.9 四功能重新定位(6a86ce2 已上线)

1. **交叉视角**:比普通剧情更重要——它在形成"共享世界"
   (煤球:「阿福今天看起来怪怪的」/ 阿福:「那只小猫好像发现了我的秘密」)。
   这是未来多人 AI 社会的种子。保留并强化。
2. **公告栏个性化 → 改名「岛上生活」**:谁去了哪里、谁认识了谁、谁开了小店、
   谁丢了东西。它不是新闻,是**世界存在感**(动森方向)。
3. **往期回音 → 升级为「猫记得你」体系**:猫啊岛最大的资产不是事件,是记忆。
   秃秃最大的价值是"它一直存在"。目标体验:D1 你说"不要太累",
   D20 煤球:「今天本来想去灯塔,但想到你第一次来的时候让我别逞强。」
   这比新剧情更有价值,优先级上调。
4. **摸摸它 → 轻接触家族**:摸摸/喂小鱼/看睡觉/叫名字/留一句话。
   解决"每天回来=需要阅读"的负担——宠物天然还有一个动作:碰一下。
   **不做小游戏**,只建立人与生命的接触。

## 五、无目的打开:首页第一屏重构

高留存产品的形态是"我没事打开看看它"(微信/猫),不是"看今天剧情"。

第一屏从"发生了什么"改成"**它现在怎么样**":

```
煤球现在:在海边睡着了。
今天风很舒服。
它说:"这里比昨天安静。"
────────────────
(往下才是)今天发生了什么
```

实现原则(吸收秃秃"时间和人同步":8:00 暖阳初醒 → 22:00 安眠):
- 三时段映射现实时间,**tick 照旧一次生成整天,展示层按现实时段解锁**——
  早上打开只见上午的事,下午的事下午浮现,晚上日记收束全天;
- "此刻状态行" = 地点 + 动作 + 一句现在时(素材来自当前时段事件的微细节);
- 一天从 1 个打开理由变成 3 个,直接服务"七日人均查看次数"与停留埋点。

微瞬间形态(秃秃两拍图说:「11:30 看!一节一节都卷起来啦 / 11:45 菇的大波浪
薯片最厉害啦」):事件时间轴用**现在时短句**呈现,日记降级为一天的收束回顾。

## 六、Digital Life Layer(数字生命层)

架构上在 Simulation / Narrative / Product 之外新增 Life Layer,负责:
日常状态、小习惯、偏好、收藏、纪念、情绪变化、小惊喜。

体验目标(煤球第 30 天):喜欢下午去码头;不喜欢雨天;喜欢听阿福讲故事;
收藏了 5 片叶子。**这些才构成生命。**

v1 实现原则:**事实的派生读取,不新增模拟机制**——
习惯 = 事件地点/时段统计;收藏 = 拾获物累积;"第一次" = 各类事件首现
(第一次认识谁/第一次收到礼物/第一次开店);主人影响 = nudge 采纳史。
全部可从 events 表回放推导,零新状态。

声线一致性(冯威赫:"对话轮次多了就会有角色不一致"):每只猫固定
**自称/口癖**字段写进叙事约束(秃秃自称"菇":「菇的帽子在飘」),
防跨天漂移 + 自带表情包体质;eval 增加跨天日记声线抽检。

## 七、路线排序

### P0

1. **Life Moment 素材层**:每个低强度模板配微细节池,合计新增 100-200 条;
   猫口癖/自称字段接入叙事。验收:干跑 30 天,每天每猫至少一件值得看的小事。
2. **首页"它现在怎么样"重构**:此刻状态行 + 时段解锁 + 微瞬间时间轴。
3. **记忆展示强化(猫记得你)**:第一次系列、主人影响史、回音升级为跨周引用。

### P1

4. **猫咪相册**:今日一图 = 立绘 + 场景模板合成(非每日 AI 生图,守 doc/00 §13);
   表情差分 + 口癖文案 = 表情包级分享物(比完整分享卡门槛更低,
   秃秃的一级传播就是用户自发截图做表情包——弱关系传播,认同情绪就转发)。
5. **周报/月报**:WeekBook 已有第一周,扩「煤球的一周」常态化 +「第一个月」。
6. **轻互动扩展**:摸头/喂鱼/打招呼(接触,不是游戏)。

### P2(多人,三阶段不跳步)

我的猫 → 我的猫认识岛上的猫 → 我的猫认识别人的猫。
16 只 NPC 即未来官方居民。秃秃的启发:不急着做社交,先天然具备"被分享"。

### 增长侧备忘(不占产品优先级)

- **NPC 内容号**:挑 1-2 只人设最强的 NPC(社牛橘猫?)把模拟器免费产出的日常
  发抖音/小红书——Sowii 打法:IP 先跑出路人缘数据,再商业化
  (抖音短片段撬公域,小红书图文沉淀好感)。
- **商业化原则"买到手才是开始"**:皮肤 = 同时解锁场景/事件池
  (买渔夫斗篷,渔港线才向你的猫开放)。付费点仍是外观,但买完是开始。

## 八、明确不做 / 警惕

- 不做小游戏化互动(数值、连击、签到压力);
- 不为"生活感"放开 LLM 自由编造——素材永远是事实数据;
- 对外文案去掉"AI/模拟/Agent"词汇,用世界观语言(8553567 已开的路,走到底);
- 不因转向生活流而废弃事件线——线提供牵挂与连续性,只是降频为背景脉络。

## 九、验收与定性信号

- 停留埋点:无明确目的的打开次数、同日二次打开率(时段解锁生效的直接证据);
- "猫记得你"触达率:第一次系列/往期引用的展示与查看;
- 干跑抽读新增标准:内容读起来"像猫"还是"像 RPG 任务日志";
- 终极定性:用户描述产品时说的是"我的猫今天……"还是"这个 AI 会……"。
