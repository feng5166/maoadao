# 海螺功能全景(2026-08-04 快照,供优化决策)

> 世界观:海螺是"传声海螺"——猫偶尔伸到现实世界的一只爪子,不是客服窗口。
> 三条铁律:入站永不进 LLM(全部确定性文案);猫不住在微信里(一来一回后回岛);
> 事实先行(消息素材只来自 factSummary/回执,不在文案层编情节)。

## 一、链路总图

```
绑定:网页「让它找到我」→ 专属二维码 → 用户扫码首条消息 → bindChannel
     (建通道+开窗24h+首句落留言) → 握手文案(按性格分池,夜间变体)+ 欢迎礼(猫头小相)

入站(用户→海螺):handleInbound 分流
     媒体 → 旁白体"它只看得懂字"(不占额度不落留言)
     找猫(正则≤20字) → 报此刻真实状态(与网页同一套时段门事实)
     退订词 → mutedAt(说话即复订)
     其他 → 落留言(合并未消费,过审核,明早日记回应)
     节流:同一北京日 第1条实质回复→第2条收束→之后微响应旁白→≥4次只回🐾
     任何入站刷新 windowOpenUntil = now+24h

出站(海螺→用户):
     8:00 tick 后入队(sendAfter 8:00-8:40 打散) → dispatch cron(8:00-8:55 每5分)发送
       优先级:D2兑现(必发) > 事件线落幕/开店/D7周册 > 缺席3天关怀(冷却5天) > 早安保底
     21:00 goodnight cron 直发:晚安(今晚的事>明日盼头>"没什么大事"),约3天随一张岛闻头条图
     发送前:静音/熔断/暂停/24h窗口检查;窗口关→window_closed=网页"未寄出的信"
     熔断:一批全败≥3 → wechatPaused 自动停发

回岛:所有消息带 72h HMAC 免登录短链(/s/{code} → entry?wt= → 种 cookie 落 /my-cat)
```

## 二、消息日历(用户视角)

| 时刻 | 内容 | 条件 |
|---|---|---|
| 绑定即刻 | 握手 + 欢迎礼(圆形猫头小相) | 一次性 |
| 8:00-8:40 | D2兑现 / 事件信 / 缺席关怀 / **早安**(保底,变体池×今晨主事件×天气句) | 每天必有一条 |
| 8:00 早安 | 昨晚 18 点后回过话 → 开头带回执感"昨晚你说的话,我睡前又看了一遍" | doc/17 习惯环 |
| 21:00 | **晚安**(变体池×今晚收束/明日盼头),约⅓的日子随"今天岛上的一幕"图 | 每天;窗口关→落未寄出的信 |
| 任意 | 用户主动说话的即时回复(找猫/回执/收束/旁白) | 一来一回节流 |

上限:每天推送至多 2 条(早+晚),即时回复不计。

## 三、平台约束与对策

- **24h 窗口**:唯一续窗方式是用户说话 → doc/17 保活设计(晚安轻钩子/早安回执感/断链落"未寄出的信"召回)
- **发图可用**(CDN AES 上传,坑在 wechat-bridge/README);**发语音服务端不下发** → 降级"海螺留声"站内页
- 静默 22:00-8:00(握手豁免);消息永远以「🐱 猫名:」开头

## 四、数据面

- `Channel`:externalId(openId)/windowOpenUntil/mutedAt/replyDay/repliesInDay/giftSentAt
- `OutboundMessage`:kind(handshake|d2_promise|event|absence|morning|goodnight|postcard)/status(queued|sent|window_closed|failed)
- `OwnerNudge`:微信留言与 Web 同规(未消费合并最新,isPublic=true)
- `WechatMessageLog` + 飞书同步:入站全量审计
- 埋点:wechat_pair_success / wechat_msg_sent{kind} / wechat_window_closed_drop / wechat_first_reply / intervention_submit{via:wechat}

## 五、运维口

- Cron:tick(8:00) / dispatch(8:00-8:55×5min) / goodnight(21:00);warm 每5分
- 人工验收:`/api/wechat/goodnight?dry=1`、`/api/wechat/postcard?dry=1`(独立明信片已并入晚安,路由留作验收)
- 开关:worldState.wechatPaused(熔断自动置位,后台恢复);channel.mutedAt(用户退订)

## 六、已知张力与优化候选(待拍板)

1. **节流 × 晚安钩子**:白天已聊满 2 次的用户,睡前回晚安只得到旁白/🐾——钩子回报感打折。
   候选:晚安发出后的第一条入站豁免节流一次("晚安回应位")。
2. **晚安配图主角**:现在是岛闻头条猫,不一定是自家猫。候选:优先自家猫生活照/相遇照,头条图退为次选。
3. **找猫意图正则较糙**(宁可错存方针下可接受);留言 60 字截断无提示。
4. **早安素材**只取今晨事件,若 tick 晚点/无事件回退"睡懒觉"——观察几天真实手感。
5. **指标看板缺位**:窗口存活率/晚安回复率/断链恢复率(doc/17)已有埋点,缺后台汇总页。
6. **未寄出的信**只展示最新一封;断链多天后早安晚安各一封,情感召回可以更整("这几天它写了 N 封")。
