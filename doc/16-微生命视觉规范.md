# 猫啊岛微生命视觉规范(v1,2026-08-04)

> 目标:让窗户"呼吸",不是让页面"动画"。参照物:吉卜力电影的一帧静止镜头里,
> 只有海浪和云在动。破坏绘本感的动效,宁可不做。

## 一、原则

1. **呼吸,不奔跑**:允许环境的缓慢往复(云/波光/雨/光晕/极缓的缩放),禁止角色位移动画(猫跑动/跳跃/表情帧动画)。
2. **像天气,不像游戏大厅**:周期 6-40s,低透明度,叠加层永远 `pointer-events:none`。
3. **一屏至多两种动效**同时进行;用户不该"注意到"动画,只该觉得画面是活的。
4. **`prefers-reduced-motion: reduce` 一律退回全静态**,无例外。

## 二、技术优先级(成本从低到高)

1. **CSS 叠加层**(现役,首选):见 `app/globals.css` 的 `fx-*` 系——
   `fx-cloud`(云影横漂 38s/56s)、`fx-shimmer`(波光 9s)、`fx-rain`(雨丝)、`fx-dawn/fx-dusk`(晨昏色温)、`fx-breathe`(照片极缓呼吸 16s,幅度 ≤1.5%)。
2. **2-3 层 PNG 视差**:场景拆前景/主体/天空层,滚动或时间驱动微位移。留给首页主视觉升级,单场景收益不明显不启用。
3. **视频微循环**(最后手段):image-to-video 首尾同帧循环已试片验证(见记忆/assets/scenes-raw/dock-loop-test.mp4)。仅当 CSS 表达不了(水面真实晃动/烟囱冒烟)且该画面是核心情感位时启用;必须 poster 兜底 + 懒加载 + 静音循环 + ≤2MB + reduced-motion 退静态。

## 三、禁项

- 猫的跑动/骨骼动画/表情帧
- 粒子系统、发光、屏幕震动、任何"游戏升级感"反馈
- 自动播放的有声内容;弹窗式动效
- 同屏 >2 种动效;周期 <6s 的循环(雨丝例外)

## 四、落点清单

| 位置 | 动效 | 状态 |
|---|---|---|
| 首页主视觉 | fx-cloud + fx-shimmer + 天气/晨昏层 | ✅ 现役 |
| 小屋 Hero 生活照 | fx-breathe(极缓呼吸) | ✅ 本轮加入 |
| 场景微动视频循环 | 视频路线 | 试片通过,待拍板 |
| 过场页(farewell 等) | fx-rise 文字缓现 | ✅ 现役 |
